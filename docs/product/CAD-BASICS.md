# CAD 기능 안내

현재 사용법과 지원/미지원은 **[기능별 대표 가이드](../features/README.md)**에서 관리한다. 이 경로는 기존 링크를 유지하기 위한 안내이며 별도 기능표를 중복 관리하지 않는다.

| 작업 | 현재 설명 |
| --- | --- |
| 탭·저장·복구·프로젝트 관리 | [프로젝트와 저장](../features/PROJECTS.md) |
| 선/곡선·스케치·구속·치수·참조 편집 | [정밀 작도와 편집](../features/DRAWING-EDITING.md) |
| 면 작업면·돌출/절삭·Hole/Shell | [솔리드 모델링](../features/SOLID-MODELING.md) |
| 도면 준비·벽/개구부·콘텐츠·바닥/천장 | [평면도와 건축 콘텐츠](../features/FLOOR-PLANNING.md) |
| 모델 뷰·단면/HLR·프레임·시트·교환 | [도면과 출력](../features/DRAWINGS-OUTPUT.md) |
| 이미지·아트보드·Scene·HTML | [이미지와 장면](../features/IMAGES-SCENES.md) |
| 조회·계획·gateway 편집 | [Copilot](../features/COPILOT.md) |

설계·미완료 카드의 책임은 [구현 단위 계획](CAD-BASICS-IMPLEMENTATION-PLAN.md), 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)가 소유한다. 이전 기능표는 아래 보존본에서 확인할 수 있다.
