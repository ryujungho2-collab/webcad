# CAD 도면 프레임·연결·작업 구역 계획 — 2026-10-11

> **문서 역할**: 후속 설계와 당시 결정 기록. 현재 사용법·지원 범위는 [도면과 출력](../features/DRAWINGS-OUTPUT.md)에서 관리한다.

사용자 요청으로 NEXT-STEPS에 추가한 계획이다. **G2-F1/S1과 [G2-F2](../implementation/G2-F2-FRAME-CONNECTIONS-2026-10-11.md)는 완료**, [G6-D5-F1 자동 시트](../implementation/G6-D5-F1-FRAME-SHEETS-2026-10-11.md)도 완료했고 [G2-F3 연속 도면](../implementation/G2-F3-CONTINUOUS-FRAMES-2026-10-12.md) 첫 범위도 완료했다. 기존 G2 아트보드 frame 또는 G6-D5-A2 도곽 완료와 구분하며 최신 검수는 [F3 마감 기록](../verification/G2-F3-CLOSEOUT-2026-10-12.json)을 따른다.

## 사용자 구조

**작업 구역 → 도면 프레임 → 시트 배치**로 작업한다. 작업 구역은 평면도/단면·입면/상세도 또는 조립도/부품도/가공 상세처럼 캔버스를 정리한다. 프레임은 도면의 표시 범위·축척·주석·원본 참조를 관리하고, 시트는 A4/A3 등 출력 용지다. CAD section(실제 단면)과 혼동하지 않도록 화면 조직용 section은 UI에서 **작업 구역**으로 부른다. 프레임 테두리와 출력 도곽도 별개다.

빈 곳에서 드래그해 프레임 생성, 선택한 도면·주석을 여백과 함께 프레임으로 묶기, 프레임 다중 선택→연결 방식→정렬 미리보기→적용을 제공한다. 3D 부품은 기존 정투영/단면 뷰를 선택하거나 생성해 담는다. 새 투영/단면 기하 지원은 해당 G6/X6 카드가 소유한다.

G2-F1/S1/F2와 G6-D5-F1, **G2-F3 첫 범위까지 완료**했다. 현재 CAD 다음 과제 **X6-D2-E1**은 유지하며, 기본 위치는 CAD 곡선/HLR 확대 큐 뒤·G1/G4/I 제작 큐 앞이다. 사용자 지정으로 F1을 구현했고 다음 작업 추천에 따라 S1까지 완료했다. F2도 정투영/단면/상세/부품 연결·구역 간 이동·재정렬 범위로 완료했다. 실제 F2는 원본/대상 두 프레임을 선택해 관계 트리를 구성한다. D5-F1은 연결 트리와 구역 순서를 보존하며 작업 프레임과 출력 배치 identity를 분리하는 범위로 완료했다. G2-F3는 수치 기준점·명시적 seam·정확 중복 정책·해제·시트/출력 범위로 완료했다. 자동 기준점/seam 탐색·부분 곡선 Join·중첩 stitch는 후속이다. F1/S1은 spline/일반 HLR 전체를 선행으로 요구하지 않는다.

## 데이터·상호작용 원칙

- 모델 좌표/실제 치수, 도면 뷰 좌표, 프레임 배치, 시트의 종이 mm를 구분한다. 이동/resize가 원본 객체의 TRS나 치수를 바꾸지 않도록 한다. 축척은 명시적으로 변경한다.
- 화면 경계 안에 겹친 객체를 자동 소유하지 않는다. 프레임은 안정 source/member 참조로 구성하고 멤버 변경은 명시한다. 치수/주석 종속 범위는 미리 보여 준다. 프레임 표시와 출력은 같은 멤버/crop 규칙을 소비한다.
- 같은 모델/뷰를 여러 프레임에서 사용할 때 원본 참조는 공유하고 배치·crop·주석 배치는 프레임별로 저장한다. 생성된 도면 출력을 일반 객체처럼 이동시키는 방식은 사용하지 않는다. 독립 2D 도면과 모델 연관 뷰 adapter를 구분한다.
- 묶어서 배치는 각 프레임의 축척과 참조를 유지한다. 이어 붙이기는 좌표 정합과 seam 정책이 필요한 별도 동작이다. 관계 연결은 형상 소유권 병합을 뜻하지 않는다.
- 원본 변경은 연결된 표현을 갱신하되 source 소멸/모호함은 unresolved로 표시하고 명시적으로 재연결한다. 재배치는 Review를 거쳐 적용하며 고정/잠금 대상을 조용히 옮기지 않는다.
- F1은 기존 **F=화면 맞춤**을 유지하고 2D 전용 Draw frame/Frame selection 버튼으로 진입한다. 추후 F를 변경할 때는 대체 화면 맞춤 키·도움말·입력 포커스를 함께 검토한다.
- 파일 버전/마이그레이션·Undo/Redo·stale/Cancel·잠금·삭제/해제·문서 교체를 포함한다. 반복 source를 중복 변환하거나 내보내지 않도록 instance/placement identity를 검수한다.

## 실제 마감 시나리오

건축: 평면도/단면·입면/상세 작업 구역 → 평면과 A–A 단면 연결 → 계단 상세 확대 프레임 → 원본 변경/참조 복구 → 구역 선택 A3 다중 시트 출력. 연속 평면도 두 프레임의 기준점 정합과 해제는 F3에서 별도 검사한다.

기계: 조립도/부품도/가공 상세 구역 → 정면·평면·우측면 연결 정렬 → 체결부 확대 → 원본 치수 변경 → 고정 프레임 유지 재배치 → 시트/PDF/DXF 대조.

독립 수치 기준으로 실제 길이·축척·crop·정렬을 확인하고 실제 UI에서 생성·편집·이동·Undo·저장 후 재열기·출력까지 검수한다. 공통 기하/표현 경로가 바뀐 경우 해당 회귀를 수행한다. 계획 반영만으로 제품 검수 수치를 올리지 않는다.
