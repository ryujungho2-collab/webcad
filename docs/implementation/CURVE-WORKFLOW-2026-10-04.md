# 곡선 편집과 기능 간 작업 연결

> **현재 기능 설명:** [정밀 작도와 편집](../features/DRAWING-EDITING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

후속: 닫힌·중간 구간 Trim과 치수·live 솔리드의 명시적 재연결은 [구간 Trim 구현](CONTOUR-TRIM-REFERENCES-2026-10-04.md)에서 추가했다. 이 문서의 검수 수치는 첫 곡선 작업 묶음의 기록이다.

사용자 기준은 **기존 CAD의 명령 배치를 복제하는 것보다, 필요한 기능을 편하게 연결해 작업을 끝내는 것**이다. 이번에는 곡선 수정 범위를 넓히고, 결과 선택·정밀 입력·미리보기·다음 동작을 하나의 작업 세션에 연결했다.

## 사용 흐름

Modify → **Curve workflow**에서 시작한다. 선택이 있으면 그 객체를 작업 대상으로 가져오고, 없으면 표시되고 잠기지 않은 일반 곡선을 목록에서 고른다.

1. Offset / Trim / Extend / Fillet / Chamfer / Join을 고른다.
2. 거리·반지름을 `3mm`, `.3cm`, `0.25in` 등으로 입력한다. Trim/Extend는 캔버스에서 대상 구간/끝부분을 고른다. Fillet/Chamfer의 두 번의 클릭은 남길 가지를 결정한다.
3. 녹색 결과와 점선 황색 원본을 함께 검토한다. **Fit workflow preview**는 결과가 아직 없을 때도 작업 대상들을 표시하며 작업대가 곡선을 가리지 않도록 화면을 조정한다.
4. Apply 또는 캔버스 Enter로 검토한 정확한 제안을 한 번 적용한다. 각각 한 Undo이며 Esc는 취소한다. 점을 고르는 중 Esc는 선택 단계만 종료한다.
5. 적용 후에도 작업대가 유지된다. **Join result**, **Offset result**, **Trim/Extend result**, **Repeat on another target**에서 결과와 입력값을 이어받는다. 적용 완료 상태에서 Enter를 눌러도 같은 결과가 복제되지 않는다.
6. 선택된 결과가 지원하는 경우 정점 편집·Split·Dimension·Pattern·Extrude 편집기로 이어갈 수 있다. 예를 들어 `두 선 → Fillet → Join result → Offset result → Pattern result`는 객체를 다시 선택하지 않고 진행한다.

## 이번 확장

- **곡선 다중선 Offset:** 열린/닫힌 선+bulge 호 윤곽을 지원한다. 원호의 반지름과 방향을 보존하며 직선/원·원/원 해석 교점에서 연결한다. 접선 연결도 정확히 유지한다. 반지름 소멸, 뒤집힌 구간, 추가 교차나 닫힌 면적 붕괴는 거부한다.
- **곡선 다중선 Trim/Extend:** 열린 윤곽의 자유 끝부분에 있는 직선 또는 원호를 수정한다. 원호 중심·반지름, 이웃 구간과 안정된 객체/제어점/변 참조를 보존한다. 기존 선·호·원 Trim도 작업대에 연결했다.
- **두 객체 Fillet/Chamfer:** 두 선 또는 열린 다중선의 직선 끝부분을 고른다. 남길 가지를 기준으로 원본을 자르거나 모서리까지 연장하고, 정확한 반지름 호/대칭 거리 모따기 선을 만든다. 두 원본의 ID와 위상을 유지하며 연결체를 같은 레이어와 보조 형상 설정으로 만든다.
- **기존 Offset 경로 정합성:** 기존 캔버스 미리보기와 공개 명령에 같은 거리/방향 어댑터를 사용한다. 곡선 경계 중심이 바뀌어도 회전/스케일 도형이 밀리지 않도록 변환을 보정한다. 음수 스케일·작업면 법선이 뒤집히는 회전과 원의 바깥/안쪽도 검사한다.
- 모든 작업은 기존 공개 명령 → Preview → Apply → 연관 갱신/검증을 사용한다. 미리보기는 문서/이력을 바꾸지 않는다. 치수와 저장된 작도는 같은 제안 안에서 갱신하고, 교점이 사라지는 등 연관 재생성이 실패하면 전체 변경을 거부한다.
- 기존 테스트의 “bulge Offset은 항상 거부” 기대를 “정확한 반지름·중심과 원본 불변” 기준으로 교체했다.
- 새 작업대와 기존 Join/Explode/Break는 현재 검토 제안의 캔버스 경로가 표시된 뒤 Apply를 활성화한다. 표시 이전 적용과 이전 제안의 경로 혼용을 막고, 같은 화면이면 매 프레임 React 상태를 갱신하지 않는다.

## 검수

새 Node 15개: 해석적인 Offset 거리·반지름·방향/접속점, XY/XZ/YZ·높이·측량 좌표·회전/스케일/반전, 자유 끝부분 편집과 위상, 접선/모따기 길이, 단일 Undo/Redo·저장, 치수/작도 연쇄 갱신과 실패 원자성을 검사한다.

새 브라우저 과제 20개: 실제 버튼·단위 입력·마우스 가지 선택, 취소와 중복 Enter 방지, Fillet→Join→Offset→Pattern 인계와 live 인스턴스 생성, 결과 선택/값 유지, 곡선 Trim·단계별 Undo/Redo·재열기를 검사한다. 브라우저 검사는 실제 React/Worker와 네이티브 입력을 사용한다.

전체 검수 결과는 [PROJECT-STATE](../../PROJECT-STATE.md)의 최신 구조 검수 기록을 따른다. 로그는 `tmp/structure-final-node.log`, `tmp/structure-final-browser.log`, `tmp/structure-final-build.log`이다. 캔버스 검토 이미지는 `output/images/cad-curve-offset.png`, `output/images/cad-curve-fillet.png`이다. 관련 계산·명령·도구는 `apps/web/src/features/drawing-editing`에 모았으며 [구조와 의존 규칙](../architecture/DIRECTORY-STRUCTURE.md)을 따른다.

## 지원 경계와 다음 작업

- 닫힌·중간 구간 Trim은 후속 구현으로 제공한다. 지원 범위와 직선 재연결/참조 정책은 위 구현 기록을 따른다. 원은 끝부분이 없어 Extend할 수 없다.
- 두 객체의 원호–선/원호–원호 Fillet, 비대칭 Chamfer와 스케치 코너 처리는 후속이다. 현재 두 객체 코너의 자유 끝 구간은 직선이어야 한다.
- 연결체와 Offset은 적용 당시의 편집 가능한 기하이다. Fillet 반지름의 영구 정의를 바꿔 두 원본을 다시 처리하는 live 피처를 추가한 것은 아니다. 기존의 live 작도·패턴·구속은 그대로 유지한다.
- 후속 관계 통합으로 완료된 같은 소유 스케치의 Trim/Join과 작도·중첩 패턴·치수·live 솔리드 재연결을 지원한다. 파생 작도/패턴 인스턴스의 직접 덮어쓰기와 혼합 sketch bulge·소유권은 계속 거부한다. [최신 참조 정책](CONTOUR-TRIM-REFERENCES-2026-10-04.md)을 따르며 재연결을 조용히 추정하지 않는다.
- 작업 종료까지의 성공률, 대상 재선택·입력 재시도·도구 전환 횟수와 피드백 지연을 다음 기능의 평가 기준으로 삼는다. 자동 브라우저의 기능 성공은 실무자 사용성 평가를 대신하지 않는다.
- 다음에는 **각도/지름 등 치수 편집 → 형상 수정 → 파일 왕복**과 원호 코너·소유 관계의 재연결을 같은 작업 연결 기준으로 확장한다. Component/수학/노드/AI/mesh도 같은 문서·명령·검토 결과를 사용한다.
