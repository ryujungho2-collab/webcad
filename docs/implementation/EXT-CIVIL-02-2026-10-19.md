# EXT-CIVIL-02 외부 주거 도면 2차 개선

2026-10-19. 같은 원본 DWG/PDF와 변환 DXF를 사용했다. 원본 SHA-256은 1차 provenance와 일치한다.

## 구현 결과

- 직선 경계 HATCH의 단색 채움·패턴을 편집 가능한 삼각형·선 블록으로 가져온다. 구멍·중첩 섬·hatch style과 패턴 dash phase를 처리한다. 원본의 61개 중 46개(단색 42, 패턴 4)를 복원했다.
- SOLID 채움을 보존한다. ACI/truecolor, 개체 선종류·선굵기와 ByBlock·ByLayer·블록 내부 layer 0 상속을 화면·SVG·PDF·DXF에서 공유한다. 동일 블록을 다른 색으로 배치해도 각 배치의 표현이 유지된다.
- 가져온 표현 정책은 문서 v48로 저장·재열기한다. 사용자 vector style 편집은 가져온 표현 정책을 명시적으로 대체한다.
- DXF 재출력은 정적 SOLID/선으로 유지하며 native associative HATCH를 재구성하지 않는다.

## 실제 파일 검증

894개 배치 객체, 블록 91개, 문자 98개를 가져왔다. A3 1:150 PDF의 별도 Poppler 렌더를 확인했다. 지붕 채움·벽 해치·가구 색상이 복원됐다. 전체 DXF 재출력/재가져오기에서 제외 0, 채움 85개와 색상별 면적(허용 오차 0.05mm²), 문자 98개의 내용·색상이 유지됐다.

전체 Node 1500/1500, 브라우저 신규 16 및 회귀 116(합계 132), build·TypeScript·architecture 709 modules 통과. 브라우저 검증에는 파일 입력, 분리된 변환/제외 동의, Undo/Redo, 문자 편집, v48 재열기와 Worker PDF 출력이 포함된다.

## 남은 한계

원본 HATCH 중 gradient 11개와 곡선 경계 4개는 명시적으로 제외한다. 해치 연관성·원본 패턴 편집 의미, 고급 동적 블록은 보존하지 않는다. 지원하지 않는 선종류는 제외 진단을 확인해야 한다. DWG는 외부 LibreDWG 변환을 사용하며 무손실을 보증하지 않는다. Chrome 소프트웨어 GPU에서 실제 파일 가져오기는 약 37초였고, 기존 Edge 대형 파일 입력 timeout 문제를 해결했다고 주장하지 않는다.

원본은 [Civil_projects](https://github.com/Abhishekh-Jha/Civil_projects) commit `5bdb0e47140f8bbbc59d630513971cbb11409cbb`다. 원본의 배포 라이선스는 확인되지 않아 로컬 검증 자료로만 사용한다. ACI palette는 ezdxf의 MIT 자료를 사용하며 [라이선스](../licenses/ezdxf-MIT.txt)를 포함했다.
