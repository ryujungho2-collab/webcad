# 기본 CAD의 정점·길이·영역 편집

> 단계 기록: 아래 구현·검수 수치는 해당 시점의 근거다. 최신 지원 범위는 [CAD-BASICS](../product/CAD-BASICS.md), 최근 전체 검수는 [PROJECT-STATE](../../PROJECT-STATE.md), 다음 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)를 따른다.

2026-10-04. 사용자 지적대로 상용 CAD와의 기능 격차는 크다. 이번 구현은
일반 2D 도면을 수정할 때 빠져 있던 정점 구성 편집, 정확한 Lengthen과
영역 Stretch를 채운다. 상용 CAD 호환성이나 실무 품질 전체를 완료했다고
판정하지 않는다. 기능 기준 전체는 [CAD-BASICS.md](../product/CAD-BASICS.md)를 따른다.

## 사용 경로

- Modify → Edit polyline: 일반 다중선/사각형 하나를 선택한다. 선분/정점을
  클릭하거나 번호로 선택해 정점 추가/삭제, 열기/닫기를 검토한다.
  직선에는 새 코너를 넣을 수 있다. 호를 분할하는 정점은 정확한 호 위에 놓인다.
  선분 클릭 후 드래그로 위치를 정하고 U,V 입력으로 마무리할 수 있다.
  `@`는 선택 선분 시작점 기준이다.
- Modify → Lengthen: 열린 선/호/다중선을 선택하고 끝점을 고른다.
  전체 길이, 증감 길이, 기존 전체 길이의 비율을 입력한다. mm/cm/m/in/ft와
  % 입력을 지원한다. 끝점 드래그는 방향/반지름을 유지하며 전체 길이를 바꾸고,
  수치 입력으로 정확한 길이를 지정할 수 있다. 마우스 드래그의 픽셀 해상도와
  수치 입력의 모델 정확도를 구분해 검수한다.
- Modify → Stretch: 사전 선택한 일반 도형을 대상으로 영역을 그린다.
  선택이 없으면 현재 작업면의 보이는 잠금 해제 일반 도형을 사용한다.
  영역 드래그/두 점 클릭 또는 정확한 두 좌표를 받고, 기준점→목표점이나
  dU,dV로 이동량을 정한다. 하이라이트 정점만 이동하며 나머지는 고정한다.
- 공통: 녹색 결과/황색 점선 이전 형상, 영향을 받는 정점, 영역을 캔버스에서
  확인한다. Fit은 편집 패널 밖에 형상과 영역을 배치한다. Apply 또는 Enter는
  검토한 동일 제안을 한 Undo로 반영한다. Esc는 취소하고 캔버스에 포커스를 돌린다.
  문서가 바뀌면 제안을 다시 계산하고 원본이 삭제되면 편집을 막고 이유를 표시한다.
  Ctrl+K 검색과 기존 Enter 명령 반복에도 연결했다.

## 정확도와 연결 계약

| 작업 | 결과와 보존 기준 | 지원 경계 |
| --- | --- | --- |
| 정점 추가 | 직선을 두 직선으로, 호를 같은 원의 두 정확한 호로 분할한다. 기존 객체/정점과 첫 선분 ID를 유지하고 새 정점/선분에 새 ID를 준다. | 호 밖의 삽입 좌표와 기존 끝점 중복은 거부한다. |
| 정점 삭제 | 끝점 삭제 또는 인접 직선 연결, 같은 중심/반지름/방향의 인접 호 합병. 살아남은 참조를 보존한다. | 선·호 혼합 및 서로 다른 원의 호를 임의 직선으로 바꾸지 않고 거부한다. 닫힌 두 호 윤곽으로 복귀할 수 있다. |
| 열기/닫기 | Open은 마지막 닫힘 선분을 제거한다. Close는 마지막→첫 정점의 직선을 추가한다. | 돌출 원본을 열어 재생성이 실패하면 변경 전체를 거부한다. 겹친 끝점은 중복 정점을 정리하도록 안내한다. |
| Lengthen | 월드 mm 기준 길이, 고정 끝점과 직선 방향/호 중심·반지름을 보존한다. 줄이면 여러 정점을 지나 단축할 수 있다. | 열린 선/호/다중선. 전체 원으로 감기는 호, 닫힌 도형, 0 이하 길이와 변경 없음은 거부한다. |
| Stretch | 영역 안 끝점/정점 이동, 전부 포함된 선/다중선의 평행 이동. 원은 중심 포함으로 전체 이동한다. | 같은 표준 작업면·높이. 부분 호는 포함각을 유지하고 반지름은 새 양끝으로 결정한다. 부분 사각형은 닫힌 일반 다중선으로 전환한다. |

모델 명령은 화면 픽셀을 기하 허용오차로 사용하지 않는다. 해석적 선·호와
bulge를 유지하고, 기존 회전/반전/스케일의 좌표계를 보존해 기준점 밀림을 막는다.
XY/XZ/YZ의 높이 있는 반전·회전 도형, 큰 측량 좌표와 비균일 직선 스케일도 검수했다.
원/호의 비균일 평면 스케일은 타원이므로 원형 편집으로 위장하지 않는다.

객체를 교체하는 Join/Explode/Break의 참조 보호와 달리, 새 편집은 객체와 피처를
유지한다. 연결 선형/반지름 치수를 갱신하고 프로파일 솔리드를 재생성한다.
바인딩 충돌, 붕괴한 선분, 열린 돌출 프로파일 등은 모든 관련 객체와 이력을
함께 복원한다. 숨김/잠금 도형, 스케치 소유 도형과 패턴 인스턴스는 기존 소유권
경로를 따라야 한다. 스케치/블록/주석의 영역 Stretch나 구성 참조 재연결은 미지원이다.

## 검수

기본 편집 묶음의 Node **442 tests / 49 suites**, 전체 브라우저 **15과제 / 309 UI·Worker checks**와
production 빌드를 통과했다. 미리보기 서버는 최신 빌드와 같은 HTML/JS를 제공한다.
기존 큰 JS chunk 경고는 남아 있으며 이번 기능 완료와 별개의 로딩 최적화 과제다.

새 Node 회귀 25개와 실제 브라우저 입력 24개는 다음 결과를 확인한다.

- 선을 120mm로 늘릴 때 연결 치수와 같은 ID를 유지하고 전체 Undo/Redo로 복원.
- 드래그 후 정확한 150mm 입력으로 이어지는 Lengthen 작업.
- 반원 정점 추가→삭제에서 같은 반지름·중심·면적·둘레와 참조 유지.
- 정점 추가 후 돌출 원본 유지, 열기 실패 시 프로파일/솔리드/이력 전체 복원.
- 100×60×8 프로파일의 오른쪽 정점만 20mm Stretch하여 정확한 면적 7200mm²,
  BRep 체적 57600mm³를 얻고 Undo/Redo. 실제 영역 드래그→기준점 이동→정확한
  10mm 입력으로 130×60×8과 62400mm³까지 이어짐.
- 선분이 영역을 통과해도 정점이 없으면 이동하지 않음. 완전 포함 선분,
  중심이 포함된 원, 부분 호와 연결 반지름 치수를 따로 검수.
- 새 입력 중 문서 변경/삭제, 실패 원자성, 바인딩·소유권·잠금,
  정확한 직렬화/재열기와 사전 선택 없는 Stretch 시작.

브라우저는 격리된 Edge/SwiftShader와 로컬 개발 서버를 사용한다. 실제 GPU의
대문서 성능이나 실무자의 작업 시간 감소를 입증하는 검수는 아니다.
형상/정점/대상 목록은 입력 또는 문서 변경 때 계산하고 프레임에서는 화면
투영을 갱신한다. 이 구조 개선만으로 성능 수치를 주장하지 않는다.
