# 곡선 손잡이·설치판: 회전축과 스윕 역할의 작업 인계

편심 덕트 다음 과제로 반원형 가구 손잡이, 단차가 있는 발 두 개, 설치판과 설치 핀 두 개를 작성했다. 회전/스윕/폴리라인은 기존 canonical 도구를 사용하며 새 기하 실행기를 만들지 않았다.

## 실제 과제

손잡이는 XY 원 단면 `(−60,0,0), R6`을 작업 평면 y축, 즉 세계 Y축 주위로 180° 회전한 반 토러스다. 중심선 R60, 단면 Ø12이며 위쪽 Z66까지 올라간다. 발은 XZ 단차 윤곽을 같은 local y, 즉 세계 Z축 주위로 360° 회전한다. R12 × 높이4, R8 × 높이8의 발에 아래쪽에서 Ø4 깊이8 막힌 구멍을 가공하고 X±60 / Z−12에 배치한다.

설치판은 160 × 36 × 4, Z−16..−12이며 두 발 중심에 Ø5 구멍을 뚫었다. 설치 핀은 Ø3.6 단면을 Z−16..−4의 12 mm 경로로 스윕하고 아래에 Ø8 × 높이3 머리를 붙였다. 머리 위쪽은 설치판 아래쪽 Z−16에 닿는다. 핀 두 개는 독립 부품으로 유지한다. 나사산·규격 체결부품·강도·인체공학·가공 공차·고정 성능을 검증한 것은 아니다.

사람이 원/폴리라인/회전/Boolean/스윕 폼을 사용했고 내부 자연어 `스윕`으로 같은 입력의 결과도 비교했다. 실제 공식 MCP SDK가 두 번째 발/핀, 구멍, 배치, 설치판, 마감과 연관 단면을 작성했다. 과제 치수와 호출 순서는 에이전트가 제공했으며 모델 API는 호출하지 않았다.

## 발견하고 고친 연결 UX

- `SharedCadToolForm`에 기존 `curve.polyline`, `solid.revolve`, `solid.sweep`를 연결했다. 사람용 폼은 아홉 도구, canonical은 39 / MCP는 42로 유지한다. 폴리라인은 숫자 X,Y,Z 행과 평면·닫힘 여부를 받고 임의 코드를 실행하지 않는다.
- 회전축을 **Plane-local axis**라고 표시하고 선택한 원본 평면으로 세계 방향과 원점을 설명한다. XY local y는 `[0,1,0]`, XZ local y는 `[0,0,1]`이며 둘 다 세계 원점 `[0,0,0]`을 통과한다. 단면 중심을 지나는 임의 축이 아니다. 회전된 객체 등 평면을 확정할 수 없는 경우는 추정 안내를 표시하지 않고 native Review에서 검증한다.
- 스윕 입력에 **Section / Path** 역할과 **Swap section and path**를 제공했다. 버튼은 실제 편집기 선택을 바꾸므로 자연어와 MCP도 같은 순서를 읽는다. 뒤집힌 역할은 공통 planner가 잘못된 path ID와 수정 방법을 알려주며 CAD/Undo를 바꾸지 않는다. 사람 폼과 MCP가 같은 거부를 거친 뒤 역할 교환으로 복구되는지 검증한다. 곡선 스윕 경로의 기존 폴리라인 근사 한계는 유지된다. 손잡이 곡면 자체는 정확한 회전 형상이다.
- `rightFoot` 검색이 앞서 생성한 `rightFootSection`을 먼저 고르는 문제를 실제 작업에서 재현했다. 검색은 앞뒤 공백을 제거하고 정확한 ID → 정확한 이름 → 부분 일치 순서로 후보를 표시한다. 새 검색은 이전 후보 선택을 초기화한다. 후보를 구경하는 것만으로 편집 선택이나 MCP 권한을 주지는 않는다.

## 독립 기하와 실제 간극

| 부재 | 예상 체적 (mm³) |
| --- | --- |
| 반 토러스 손잡이 | 2160π² |
| 막힌 구멍이 있는 발 한 개 | 1056π |
| 핀 축 한 개 | 38.88π |
| 머리를 붙인 핀 한 개 | 86.88π |
| 손잡이+발+설치판 | 23040 + 2062π + 2160π² |

각 부재의 exact volume과 배치 bounds를 실제 native/MCP 측정으로 비교한다. 체적 합만으로 설치 위치가 맞다고 판단하지 않고 **최종 세 부품을 실제로 절단**한다. Z−6에서 각 발/구멍/핀의 동심원 R8, R2, R1.8을 읽어 방사 간극 0.2 mm를 확인한다. Z−14에서는 설치판 구멍 R2.5와 핀 R1.8의 방사 간극 0.7 mm를 확인한다. 이는 명시한 두 절단 위치의 원형 단면 검사이며 전체 충돌·체결 성능 인증이 아니다.

native Undo/Redo와 cache 재열기로 원본 윤곽, 회전축/스윕 입력, 부품 ID, 마감과 연결 단면을 보존하는지 확인한다. STEP와 실제 단면 SVG/DXF를 저장하며 치수·공차를 갖춘 제작도로 부르지 않는다.

## 재현

`apps/web`에서 `node scripts/browserChecks.mjs --page=handleHandoff --artifacts`를 실행한다. 물리 UI 입력과 실제 MCP stdio로 작성하며 문서를 직접 주입해 모델을 만들지 않는다. 산출물은 `output/projects/arched-handle`에 저장한다. 전체 수동 CAD 도구가 MCP에 연결된 것은 아니다.
