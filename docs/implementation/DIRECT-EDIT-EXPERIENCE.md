# 드래그·핸들 편집 경험 검수

> 단계 기록: 아래 구현·검수 수치는 해당 시점의 근거다. 최신 지원 범위는 [CAD-BASICS](../product/CAD-BASICS.md), 최근 전체 검수는 [PROJECT-STATE](../../PROJECT-STATE.md), 다음 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)를 따른다.

2026-10-03. 사용자의 우선순위에 따라 캔버스 치수 편집의 의도·영향 검토를
2D 스케치와 일반 도형의 직접 편집으로 연결했다. 기능 호출 성공보다
선택 → 드래그 → 검토 → 정밀 조정 → 확정/취소 → Undo의 연결을 검수한다.

후속으로 구속에 따른 핸들 이동 안내와 포인터/정밀 입력 제어를 연결했다.
현재 조작, 해석 경계와 검수는
[CONSTRAINT-GUIDED-DRAG.md](CONSTRAINT-GUIDED-DRAG.md)에 기록한다.

## 실제 조작

- Direct에서 선택한 도형의 점에는 사각 핸들, 직선 구간의 중점에는 다이아몬드
  핸들이 유지된다. 표시된 핸들을 반복해서 잡으면 같은 점/변을 편집하며,
  겹치는 대상의 순환 선택으로 인접 변이 대신 잡히지 않는다.
- 드래그 중 요청한 윤곽은 점선으로 먼저 표시한다. 분리된 문서에서 기존
  솔버·커널이 검증한 결과는 현재 윤곽과 구분해 보여준다. 연결된 구멍,
  변수·구속·솔리드 체적의 영향은 치수 편집과 같은 검토 UI를 사용한다.
  계산 중의 요청 윤곽을 검증된 결과로 표시하지 않는다.
- 놓으면 검토를 유지한다. 작업평면의 Target/Delta 좌표를 단위로 조정하고
  Apply 또는 Enter로 화면에서 검토한 동일 제안을 확정한다. 드래그 중에도
  `2cm` 같은 이동 길이와 Enter로 검토 단계에 들어갈 수 있다.
  좌표의 작업평면/원본 기준을 표시하며 XZ/YZ에는 실제 축 이름을 사용한다.
- 일반 도형의 점/구간도 같은 흐름을 사용한다. 회전·스케일된 도형의
  경계 중심이 바뀌어도 원본 좌표계를 보존해 핸들이 목표 위치에 남고,
  변경하지 않은 끝점이 함께 밀리지 않는다. 기존 도형의 높이도 유지한다.
- 검토창은 형상 주변 여유가 큰 캔버스 가장자리에 놓이고, 접기/스크롤로
  도면과 확정 버튼에 접근한다. 스케치 편집기 밖에서 원본을 잡아도
  검증된 원본 윤곽과 종속 영향을 표시한다. 충돌 치수의 Edit는 소유
  스케치와 해당 치수 편집기로 이어진다.

## 구동 치수와 유지할 관계

`Resize through dimensions`는 지원하는 핸들에서 구동 원본을 편집한다.
사각형의 원점을 유지하는 폭/높이 조절과 원의 반지름 핸들이 해당한다.
단일 변수는 그 변수와 전체 연결 값을 변경하고, 변수/바인딩의 복합 식에는
변경량을 더해 기존 의존 관계를 보존한다. 코너의 폭·높이를 함께 바꾸는
경우 바인딩·후속 실체는 최종 값의 조합으로 검증한다. 중간 값만 적용하면
구멍이 경계와 교차하지만 최종 값은 유효한 경우도 원자적으로 적용한다.

`Keep dimensions`는 기존 치수·관계를 유지하는 기하 편집이다. 직접 치수
조절에 해당하지 않는 핸들도 이 의미를 사용한다. 충돌하면 요청 위치와
막는 관계/원본을 강조하며 자동으로 구속을 완화하지 않는다. Edit 또는
Preview release로 해결을 검토한다. 해제할 구속과 소유 바인딩, 원래 편집은
한 트랜잭션이며 Keep all constraints로 해제 제안을 되돌릴 수 있다.

Esc/Cancel, 포인터 취소, 선택 모드 전환, 원본 선택 해제는 문서와 History를
바꾸지 않는다. 나중에 도착한 계산 결과나 mouse-up이 취소를 되돌리지 않는다.
Undo/Redo 등 문서 변경은 캡처와 오래된 예상 형상을 해제하고 Apply를 막는다.
새 드래그를 시작해야 현재 문서 기준으로 다시 검토한다.

## 검수와 재실행

- 새 Node **11개**: 구동 원본·전체 관계 보존, 실제 BRep 체적과 독립 공식,
  원점/안정적인 점·변 ID, 원자적 코너 변경, 식 의존성, 명시적 해제와 소유
  바인딩, XY/XZ/YZ 회전 사각형, 연결 지름, 일반 도형의 높이·변환·정확한
  목표/반대 끝점, 분리된 예상 데이터, 오래된 제안 거절, 완전한 Undo/Redo.
- `directEditExperience` 브라우저 **43개**: 실제 React/Worker와 신뢰된
  브라우저 마우스 입력으로 잡기/이동/놓기, 요청·현재·검증 윤곽의 실제 위치,
  전파된 구멍과 독립 체적, 정밀 단위와 잘못된 입력, 검토 접기, 확정/취소,
  충돌 편집기 전환·해제/유지, 반복 코너 선택, 작은 반지름 변경, 편집기 밖
  원본, 일반 선의 끝점·구간, 키보드 길이/Enter, 0 이동의 중립 상태,
  포인터 취소와 원본 선택 해제. 연결된 폭/높이 바인딩이 이동시키는 실제
  핸들 위치와 좌표 안내 일치, 취소/그래프 복원도 추가했다.
- 기존 거절 드래그 검사는 `Keep dimensions`를 명시해 검사 의도를 유지했다.
  결과·충돌 ID·문서/revision/History 보존 기준은 약화하지 않았다.
- 이동 제어 검수까지 전체 Node **375개**, 11개 브라우저 과제의
  **214개 UI/Worker 검사**,
  워크스페이스 빌드와 `diff --check`로 기존 흐름의 회귀를 확인한다.

```powershell
pnpm --filter @agent-webcad/web test
pnpm --filter @agent-webcad/web test:browser
pnpm --filter @agent-webcad/web test:browser --page=directEditExperience --artifacts
pnpm build
git -c core.safecrlf=false diff --check
```

## 다음 경험 개선과 현재 경계

구속에 맞는 방향/원형 경로/잠김 안내와 이동 제어는 구현했다.
일반 비선형 관계는 국소 접선과 실제 해석 결과를 사용한다.
사각형 왼쪽/아래처럼 원점을 바꾸는 조절은 자동 치수 변경에 포함하지 않는다.

1. **손과 키보드의 반복 작업**. 그립 자체의 키보드 탐색/활성화와 겹친 원본의
   선택 전 형상·관계 확인, 정밀 입력 후 동일 그립 복귀도 구현했다. 후속 검수는
   [CANVAS-TARGET-EXPERIENCE.md](CANVAS-TARGET-EXPERIENCE.md)에 있다.
   반복 작업의 확정 횟수와 작업 시간은 다음 실무 측정이다.
2. **큰 문서의 피드백과 실무 비교**. 요청 윤곽은 즉시, 해석은 입력을 잠시
   묶어서 처리하며 이전 응답을 폐기한다. 대형 스케치의 solver/재생성 지연과
   프레임, 실무자의 재시도·패널 이동·작업 시간을 측정한 결과는 아직 없다.

이번 예상 형상은 원본의 2D 선/곡선이다. 종속 BRep는 실제 재생성·체적을
검토하지만 실체 자체의 전후 3D ghost나 면/엣지 변형 그립은 제공하지 않는다.
기존 CAD와의 실무 경험 동등성/우수성을 입증한 사용성 실험도 아니다.
AI, live Pattern/정의·인스턴스, mesh 편집은 이 CAD 경험을 안정화한 뒤의
제품 확장 순서를 유지한다. 기존 build chunk 크기 경고는 남는다.
