# WF-C0 + WF-A2 → WF-B1

> **현재 기능 설명:** [평면도와 건축 콘텐츠](../features/FLOOR-PLANNING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-16. 지원 범위 구현 완료. 평면도 준비 → 기존 문서 정리 → 선 진단/수리 → 평면 면 → 기존 정확 돌출 → Undo/저장/재열기를 실제 UI로 연결했다.

## 사용하는 경로

- File → **Floor plan tasks…**, Copilot → **Clean / Make face…**, 또는 Ctrl K에서 `PURGE`/`Make face` 검색. 같은 로컬 작업 패널과 `planFloorTask`를 사용한다. 임의 자연어 실행이나 gateway 권한 확대는 하지 않았다.
- DXF 준비: 레이어 검색·Wall/Opening/Reference/Exclude 역할 선택 → 입력 단위 확인 → 미리보기의 기준점 pick/수치 입력 → 선택적 알려진 길이의 양 끝점 pick → Review preparation → Import. 원본 DXF와 기존 문서는 Apply 전까지 바뀌지 않는다.
- 문서 정리: Review PURGE → 삭제될 블록 정의/빈 레이어 이름 확인 → Apply floor task. 숨김/잠금 객체, sketch, scene, sheet, 블록의 중첩 의존성을 포함한 참조는 사용 중이다. 기본/잠긴 레이어는 지우지 않는다.
- 면: Model에서 외곽과 홀의 경계 도면을 함께 선택 → Diagnose / review Make face. 틈·중복·T 접합·비평면/지원 밖 입력을 진단한다. Inspect issue는 좌표 witness를 중심으로 카메라를 맞추며 선택과 문서를 바꾸지 않는다. 닫힌 경계/홀을 색으로 미리 본 뒤 Apply한다.
- 수리는 **Propose gap bridges**를 명시적으로 선택한다. 기본0.1mm, 허용0–10mm. 서로 유일하게 대응하는 열린 끝점 사이에 원본 선/호를 유지한 새 직선만 추가한다. 0.1/1mm 틈 fixture를 검증했다. 수리선과 면이 한 Undo다. 중복 제거/분기 분할/곡률 변경/허용오차 밖 연결/Z flatten은 자동 수행하지 않는다.
- 생성된 면을 선택해 **Extrude selected face…** 또는 기존 Extrude를 사용한다. 홀과 선택 영역이 정확한 OCCT 돌출로 이어지고 원본 변경을 따라 갱신된다. 면의 면적·둘레는 line/arc 원본의 정확 적분으로 계산하며 표시 삼각형 면적으로 대체하지 않는다.

## 데이터와 수명

`FloorTaskIntent`는 request ID·document ID/revision·target IDs·출력 layer·mm tolerance·repair 결정을 고정한다. UI는 document generation도 잡고 `previewCadCommand`/`applyCadPlan`의 기존 세대 검증을 사용한다. 입력/선택/문서 변경 시 이전 계획을 폐기하며, AbortSignal/Escape/Cancel은 publish 전에 중단한다. 적용은 하나의 원자적 문서 명령/History 항목이고 반복 Apply는 기존 plan idempotency를 유지한다. 단위 필드 입력 중에는 기하 계산을 실행하지 않는다.

`purge-unused`는 실행 시 후보를 재계산하여 사용/잠금/누락된 후보를 거부한다. 일반 레이어 삭제(객체를 Default로 옮기는 명령)와 분리되어 실제 사용 중인 레이어를 PURGE로 이동/삭제하지 않는다. 참조 탐색은 보수적으로 전체 문서의 문자열 참조도 보호한다. 같은 이름/ID를 가진 메타데이터 때문에 일부 미사용 항목이 남을 수 있으며, 사용 중 자원을 잘못 지우지 않는 쪽을 택했다. 폰트/재질/외부 DWG 자원 PURGE는 이 범위가 아니다.

DXF root feature의 `floorPlanSource`에는 파일명/tag·원본 index/ID·입력 단위의 mm 배수·원점 offset·선택 레이어/역할·선택적 길이 검산을 저장한다. 단위 미지정은 명시적인 mm 확인 또는 override 없이는 Import하지 못한다. XY 미리보기는 화면 letterbox/Y 방향을 반영하고 10px 안의 표시 끝점에 snap한다. Z는 명시 입력이며 임의 3D 면/기울어진 OCS의 화면 길이를 실제 3D 길이로 주장하지 않는다.

초기 수입 좌표의 역변환은 `(prepared world mm + originMm) / unitMm`이다. 이후 이동/회전/scale은 별도 모델 편집으로 기록되므로 이 식만으로 이후 편집까지 역산하지 않는다. 원본 파일 byte/hash 보관이나 재수입 remap은 아직 별도다. receipt는 최종 참조 잠금 전에 같은 import batch에 기록하며 Undo/휴대 파일/복구 저장에 함께 들어간다.

면은 `drafting/kind:face`의 **analytic planar region**이다. 원본 drawing IDs를 inputs로 유지하고 정확한 line/arc/circle outer/hole profile을 재생성한다. 독립 BRep face나 보편적인 surface modeler로 확대하지 않는다. 면 자체의 transform은 거부하고 원본을 편집한다. 잠긴 CAD 참조는 읽을 수 있으나 별도의 편집 가능한 layer에 면을 생성해야 한다. 폐합이 깨지거나 면/돌출 출력이 잠기면 원본 편집 전체를 rollback한다.

새 면/선택 돌출 영역은 파일 v40을 사용한다. v39 이하로 downgrade하거나 누락된 경계·잘못된 region/receipt·면의 독립 transform을 가진 파일은 거부한다. 이전 문서는 기존 최소 버전을 유지한다.

## 렌더와 출력

- viewport: outer/hole을 같이 triangulate하고 원래 경계선을 그린다. GPU 표현은 근사이지만 원본 원호는 보존한다.
- SVG/공유 PNG·PDF scene: compound `evenodd` path로 홀을 비운다. 표시 곡선 오차 목표는 source mm0.02다. 모델 도면 frame/연속 frame의 변환은 홀에도 적용하고 crop은 기존 SVG clip을 유지한다.
- DXF: 면은 outer/hole 경계 polyline으로 내보내며 fill/association 손실과0.02mm 표시 근사를 경고한다. 프레임 DXF도 홀을 별도 경계로 출력한다. 정확한 면/곡선 원본·연관 관계는 WebCAD JSON에서 유지한다.
- 기존 extrusion에 `profileRegionIds`를 연결해 일부 영역 선택이 재생성 때 전체 영역으로 확대되지 않게 했다.
- 자기교차 검사는 표시 호를 잘게 나눈 모든 선분 쌍 대신 원본 line/circular support 교차를 검사한다. 인접한 호도 공유 꼭짓점 이외에서 교차/겹치면 거부한다.
