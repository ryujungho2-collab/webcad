# CAFE-2F-01 — 2층 카페 2D 과제와 발행·DXF 보완

2026-10-20. 과제 원본과 납품 안내 (local-only, not in repository: `output/projects/large-cafe/README.md`), 현재 출력 계약은 [도면과 출력](../features/DRAWINGS-OUTPUT.md)·[이미지와 장면](../features/IMAGES-SCENES.md)을 따른다. 가상 실측 조건의 실무형 설계 발전안이며 시공 승인·설비 계산 완료나 임의 자연어 자동 설계 완료를 뜻하지 않는다.

## 실제 과제

층별 15×15m, 2개 층의 외곽 면적 합계 450㎡, 40/60석의 카페를 공개 CAD 명령으로 작성했다. 선·호·문자·치수·블록/인스턴스와 원본 참조 프레임으로 평면·천장·마감·입면·단면·바 상세·전원/급배수 협의·수량 키를 12장 발행했다. 종이 구성은 A2 5장과 A3 7장이다. 원본에는 20종 재사용 블록과 그 층별 배치가 들어 있고 에셋만 별도 WebCAD/DXF로 열 수 있다. 새 bitmap을 도면 원본으로 사용하지 않았다.

`cafeSymbols.ts`가 명시 크기·좌석 수와 원본 도형을, `stairLayout.ts`가 plan/section에 쓰는 단높이·단수·디딤판·참 계산을 관리한다. `scripts/largeCafeDesign.ts`는 이 과제의 작성 recipe이며 일반 자연어 생성 엔진이나 자동 건축 설계 solver로 표시하지 않는다. 2D의 평면·입면·단면은 명시적으로 작성되어 후속 변경 시 관련 도면을 대조한다.

## 과제 중 발견하고 고친 제품 문제

1. PDF 합계 픽셀 한도가 단일 PNG surface 한도와 같아서 12장 묶음이 거절됐다. 페이지는 실제로 순차 렌더링하므로 페이지별 16M 한도와 문서 합계 64M 한도를 분리했다. 기존 축당 8192px·32페이지·예상 메모리 256MiB·예상 파일 128MiB 검사는 유지한다. 실제 과제 96dpi는 30,289,482 pixels·232,879,280 bytes의 추정 peak로 통과하고, 150dpi는 사전 진단으로 거절한다. 실측 heap/VRAM 수치로 주장하지 않는다.
2. 모델 DXF의 dimension adapter가 원본 글자 높이를 3.5mm로 바꾸고 객체 배치를 적용하지 않았다. `worldDraftingGeometry`가 dimension의 실제 표시 높이와 이동/회전/축척·평면 축을 처리하게 했고 DXF가 그 공통 결과를 사용한다. XY/XZ/YZ에서 원본 160mm → 2배 배치 320mm와 기대 WCS 위치를 독립 계산으로 비교했다. 모델 공간 DXF의 읽을 수 있는 치수를 보존하며 도면 driver를 바꾸지 않는다.

프레임 잘림·수직 치수 부호·도면 호출부호·가구 간격과 계단/상세 주석의 겹침은 과제 작성에서 수정했다. 테스트 보고서의 대용량 이미지/PDF를 sessionStorage에 넣는 문제는 테스트 artifact 전용 IndexedDB로 옮겼다. 실제 앱 문서 저장과는 구분한다.

## 검증과 증거

신규 과제 테스트는 26×150 계단 레벨, 20개 에셋의 실제 CAD 외곽과 선언 치수, 배치된 세트의 40/60석 집계와 좌석/코어/기둥 비중첩, 특정 창가·계단 전면 이격을 확인한다. PDF 예산·DXF 치수 회귀를 함께 검사했다.

실제 React/Worker 브라우저 13개 검사는 UI의 바 이동·Undo/Redo·원상 복원, 실제 PDF 대화상자의 150dpi 거절/96dpi 12장 발행, 페이지별 Worker render, 원본/History 불변과 실제 cache reload를 다룬다. PDF를 별도 pypdf/Poppler로 다시 읽어 장수·물리 크기·비어 있지 않은 페이지와 source/asset 무결성을 검사하고 12장 및 확대 도면을 육안 확인했다. 최종 수치는 [검증 기록](../verification/CAFE-2F-01-2026-10-20.json)에 둔다.

최종 전체 Node 1540개(54 suites, 실패 0), 실제 브라우저는 신규 13개와 기존 PDF 21개·출력 사전검사 24개·대형 모델 발행 40개, 합계 98개를 통과했다. production build/typecheck·architecture 738모듈·문서 링크 검사도 통과했다. 기존 Vite main chunk 크기 경고는 유지된다.

설계 자체의 남은 협의 항목과 원본/종이 DXF, raster PDF/vector SVG의 차이는 과제 README에 기록한다. 현재 과제를 2D 도면 발행·재편집 기준 사례로 유지하며, 현장 자료·구조/피난/설비 검토와 자동 관계 확대는 별도 완료 조건을 갖는다.
