# 2D 순서 단면 → 편심 전환 덕트

벽걸이 외함 다음 과제는 축이 40 mm 어긋난 원형 전환 덕트다. 기존 기하 기능을 사람용 입력, 내부 자연어와 실제 MCP에 연결하고, 단면 선택 순서를 검증했다.

## 과제

높이 180 mm 구간의 외부 원 단면은 `(0,0,0) R60`, `(20,0,90) R45`, `(40,0,180) R30`이다. 외경은 120 → 60 mm, 내부 통로 지름은 112 → 52 mm다. 같은 중심의 내부 단면 R56/41/26을 로프트해 빼므로 **XY 단면의 방사 방향 두께 4 mm**이며, 경사면 법선 방향 두께가 일정한 셸이라고 주장하지 않는다.

입구 플랜지는 Z−8..0, 바깥 R78 / 안쪽 R56, 볼트 원 반지름 66, Ø8 구멍 네 개다. 출구 플랜지는 중심 X40, Z180..188, 바깥 R48 / 안쪽 R26, 볼트 원 반지름 38, Ø6 구멍 네 개다. 두 플랜지 모두 두께 8 mm다. 규격품·유동/집진 성능·압력 손실·강도·용접·전개·제조 공차를 검증한 과제가 아니다.

## 같은 도구의 작업 인계

1. 사람이 원 입력 폼으로 높이가 다른 native 2D 단면 세 개를 만든다. MCP는 이 원들의 이름만 정리한다.
2. 잘못된 선택 순서에서 시작해 선택 목록의 Up/Down으로 입구 → 중간 → 출구를 정렬한다. 형상이나 Undo 이력은 바뀌지 않고 실제 캔버스 선택 순서가 바뀐다.
3. 내부 자연어 `직선 로프트`와 사람의 로프트 폼을 각각 적용하고 독립 체적을 비교한다. 자연어 결과를 Undo한 뒤 사람 폼으로 작성해 원본 단면과 연결을 보존한다.
4. 실제 MCP SDK가 내부 단면/로프트와 차집합으로 통로를 뚫는다. 사람은 두 원 윤곽을 돌출해 입구 플랜지를 만들고, MCP가 같은 원/돌출 도구로 출구 플랜지를 만든다.
5. MCP가 볼트 구멍을 가공하고 사람이 입구 플랜지를, MCP가 출구 플랜지를 Boolean으로 합친다. 최종 부재의 native 단면 세 개와 STEP/SVG/DXF를 저장한다.

## 연결 개선

`SharedCadToolForm`에 기존 `curve.circle`, `solid.loft`를 연결했다. 별도 기하 실행기나 MCP 도구를 추가하지 않아 canonical 39 / MCP 42는 유지한다. 사람 폼은 이제 여섯 공통 도구를 제공하며, 전체 수동 CAD 기능을 노출한 것은 아니다. 원은 world XYZ 중심과 평면을 명시하고, 로프트는 표시된 단면 순서와 ruled/smooth 연결을 명시한다. 이 과제는 ruled 연결을 검증한다.

`SharedToolTargets`에 다중 선택의 위/아래 이동을 추가했다. 같은 ID 집합도 순서가 바뀌면 이전 MCP context가 유효하지 않다. 미적용 MCP 로프트가 열린 상태에서 순서를 바꾸면 그 receipt가 취소되고 모든 원 단면은 보존된다. 잘못된 순서를 자동으로 추정해 고치는 기능은 아니다.

연관 단면 조각도 원 부품 이름을 포함해 검색 후보가 섞이는 문제를 확인했다. 선택 검색에 **All editable objects / 3D solids / 2D profiles / curves** 필터를 추가했다. native feature representation으로 분류하며 검색/분류는 실제 선택이나 현재 MCP context를 바꾸지 않는다. 최종 부재와 같은 이름의 단면 출력 수십 개를 분리하고, 로프트에서는 원 단면 세 개만 찾아볼 수 있다.

## 독립 기하 기준

중심 오프셋은 단면적 적분에 영향을 주지 않는다. 단면 중심과 반지름이 선형으로 변하는 원뿔대 체적은 `πh(R² + Rr + r²)/3`이다.

| 단계 | 예상 체적 (mm³) |
| --- | --- |
| 외부 로프트 | 378000π |
| 내부를 뺀 덕트 | 61920π |
| 구멍 네 개를 뚫은 입구 플랜지 | 23072π |
| 구멍 네 개를 뚫은 출구 플랜지 | 12736π |
| 최종 합친 부재 | 97728π |

최종 exact bounds는 X−78..88, Y−78..78, Z−8..188이다. 입력/출구 플랜지 중간 높이와 Y0에서 실제 BRep를 절단한다. native 재열기는 단면 순서, 숨긴 원본, Boolean 입력, 마감과 연관 도면을 보존해야 한다. 단면은 제작 치수·공차가 갖춰진 완성 제작도가 아니다.

## 재현

`apps/web`에서 `node scripts/browserChecks.mjs --page=ductHandoff --artifacts`를 실행한다. CAD 작성은 물리 UI 입력과 실제 공식 MCP SDK stdio를 사용한다. 과제 치수와 도구 순서는 에이전트가 작성하며 내부 엔진의 자율 설계를 입증하지 않는다. 모델 API는 호출하지 않는다. 산출물은 `output/projects/eccentric-reducer`에 저장한다.
