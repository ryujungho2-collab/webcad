# 구속에 따른 이동 안내와 드래그 제어

> **현재 기능 설명:** [정밀 작도와 편집](../features/DRAWING-EDITING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

> 단계 기록: 아래 구현·검수 수치는 해당 시점의 근거다. 최신 지원 범위는 [CAD-BASICS](../product/CAD-BASICS.md), 최근 전체 검수는 [PROJECT-STATE](../../PROJECT-STATE.md), 다음 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)를 따른다.

2026-10-03. 선택한 2D 스케치의 핸들/변에서 가능한 이동을 먼저 보여주고,
포인터와 정밀 입력을 그 이동에 맞게 제어한다. 직접 편집의
잡기 → 이동 → 검토 → 정밀 조정 → Apply/취소 → Undo 흐름을 유지한다.

## 조작 경험

- 핸들을 잡는 즉시 해당 핸들의 방향 화살표, 두 방향 이동, 고정 거리의
  원형 경로 또는 잠긴 위치를 표시한다. 스케치 전체 자유도와 구분한다.
- 허용 방향을 벗어난 입력은 노란 요청 위치와 연결선으로 표시하고,
  실제 제어 위치는 초록 마커로 구분한다. 방향/경로는 파란색이다.
  일반 도형에는 스케치 구속을 새로 부여하지 않는다.
- 수평/수직 및 고정 각도에서 방향으로 투영한다. 고정 길이 선과 반지름이
  고정된 호의 끝점은 원형 경로를 따른다. 원의 반지름 핸들은 표시된
  반지름 축으로만 조절하며 중심을 넘어가면 거절한다.
- 반대 점/변과 수정하지 않은 꼭짓점을 유지한다. 선/폴리라인의 변은
  길이와 방향을 유지하며 이동한다. 고정 끝점이 있는 변 이동을 선의
  길이 변경으로 바꾸지 않는다.
- 요청한 Target/Delta 입력과 Allowed 좌표를 함께 표시한다. 같은 변수의
  폭/높이 등 연결된 구동 값이 핸들 위치까지 바꾸면 실제 해석 결과의
  마커와 Verified 좌표를 표시하고 그 이유를 설명한다.
- 확대/축소 시 가이드와 목표가 같은 모델 좌표를 다시 투영한다.
  입력 오류, 취소, 오래된 문서에서는 가이드/예상 결과를 해제한다.
  새 입력에 이전 제안의 Apply가 사용되지 않게 제안과 의도를 연결한다.

## 유지할 관계와 수정 의도

`Resize through dimensions`에서 사각형의 오른쪽/위 변, 원점을 유지하는
코너와 원의 반지름 핸들에 해당하는 구동 치수만 조절 대상으로 분석한다.
`Keep dimensions`에서는 그 치수도 유지한다. 중복 치수는 자동 해제하지
않으므로 같은 핸들이 잠길 수 있다. 모드와 명시적 해제 선택에 따라 안내를
다시 계산한다. 사각형 왼쪽/아래처럼 원점이 바뀌는 조절은 자동 치수 변경에
포함하지 않는다.

완전히 잠긴 핸들은 실제 위치를 유지하면서 기존 명령 경로의 구조화된
충돌 진단을 받는다. Edit와 Preview release로 해결할 수 있다.
해제 제안에서는 치수 참조와 소유 바인딩도 함께 제외해 분석하며, 실제
Apply는 기존 명령으로 해제와 편집을 한 트랜잭션에 적용한다.
자유도가 있지만 입력이 허용 방향에 수직이면 중립적인 No change로
남으며 Apply/History를 만들지 않는다.

## 계산과 검증 경계

선택 원본의 구속 연결 성분과 핸들 조작의 임시 보존 조건으로 야코비안
영공간을 계산한다. 그 공간을 핸들의 평면 좌표에 사상해 0/1/2 방향을
구분한다. 연결되지 않은 자유 형상의 자유도를 섞지 않는다. 큰 좌표에서는
로컬 원점을 사용하고, 호의 각도 열은 물리적 이동량으로 환산해 큰 반지름이
반지름 방향 자유도를 가리지 않게 한다.

알려진 원형 경로는 입력을 그 경로로 투영한다. 일반 비선형 관계는
**국소 접선**이라고 표시하며, 접선 위치를 곧바로 확정하지 않는다.
별도 해석으로 가능 위치를 찾고 조작 의미로 재표현할 수 있는지 검사한다.
수렴/비퇴화 조건을 만족하지 못하면 검토를 막는다. 모든 최종 제안은 기존
엄격한 점/변 명령, 원본 구속, 변수 그래프 및 종속 커널 형상을 다시 검증한다.
임시 조작 조건은 저장된 구속이나 History에 포함되지 않는다.

가이드는 국소 기하 이동을 설명한다. 모든 비선형 연결의 전역 최단 투영,
해 분기 선택이나 종속 솔리드의 유효성까지 미리 보장하는 경로는 아니다.
최종 초록 윤곽과 영향 검토는 실제 Preview 결과이며 Apply는 그 동일 제안이다.
전체 실무 사용성 동등성/우수성과 대형 연결 스케치의 지연은 후속 측정이다.

## 검수

- 새 Node **16개**: 수평/수직/고정 각도, 고정 길이 원형 이동, 잠김,
  무관한 자유 형상 제외, 강체 변/폴리라인, 호/반지름, 구동 치수와 중복
  관계, XY/XZ/YZ 회전 사각형의 실제 Preview/Apply/Undo/Redo, 연결 점의
  전체 이동 전파, 임시 조건 비저장, 큰 좌표·반지름 및 비선형 접선 해석.
- 새 `constrainedDrag` 브라우저 **19개**: 신뢰된 마우스 잡기/대각선 이동,
  실제 마커/예상 윤곽 좌표, 연결 점 전파, 정밀 단위 입력, 네이티브 확대,
  오류 표시 해제, 금지 방향의 No change, 큰 원형 이동, 실제 Apply와 완전한
  Undo/Redo, 잠김, 구속 해제/유지에 따른 즉시 안내 변경, Esc 취소.

- 전체 Node **375개**, 11개 브라우저 과제 **214개 UI/Worker 검사**,
