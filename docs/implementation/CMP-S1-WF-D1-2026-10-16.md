# CMP-S1 콘텐츠 슬롯 → WF-D1 바닥·천장·마감

> **현재 기능 설명:** [평면도와 건축 콘텐츠](../features/FLOOR-PLANNING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-16, 첫 지원 범위 구현. 기존 2D 블록을 3D 객체로 간주하지 않고, 자체 포함 콘텐츠 정의와 인스턴스 공간 슬롯을 추가했다. 실제 명령·공통 작업 UI·정확 기하·렌더·저장/복구·출력을 연결했다.

## 사용

File → Floor plan tasks… 또는 Copilot → Clean / Make face…를 열고 **Content, floors & finishes…**를 펼친다. Ctrl K의 기존 평면도 작업 진입도 같은 패널을 연다. 모델 트리를 선택하려면 패널을 닫고 대상을 선택한 후 다시 연다.

1. 완성된 단일 3D solid, XY drawing, 좌측 정렬/회전 없는 text 또는 내장 image를 선택하고 이름을 입력한 뒤 **Review capture content → Apply**로 라이브러리에 등록한다. 원본은 보존하며 위치는 슬롯 경계 기준으로 정규화한다. 모델 정의는 실제 BRep bounds를 사용한다. 원본은 회전 0/unit scale이어야 하며 원본 translation은 정규화한다.
2. 라이브러리 정의를 고르고 **Explicit space**에 mm 단위 위치·크기·Z 회전, 각 축 padding/minimum을 입력한다. `Contain`은 균등 확대/축소 후 중앙 정렬, `Fill`은 축별 확대/축소, `Natural size`는 원래 크기를 유지하며 공간이 부족하면 거부한다. padding 양측을 뺀 공간이 minimum보다 작아도 거부한다.
3. 벽을 선택하면 **Wall opening** 슬롯에서 기존 문/창을 고를 수 있다. 개구부 폭·현재 벽 두께·개구부 높이가 컨테이너다. 배치된 콘텐츠는 벽 두께·개구부/창턱/레벨·원본 및 호스트 이동/회전을 추종한다. 콘텐츠의 +Y가 opening의 선택된 좌/우 측면을 향하도록 프레임을 배치한다. 슬롯은 별도 Boolean 구멍을 만들지 않는다.
4. 인스턴스를 선택하면 슬롯 편집, **Instance replacement**, **Review reset overrides**, **Review detach content**를 사용할 수 있다. replacement/재질은 그 인스턴스만 바꾼다. reset은 공유 정의로 복귀하면서 현재 슬롯을 유지한다. detach는 현재 평가된 형상·배치를 독립 snapshot으로 보존한다.
5. 공유 정의를 바꾸려면 새 원본을 선택하고 기존 라이브러리 정의와 이름을 고른 뒤 **Review edit shared definition**을 실행한다. 연결된 인스턴스가 함께 바뀌고 다른 정의로 대체된 인스턴스는 보존된다. 참조 중인 정의 삭제는 막는다. definition은 원본을 계속 읽는 live 링크가 아닌 명시적으로 갱신하는 자체 포함 snapshot이다.
6. 방 외곽과 중정/설비 홀 경계를 함께 선택하고 **Floor / ceiling**에서 레벨·두께를 지정한다. 바닥은 상면 레벨에서 아래로, 천장은 하면 레벨에서 위로 돌출한다. 이후 같은 객체의 레벨/두께를 수정하고 원본 경계 변경을 재생성할 수 있다. 레벨은 별도 object placement 전 모델 Z다.
7. **3D finish**는 Concrete/Timber/White plaster/Glass 프리셋이다. 선택한 solid에 적용하거나 새 slab에 적용한다. `set-solid-finish` 명령은 이름·색·roughness·metalness·opacity를 명시할 수 있다. 실제 MeshStandardMaterial에 연결되며 2D vector/단면 표현색과 별개다. 텍스처를 입히는 기능은 아니다.

새 콘텐츠/바닥/천장은 기본적으로 **Architecture fitout** 레이어에 묶인다. 옵션을 끄면 현재 레이어를 사용한다. 최초 레이어 생성과 객체 삽입도 하나의 Review/Undo다. 이 레이어는 작업 세트이며 임의 그룹 계층/Flex 엔진을 의미하지 않는다.

## 모델·문서 계약

- `CadDocument.componentLibrary`에 최대 500개 정의를 저장한다. `ComponentContent`는 인스턴스당 하나의 `space` 또는 `opening` 슬롯, 기본 정의 ID, 대체 정의/재질 override를 가진다. 3D와 2D presentation domain을 섞지 않는다. nested block/definition 참조는 받지 않아 definition cycle을 만들지 않는다.
- 3D는 기존 primitive/extrude/Boolean/fillet/chamfer/revolve/sweep/loft/shell의 자체 포함 기하 snapshot을 재사용한다. placement의 실제 transform과 정확 solid 체적/유효성을 검사한다. 단순 box만을 별도 가짜 모델로 표시하는 구현이 아니다. 한 정의의 원본은 하나의 완성된 solid이며 다중 객체 assembly 캡처는 후속이다.
- XY presentation은 유한 XY bounds를 가진 drawing, 일반 text, 내장 image다. image crop/mask/adjustment·내장 asset을 재사용한다. 이미지 정의가 원본 삭제/교체 이후에도 asset을 소유한다. 마지막 placement/정의 삭제 후 더는 참조하지 않는 이미지 자산만 정리하며 Undo는 복원한다. 파일은 자체 포함이며 외부 링크를 의존하지 않는다.
- 텍스트는 기존 renderer/export의 문자 축 변환을 사용해 슬롯의 scale/rotation이 적용된다. 글꼴 bounds는 기존 CAD 추정치이므로 정밀 typography fitting/줄바꿈/가변 폰트 측정을 보장하지 않는다. 2D 슬롯의 Z size/padding/minimum은 0이다. 비균등 확대가 원/호의 정확 표현을 바꾸는 경우 `Fill`을 거부하고 `Contain`을 안내한다.
- floor/ceiling은 `ArchitecturalSlab` metadata와 live source IDs를 가진 정확 extrusion이다. 기존 analytic line/arc/circle footprint와 holes를 재사용한다. 독립 surface/곡면 천장·경사/임의 UCS 슬래브·BIM room 추론을 추가하지 않았다.
- 콘텐츠 opening link와 slab 원본은 기존 live feature DAG에 들어간다. 호스트/원본·공유 정의 수정으로 잠긴 결과가 바뀌면 전체 변경을 거부한다. 사용 중인 opening을 삭제하면 연결된 콘텐츠 때문에 거부되며 먼저 detach/delete해야 한다. 일반 geometry 편집은 인스턴스의 의미를 우회하지 못하도록 막고 슬롯 편집/detach를 안내한다.
- 라이브러리는 source와 별도 소유권을 가지며 dependency inspector/Copilot query에는 definition 연결을 표시한다. definition 갱신은 모든 적용 인스턴스와 그 downstream 기하를 같은 transaction으로 갱신한다. schema/asset/단위·domain·참조 오류를 거부한다.
- Review는 detached document를 평가하고 3D solid ghost, 전후 체적, 정의/객체 영향 목록을 보여준다. 취소/Escape/패널 닫기는 ghost/계획을 폐기한다. stale revision은 Apply를 거부한다. 저장·프로젝트 교체·Undo/Redo에 라이브러리도 포함된다. 새 의미/재질이 있는 파일은 v42이며 이전 버전으로의 의미 손실 downgrade를 거부한다.

## 이격·출력·비용

`contentClearances`는 다른 가시 객체와의 **world AABB gap/contact/overlap**를 최대 12개 가까운 순서로 표시한다. 문은 폭만큼의 접근/개폐 사각 공간을 추가로 경고한다. 실제 hinge/문짝 sweep나 법정 유효폭은 모델링하지 않았으며, 이 경고는 정확 BRep 거리나 충돌 판정이 아니다. 마우스 hover 정확 측정은 기존 후속 **MEAS-H1** 범위다.

배치 콘텐츠와 slab은 일반 solid이므로 STEP·등록 model part·정투영·실제 단면·시트 경로에 들어간다. 기존 topology/stale/잠금·주석 대응 정책을 유지하며 소실된 참조를 임의 재연결하지 않는다. courtyard floor 단면→시트의 SVG/DXF에서 정확한 홀과 1:100 스케일을 검증했고, 가구 슬롯 이동 후 정투영 갱신도 검사했다. 전체 주거 과제 발행 완료는 다음 **WF-Q1**이다.

재질/평가된 slot metadata는 정확 geometry/measurement cache key에 포함하지 않는다. 실제 형상·중첩 operand·placement 값은 계속 key에 포함하고 측정 반환값을 복제한다. 재질만 바꾸면 source geometry 비교와 연관 도면 대응을 유지한다. 검증 fixture에서 finish-only Review/Apply의 추가 Worker 작업 제출은 **0**이었다. 이 값은 대형 라이브러리/장시간 세션 성능 벤치마크가 아니다.
