# B5-B/C 면 스케치와 돌출 절삭

> **현재 기능 설명:** [솔리드 모델링](../features/SOLID-MODELING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-10. 평면 BRep 면에 붙은 작업면에서 스케치를 작성하고, 그 단면으로 솔리드를 돌출하거나 원본 솔리드를 절삭한다.

## 사용 흐름

솔리드의 평면 면을 선택해 작업면을 만든 뒤 **Sketch on face**로 스케치를 시작한다. 기존 스케치 작도·구속·구동 치수가 작업면 로컬 2D 좌표에서 작동하고, 투영 도형은 면의 world frame에 표시된다. 정확히 하나의 닫힌 비작업용 프로파일을 만든 뒤 **Extrude face sketch**에서 거리를 입력하면 live 돌출을 만든다. **Face cut**에서는 깊이와 **Through all**을 입력하고 **Review face cut**에서 절삭 전후 체적과 영향을 확인한 뒤 **Apply face cut**으로 확정한다. 양의 깊이는 원본 솔리드 내부 방향, 음의 깊이는 반대 방향이다. 실제로 체적을 제거하지 않거나 빈 형상을 만드는 절삭은 거부한다.

절삭은 커터 솔리드를 문서에 만들지 않는다. 원본 솔리드와 스케치 투영 도형을 입력으로 갖는 Boolean 결과 하나를 생성하고 원본은 숨긴다. 숨겨진 원본은 트리에 남겨 면 키가 소멸했을 때 다시 표시·선택해 작업면을 명시적으로 재연결할 수 있다. Review는 문서를 바꾸지 않으며 Apply가 단일 History 항목을 만든다.

## 재생성·저장

원본 솔리드의 이동·회전은 면 frame의 원점과 X/Y 축에 적용된다. 면 스케치 투영, 구동 치수, 돌출과 절삭은 같은 트랜잭션에서 재생성된다. 절삭 대상 또는 프로파일이 변경되어 체적 제거가 사라지면 편집 전체를 거부한다. 저장 형식 v19는 스케치의 `facePlaneId`, 마지막 해석 `faceFrame`, `faceStatus`를 보존한다. 절삭은 `boolean` feature의 `faceCut` 정의 및 source/프로파일 입력으로 저장되어 재로드·STEP 내보내기에서 같은 솔리드를 사용한다.

원본 형상 수정으로 정확한 면 키가 사라지면 `missing`으로 표시하고 마지막 형상을 검토용으로 보존한다. 다른 면에 자동 연결하지 않는다. 이 상태의 face extrusion/cut은 STEP/STL 내보내기를 거부한다. 원본을 트리에서 다시 표시하고 의도한 새 면을 선택해 **Rebind**한 뒤 숨기면 재생성이 다시 시작된다.

## 지원 경계

현재 솔리드 프로파일은 하나의 닫힌 선/직사각형/다중선 루프 또는 원 하나다. 다중 영역·홀은 제외한다. 면 스케치는 Offset/Trim/Extend, 자유 grip/stretch와 자유 회전을 제공하지 않는다. 별도 원통형 Hole은 [B5-D](B5-D-FACE-HOLE-2026-10-10.md)에서 구현했다. Shell·명명된 UCS 전환은 B5-E·X5에 남는다. 작업면은 평면 BRep 면만 지원하며 토폴로지 키 변화는 수동 재연결이 필요하다.
