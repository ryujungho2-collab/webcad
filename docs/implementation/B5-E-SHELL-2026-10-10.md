# B5-E 면 제거와 두께 지정 Shell

> **현재 기능 설명:** [솔리드 모델링](../features/SOLID-MODELING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-10. BRep 솔리드에서 지정한 면을 제거하고 안쪽으로 일정 두께를 남기는 Shell을 구현했다.

## 사용자 흐름

솔리드를 선택한 뒤 Inspector의 **Shell**에서 제거할 면을 체크하고 **Thickness**에 길이를 입력한다. 뷰포트에서 선택한 원본 BRep 면도 제거할 면으로 사용할 수 있다. 면 목록의 설명에는 원본 좌표계 중심(mm)이 표시된다. **Review Shell**은 정확한 체적과 변경 객체를 계산하며 문서는 변경하지 않는다. **Apply Shell**은 원본을 숨기고 live Shell 결과를 한 History 항목으로 만든다. 입력을 바꾸면 이전 검토는 취소된다.

결과를 선택하면 **Edit Shell**에서 두께와 제거할 원본 면을 수정한다. **Result** 선택기로 편집할 Shell을 고정한 상태에서 원본을 표시·선택할 수도 있다. 원본 치수 변경으로 저장된 면 키가 사라지면 `missing`을 표시하고 마지막 형상을 보존한다. 현재 원본의 의도한 면을 다시 체크해 Review→Apply 하면 명시적으로 재연결한다. 원본 형상 변경 후에도 면 키가 정확히 유지되면 같은 두께로 자동 재생성한다. 원본 이동·회전은 항상 live 결과의 배치를 갱신한다.

## 형상·저장·출력 계약

새 `shell` feature는 `thickness`, `faceKeys`, 원본 operand, `referenceStatus`, bounds와 live source input을 보존한다. 커널은 원본 형상의 좌표계에서 정확히 하나로 해석되는 면 키만 사용하고, `MakeThickSolidByJoin`의 음수 offset과 intersection join으로 안쪽 벽을 만든다. 원본 배치 변환은 Shell 생성 뒤 한 번 적용한다. 두께는 0.000001 mm보다 커야 하며, 중복·소멸·모호한 면과 모든 면 제거를 거부한다. 결과가 정확히 하나의 solid이고 BRep validity가 valid이며 양의 체적을 실제로 제거해야 적용한다. 불가능한 두께·유효하지 않은 offset은 객체·가시성·History를 변경하지 않는다.

렌더링, 면/엣지 선택, 작업면 연결, 정확 측정, 선택 bounds, Boolean/Fillet/Chamfer 입력과 live 종속 재생성, STL/STEP이 Shell 경로를 사용한다. unresolved Shell과 그 종속 결과의 STL/STEP은 명시적인 재연결 전까지 거부한다. 문서는 v21으로 저장하고 이전 버전으로 위장한 Shell 파일은 읽지 않는다. 독립 복제는 source snapshot을 보존하며 원본 수정의 영향을 받지 않는다. 복제의 과거 Shell 정의를 편집하는 대신 복제 형상에서 새로운 Shell을 만들 수 있다.

## 검증과 지원 경계

상자 20×16×10 mm, 상면 제거, 두께 2 mm의 기대 체적은 `3200 − 16×12×8 = 1664 mm³`, 면적은 `320+720+128+192+448 = 1808 mm²`다. 원통 R10×H20 mm에서는 체적 `848π mm³`, 면적 `888π mm²`를 독립 수식과 비교한다. 복수 면 제거, 종속 Boolean 갱신, 과도한 두께 거부, stale review, 면 소멸/재지정, 독립 복제, Undo/Redo·v21·실제 STEP·STL을 Node에서 검증했다. 실제 브라우저에서는 생성·두께 수정·검토 취소·Undo/Redo와 원본 치수 변경 후 면 재지정을 검수했다. [마감 증거](../verification/B5-E-CLOSEOUT-2026-10-10.json)를 따른다.

이번 범위는 면을 하나 이상 제거하는 inward Shell과 단일 결과 solid다. 닫힌 중공체(제거 면 없음), outward/양방향 두께, 면별 가변 두께, scaled source는 지원하지 않는다. 복잡한 오목 형상이나 자기 교차 offset을 자동 보정하지 않으며 커널이 유효한 단일 solid를 만들지 못하면 거부한다. 전체 가능한 BRep 형상에 대한 offset 성공을 보장하지 않는다.
