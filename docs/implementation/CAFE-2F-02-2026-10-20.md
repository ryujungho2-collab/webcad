# CAFE-2F-02 / R0 평면 → 3D CAD·모델링

사용자 요청: 공간 배치 재설계는 미루고, 완성한 2층 카페 도면을 3D CAD와 3D 모델링 양쪽 의미로 구현한다.

## 결과

R0의 15m × 15m × 2개 층, 40/60석을 유지했다. 벽·기둥·창호·문·두 계단·바닥 개구부·가구·바·장비·위생기구·조명을 1,114개 편집 가능한 BRep 솔리드로 생성했다. 원래 2D 문서와 20종 블록·12장 도면도 보존했다. 정확한 STEP, 재료 포함 GLB, 오프라인 3D 뷰어와 원본을 납품 폴더 (local-only, not in repository: `output/projects/large-cafe/3d/README.md`)에 작성했다.

2층 평면의 X22000 배치 오프셋을 제거해 Z3900에 맞춘다. 원본 벽의 live extrusion과 두 계단·승강기 홀을 가진 slab profile을 유지한다. 가구·창호 해석은 2D source ID에 대응하는 snapshot recipe다. 치수나 역할이 주어지지 않은 도면을 일반적으로 해석하는 자동 설계/BIM 기능은 아니다.

모델에서 X12500의 A–A 단면을 실제 BRep 교차선 80개로 생성했다. 건축 부재 19개를 자르는 저장된 live section과 SVG/DXF를 제공한다. 화면 단면 클리핑과 구분한다.

## 구현

- `src/architecture/planModel.ts`: 역할/층 기준의 명시적 변환, 원본 닫힌 XY 윤곽 검사, block 배치·회전, 중복 ID 거부, 원본 대응 receipt와 공개 CAD 명령 생성.
- `src/library/cafeModelAssets.ts`: 원래 20종 2D 에셋에 대응하는 치수/재료/부품 레시피. 형상은 primitive BRep다. 가구 높이와 제조사 미지정 장비는 모델링 가정이다.
- `scripts/largeCafeModelDesign.ts`, `largeCafe3d.ts`, `finishCafe3d.ts`: R0 역할·레벨 적용, 벽 live source와 바닥 개구부, 단일 batch Undo, 4개 저장 시점, 층 분리 보기, STEP/GLB와 CAD 단면·원본 출력.
- `src/state/appendOnlyModelBatch.ts`: 새 ID/레이어의 독립 모델 생성에 한해 batch 끝에서 재생성한다. 기존 형상 편집과 생성 후 소비된 프로파일 이동은 기존 순차 재생성으로 돌린다. 외부 원본은 읽기만 하며 전체 batch rollback/최종 유효성 검사를 유지한다.
- `src/export/glbExport.ts`, `glbWriter.ts`: 기존 솔리드 exporter와 같은 커널 메시/가시성·면 참조 검사. 비동기 실행 전에 문서 snapshot을 캡처한다. 형상·재료 공유, PBR, CAD ID, 표준 m/Y-up 변환, 조립 좌표를 지원한다.
- File의 Export GLB, View의 Material view/CAD edge view를 연결했다. 표시 전환은 문서/Undo를 변경하지 않는다.
- `scripts/buildCafeViewer.ts`, `cafeModelViewer.ts`: GLB와 Three.js를 자체 포함하는 HTML. 회전/선택/CAD ID, 전체/층별/분리/외피/지붕/천장/모서리/수평 단면/내부 시점/PNG를 지원한다.
- 소스 구조 검사의 파일 해석에 Vite의 실제 파일 `?raw`/`?url` 쿼리를 반영했다. 파일 존재 여부와 의존성 경계 검사는 유지한다.

## 검증

[검증 manifest](../verification/CAFE-2F-02-2026-10-20.json)를 따른다. 전체 Node 1546개/54 suites, 신규 실제 브라우저 14개, build/typecheck와 architecture 746 modules를 통과했다.

STEP 재수입에서 1,114개 솔리드/valid, 외곽 `[0,-700,-250]`~`[15000,15000,7800]`mm다. Y-700은 원본의 외부로 열린 900mm 입구 문짝이며 pivot Y200을 따른다. 독립 primitive/다각형 해석 체적과 STEP 체적 차이는 0.00330mm³다. GLTFLoader로 GLB 전체 1,114개 node를 열고 143개 공유 mesh, 12종 재료를 확인했다.

브라우저에서 실제 Worker 모델 로딩, 높이 검토/Apply, Undo/Redo, 캐시 복원, File→GLB 다운로드, 재료 표시 전환, GLB 파싱과 층별·층 분리·화면 단면을 검증했다. 최종 PNG로 native CAD와 분리·층별·내부 화면을 확인했다.

## 남는 범위

배치와 동선의 설계 품질을 개선하지 않는다. 재료는 단색 PBR이며 목재 텍스처·실측 광원/조도·사실 렌더링이 아니다. 가구 조합 전체의 live 2D↔3D 양방향 편집, 제조사 모델, 전체 MEP/충돌 해소, 구조·시공 승인 검토는 미완료다. 큰 조립체 STEP export는 시간이 걸릴 수 있다.
