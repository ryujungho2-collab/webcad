# B3-A3 DXF OCS·기울어진 평면 교환

> **현재 기능 설명:** [정밀 작도와 편집](../features/DRAWING-EDITING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-10. 비기본 extrusion normal의 원·원호·bulge 다중선을 해석 기하로 가져오고, 실제 3D 배치를 OCS DXF로 내보낸다. 사용자 UCS 편집기는 추가하지 않는다.

## 지원과 좌표 계약

CIRCLE·ARC·LWPOLYLINE·2D R12 POLYLINE의 210/220/230 normal을 정규화하고 Autodesk arbitrary axis algorithm으로 직교 OCS를 계산한다. OCS의 원점은 WCS 원점이며 원/원호 center Z, LWPOLYLINE 38 elevation과 2D POLYLINE elevation을 normal 방향으로 변환한다. 좌표·반지름·elevation은 입력 단위에서 mm로 변환하고 normal은 단위 변환하지 않는다. ARC의 350°→10°는 20° CCW sweep이며 -Z extrusion도 정확히 보존한다.

LINE 좌표와 3D POLYLINE 좌표는 WCS로 해석한다. 기울어진 선과 평면 3D 다중선은 직교 local XY 좌표와 기존 rotation/translation으로 복원한다. 비평면 3D 다중선은 입력에서 명시적으로 제외한다. 큰 좌표에서도 모델 선형 정밀도와 좌표 roundoff를 사용해 평면 여부를 판정한다.

원본 도형은 기존 analytic center/radius/angles/vertices/bulges를 유지한다. 기존 drawing pivot에 맞춰 rotation과 translation을 보정하며 새로운 명령이나 파일 버전은 필요하지 않다. Layers→Create→Placement가 한 transaction/Undo로 게시된다. 잠금·실패·stale Review는 전체 게시를 막고 Cancel은 원본을 바꾸지 않는다. 기존 JSON 저장·재열기도 배치를 보존한다.

내보내기는 실제 model controls와 drawing transform에서 normal/OCS 좌표를 계산한다. XY/XZ/YZ·임의 rotation·균일 in-plane scale·반사를 포함한다. 원/원호는 CIRCLE/ARC, 다중선은 elevation과 signed bulge가 있는 LWPOLYLINE이며 renderer facet으로 대체하지 않는다. ARC는 normal을 선택하여 DXF CCW 규칙과 원본 끝점 순서를 함께 보존한다. 직선 비평면 다중선의 기존 WCS 3D POLYLINE 출력 경로는 유지한다.

## Review와 사용

File → Import DXF에서 단위·제외 항목과 oriented drawing 수를 확인한다. 미리보기는 각 도형의 authoring plane에서 곡선을 보여주며, Apply 뒤에는 실제 3D 위치를 사용한다는 안내를 표시한다. 3D 뷰에서 기울어진 배치를 확인할 수 있다. 기존 2D 곡선 편집 도구는 정렬된 작업면을 요구하므로 임의 평면의 편집은 UCS/작업면 후속이다. Export DXF의 Download reviewed DXF는 같은 Review/제외 수락 계약을 사용한다.

## 명시적 지원 경계

- TEXT·INSERT 비기본 OCS는 제외한다. 주석 adapter와 기울어진 component placement는 별도 후속이다. 기본 OCS TEXT·기존 XY BLOCK/INSERT는 기존 범위를 유지한다.
- 0이 아닌 thickness, polyline width, mesh/fitted/spline, 비균일 scale의 원/원호/bulge와 ellipse 교환은 확대하지 않는다. 잘못된 normal·비유한 수치는 명시적 제외다.
- full-circle ARC는 CIRCLE로 표현해야 한다. 비평면 3D 다중선 입력·중첩 INSERT·DWG·사용자 UCS는 별도 지원 단계다.
- 치수/해치는 기존 선/문자 부분집합으로 출력한다. XZ/YZ 또는 기울어진 TEXT 출력은 annotation adapter 필요 안내와 함께 제외한다. JSON의 연관 관계는 유지한다.
