# I-UX1 이미지 배치 경험 개선

2026-10-18 구현.

- 이미지 선택 문맥에서 이미지 배치 속성을 열고 원본 교체 버튼으로 포커스를 이동한다. 잠긴 이미지도 속성 열기는 가능하고 변경은 차단한다.
- 원본 이름·미리보기, 기존 교체 비교, 정확한 크기·비율 잠금, 캔버스/수치 자르기를 같은 패널에서 제공한다.
- Fit source는 너비를 유지하고 원본 비율과 전체 crop을 복원한다. Fill frame은 현재 프레임 크기에 맞춰 중앙 crop을 계산한다. Reset crop은 프레임 크기를 유지하며 전체 원본을 표시한다.
- 투명도 수치 입력과 키보드 조작 가능한 슬라이더를 동기화한다.
- 앞/뒤 한 단계 및 맨 앞/맨 뒤 순서를 같은 작업 평면의 이미지 사이에서 변경한다. 벡터와 다른 객체의 root 슬롯은 유지한다. 화면은 문서 순서에 따라 이미지 renderOrder를 갱신하고 출력은 저장된 root 순서를 따른다.
- 교체·크기·crop·투명도·순서를 검토 후 한 번의 Apply/Undo 트랜잭션으로 처리한다. 순서 경계, 잠김, 숨김, 잘못된 입력은 거부한다. Cancel은 저장된 배치를 유지한다. 원본 픽셀은 변경하지 않는다.

범위: 맞춤은 선택 이미지의 현재 프레임 안에서 수행한다. 아트보드 자동 이동/맞춤은 포함하지 않는다. 크기와 순서의 최종 화면 반영은 Apply 시점이며 crop·색상·투명도·교체 원본은 기존 캔버스 미리보기를 사용한다.

검증: 이미지 명령·교체·선택 문맥 Node 테스트 20개, imageWorkflow 네이티브 입력 브라우저 47개, imageSourceWorkflow 16개, artboardPngWorkflow 25개. 전체 빌드 및 655개 모듈 아키텍처 검사 통과. SVG 및 PNG 출력, 저장/재열기, 원본 공유, Undo/Redo를 확인했다. PDF 별도 재검증은 이번 변경에서 수행하지 않았다.
