# B4 호를 포함한 스케치 관계

> **현재 기능 설명:** [정밀 작도와 편집](../features/DRAWING-EDITING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-10. `B4-A–D`의 현재 지원 대상은 스케치 원호·원·직선과 스케치 점이다.

## 사용자 동작

- 점과 호를 선택하고 점 핸들을 지정한 뒤 **Point on arc**를 적용한다. 반지름뿐 아니라 호의 시작·끝 각도 사이에 점을 둔다. 반시계/시계 방향과 0° 경계 통과를 처리하고 양 끝점을 포함한다. 구속된 자유점의 직접 드래그는 호 궤도를 따라가며 범위를 벗어나면 가까운 끝점에 멈춘다.
- 선과 호를 선택하면 **Tangent**, 이미 근접한 접점이면 **Review suggested tangent**가 나타난다. 선의 방향으로 지정된 측면을 보존하며 접점이 유한 선분과 실제 호 구간에 모두 있어야 한다. 원과 선의 기존 무한원 관계는 유지한다.
- 호–호 또는 호–원을 선택하면 내접/외접을 각각 검토할 수 있다. 중심 거리만 맞고 접점이 호 밖이면 충돌로 거부한다. 일치 중심·동일 반지름 내접처럼 접점이 사라지는 경우도 거부한다.
- 후보 버튼은 임시 미리보기만 연다. **Apply constraint**를 눌러야 영구 관계와 한 단계 Undo가 만들어진다. 취소·Escape는 원본 도면과 History를 바꾸지 않는다. 충돌 미리보기는 적용할 수 없다.

## 계산·문서 계약

`sketchArcRelations.ts`가 방향 있는 호의 각도 범위와 실제 접점을 계산한다. solver residual은 점-호에 반지름/범위 두 조건, 선-호에 측면 거리/선분/호 범위 세 조건, 호 포함 곡선 쌍에 중심 거리/두 곡선 범위 세 조건을 사용한다. 접점 범위가 불가능하면 전체 편집을 원자적으로 거부한다. 관계 주석은 접점에 표시한다.

새 `point-on-arc`와 원호가 참여한 접선 관계가 있으면 저장 파일은 v17이다. 구버전 파일과 원/원·선/원 관계의 기존 최소 버전은 유지한다. v16 이하에 새 관계를 억지로 넣은 파일은 열지 않는다. 스케치 투영·live 종속 형상 재생성, 미리보기·Undo/Redo·파일 재열기는 기존 문서 명령 경로를 사용한다.

지원 경계: 호는 0 또는 360° 전체 sweep이 아닌 유한 원호여야 한다. 타원/스플라인, 접점 위치를 별도 파라미터로 잠그는 구속, 자동 작도 중 영구 구속 삽입은 이 카드에 포함하지 않는다. 후보는 선택된 가까운 두 대상에서 계산하며 영구 적용은 항상 명시적이다.
