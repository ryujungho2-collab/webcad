# COPILOT-NATIVE-ARCHITECTURE-01 — 기능을 사용한 작은 공간 검증

사용자의 “기능부터 다시 배워(개선해)” 요청에 따라 기존 CAD 기능을 다시 조사하고 코파일럿에서 실제 부재로 생성·수정·검증하는 경로를 연결했다. 앞선 도시수리학교의 졸업설계 수준 판정은 **미달**로 유지한다. 이 결과는 작은 기능 과제이며 설계·미적 완성의 증명이 아니다.

## 문제와 기존 기능 확인

이전 과제는 프로그램을 색칠한 구역과 선으로 표현하는 데 치우쳤다. 벽체, 호스트 개구부, 바닥, 실제 단면을 갖춘 건축 모델을 충분히 사용하지 않았다. 먼저 아래 구현과 관련 테스트를 읽고 기존 지원 범위를 확인했다.

| 기존 CAD 기능 | 기존 구현 | 이번 연결 |
| --- | --- | --- |
| 원본 중심선/외곽에 연결된 벽과 관통 문·창 | `architectureWall.ts`, `architectureWallCommands.ts` | 코파일럿의 native 벽 생성·치수 수정·개구부 편집 |
| 외곽 및 홀에 연결된 바닥·천장 | `ArchitectureContent.ts`, architectural slab commands | 선택 윤곽으로 부재 생성, 레벨·두께 명시 |
| 실제 BRep 교차로 만드는 평면·단면 | native model section commands | 선택 부재의 절단과 관련 도면의 명시적 재연결 |
| 미게시 검토, 전체 실패 거절, 단일 Undo | `previewCadCommand → applyCadPlan` | 새 쓰기 도구도 동일한 실행 경로 사용 |

없는 핵심 CAD 기능을 새로 만든 것으로 설명하지 않는다. 이번 핵심 개선은 기존 기능을 공통 도구·내부 문법·사용자 진입점으로 연결한 것이다.

## 추가한 기능

공통 카탈로그를 29개에서 **37개**로 확대했다. `cad.architecture`, `cad.pathClearance`, `wall.create`, `wall.opening`, `wall.update`, `slab.create`, `drawing.section`, `drawing.refresh`를 추가했다. 도구 schema, 로컬 문법, 선택·잠금 검사, native 미리보기/게시를 함께 사용한다. 기존 부재는 조회만으로 편집 권한을 얻지 않으며 선택된 독립 원본이어야 한다. 불가능한 개구부나 잠긴 관련 출력은 전체 변경을 거절한다.

내부 모드의 **Native architecture**는 지원 명령을 편집 입력란에 준비한다. 버튼만 눌러 도면을 게시하지 않는다. **Plan → Review → Apply** 후에 적용한다. 벽의 원본 중심선은 숨겨 보존하며 개구부는 실제 벽 두께를 관통한다. 기존 벽 ID·개구부 ID를 유지하며 관련 도면 재연결을 같은 Undo에 포함할 수 있다.

**Wall path clearance**는 명시한 XY 경로를 원형 몸체가 따라갈 때 직선·수직·단위 축척 native 벽과 문을 통과할 여유가 있는지 내부에서 조회한다. 실제 벽/문의 정의를 사용한 유한 선분과 점유 사각형 사이의 2D 거리 계산이다. body 높이 전체를 통과시키는 문만 벽 구간에서 제외한다. 창은 보행 개구부로 취급하지 않는다. 기본 범위는 표시된 native 벽 전체이며 한 번에 10개를 넘으면 명시적으로 나눠 검사한다. 문서·선택·경로·치수가 바뀌면 이전 결과를 폐기한다.

이 검사는 전체 BRep 충돌 검사나 자동 경로 탐색이 아니다. 가구·문짝 회전·계단·바닥·범위 밖 객체는 검사하지 않으며 피난/접근성 인증도 아니다. 기울거나 축척된 벽 및 임의 외곽 벽은 근사해 통과시키지 않고 미지원을 표시한다.

## 실제 과제와 검증

[native 원본 및 산출물 안내](../../output/projects/native-architecture-lesson/README.md). 6 × 4m 규모 공간에 외벽 4개, 내부 벽 1개, 현관문·실내문·창, 바닥을 만들었다. 이어 여섯 부재의 실제 XY 평면 절단과 XZ 단면을 생성했다. 설계 과제로 포장하지 않고 부재 연결을 확인할 수 있는 연습 모델로 사용한다.

문 폭 900→1200mm 수정은 벽과 두 절단 도면을 동시에 바꾸며 한 Undo/Redo로 원복한다. 실제 벽 체적과 평면 절단 결과 변화를 검사했다. 별도 실내문을 500mm로 좁히면 같은 지름 600mm 몸체 경로가 막히고, Undo 뒤 재검사하면 여유가 복원된다. 문 없는 벽 구간을 가로지르는 경로는 가까운 곳에 문이 있어도 막힌다. native 파일을 실제 재열어 호스트 관계·도면의 resolved 상태·체적을 다시 확인했다. STEP과 편집 가능한 DXF/SVG도 실제 모델·절단 결과에서 내보냈다.

- 전체 Node 검사: **1592개 / 54 suites / 실패 0**.
- 추가 단위 검사: **9개 통과**. 경계·홀·문 높이·잠금·회전/역방향 벽·레벨·원본 유지·Undo 포함.
- 신규 실제 UI/Worker 검사: **29개 통과**, 모델 요청 **0회**.
- 기존 코파일럿 회귀: **70개 통과** (내부 29, 대안 비교 26, 후속 대화 15).
- 최종 build/typecheck와 architecture **777모듈** 및 문서 링크 검사 통과. 실행 명령과 로그는 [검증 manifest](../verification/COPILOT-NATIVE-ARCHITECTURE-01-2026-10-23.json)에 기록했다.

## 남은 범위

벽 생성 shortcut은 XY 직선 중심선과 butt 끝단을 사용한다. 벽 모서리 자동 접합, 곡선 벽, 실/층 관계의 자동 구성, 계단/피난 판단, 자유로운 문장 해석, 건축적 배치와 미적 판단은 이번 완료 범위가 아니다. 외부·로컬 모델은 여전히 선택 기능이며 이번 실행에는 필요하지 않았다. 다음 규모 확대는 기존 도구로 실제 부재와 수정 관계를 설명할 수 있는 과제로 평가해야 한다.
