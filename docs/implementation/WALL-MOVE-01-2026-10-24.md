# WALL-MOVE-01 · 벽체 상대 이동

2026-10-24. 기존 `move-object`와 `refresh-wall-drawings`를 조합하여 벽 전용 상대 이동 검토를 추가했다. 일반 객체 이동 명령의 의미나 직렬화 형식은 변경하지 않았다.

## 사용자 흐름

벽 하나 선택 → File / Floor plan tasks… → Walls & openings → **벽체 이동** → 방향·거리 → **Review wall move** → **Apply wall review**.

- 월드 X/Y/Z와 벽 길이/직각 방향을 구분한다. 직각 양수는 원본 시작→끝 기준 왼쪽이다.
- 벽 기준 방향은 실제 원본 선/직사각형 footprint와 호스트 회전을 반영한다. 일반 footprint에서 방향을 정할 수 없으면 월드 축을 지정해야 한다.
- 거리를 현재 translation에 더한다. 음수와 mm/cm/m를 지원한다. 0, 비유한 수, 범위 초과를 거부한다.
- 문·창문은 호스트의 일부로 함께 이동한다. 길이·두께·마이터·개구부 ID/상대 위치는 유지한다.
- 미리보기는 detached 실제 solid ghost다. 입력 변경·취소·문맥 변경은 검토를 무효화한다.
- 도면 재연결 체크가 켜져 있으면 벽 배치와 연관 단면/정투영 갱신을 한 transaction/Undo에 묶는다. 잠긴 영향 도면은 전체 변경을 거부한다.
- 원본 참조선/윤곽은 유지한다. 하나의 참조선을 공유하는 다른 벽을 뜻하지 않게 움직이지 않는다. 인접 벽 자동 연장·코너 접합 조정은 지원하지 않는다.

내부 자연어도 같은 `wallMovePlan`을 사용한다:

```text
선택한 벽 Y 300mm 이동
선택한 벽 직각 방향 -30cm 이동
선택한 벽 왼쪽으로 0.3m 이동
선택한 벽 오른쪽으로 300mm 이동
선택한 벽 길이 100mm 이동
```

추가 조건을 포함하거나 여러 객체가 선택된 요청은 거부한다. 선택한 native 벽 하나의 이동이며 기존 모델 gateway/MCP 도구 스키마는 바꾸지 않았다.

- `wallMove.test.ts`, `architectureWall.test.ts`, `architecturalCopilot.test.ts`: **20/20 통과**.
- 회전 호스트/회전 원본의 방향, 누적 이동, 문·창/체적/공유 원본 보존, Undo/Redo, 저장 왕복, 잠금/오래된 검토 거부를 확인했다.
