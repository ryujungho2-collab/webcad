# 졸업설계 수준의 과제로 내부 코파일럿 검증

2026-10-23. 사용자는 “코파일럿을 이용해서 고려대학교 졸업작품 수준의 과제 검증”을 요청했다. 기본 내부 엔진으로 시험하며 모델 호출은 0회다. 이 검증 완료와 졸업작품 수준 달성은 구분한다. **과제 판정은 미달**이다.

## 기준과 출처

[고려대학교 공과대학의 2026 졸업전시 공식 소식](https://eng.korea.ac.kr/square/news_view.html?key=&no=1194&page=)은 도시·사회·삶의 공간을 해석한 작품과 외부 오픈 크리틱을 소개한다. [2025 공식 소식](https://eng.korea.ac.kr/square/news_view.html?key=&no=1141&page=5)도 학문적 탐구와 건축적 실험을 설명한다. 여기에서 세부 학생 도면이나 공식 채점표를 확보하지는 못했다. 따라서 본 문서의 기준은 이번 CAD 검증을 위해 구성한 자체 기준이며 고려대 심사나 특정 학생 작품과의 동등성 인증이 아니다.

과제는 가상 84×66m 대지의 2층 도시수리학교다. 기존 24×18m 수리동을 보존하고 대학과 동네의 수리·도구 공유·학습·전시를 연결한다. 17개 프로그램 영역, 4.2m 주 통로, 두 계단과 승강기, 중정과 보이드, +4.20 단면을 설정했다. 실제 안암동 필지·지형·이용자 조사는 수행하지 않았다. 치수는 법규 기준을 인용한 것이 아니라 명시적인 과제 입력이다.

## 실제로 실행한 부분과 설계자 기여

복합 브리프를 내부 자연어 플래너에 입력했다. 전체 건축 설계를 계획하지 못하므로 사각형 하나를 성공처럼 내놓지 않고 미지원 범위를 표시한다. 이후 Codex가 **검증 설계자 역할로 실 배치와 좌표를 직접 작성**했다. 그 입력을 `version:1,toolCalls`의 구조화된 코파일럿 제안으로 나눴다. 23개 제안을 실제 UI에서 Plan/Review/Apply하여 365개 객체를 만들었다. 숨은 모델 응답, mock 외부 gateway 또는 원본 문서 직접 덮어쓰기로 도면을 만든 검사는 아니다.

수리동의 외곽 및 세 프로그램 source를 보존 대상으로 두고 공공 경계 spline의 3번 통과점 X만 1000mm 이동했다. 다른 통과점과 모든 다른 feature는 유지됐다. detached preview, Apply 1 Undo, 정확한 Undo/Redo, native 직렬화와 실제 브라우저 reload를 확인했다. 이 수정은 경계 곡선에 한정하며 연결된 방 배치를 재설계하거나 단면을 자동 갱신한 것은 아니다.

5개 source view를 작성했다: S01 가상 대지, A101 1층 프로그램, A102 2층 프로그램, A201 독립 2D 단면, D01 계단·입구 개념 상세. native 원본, 각 SVG와 DXF, 모든 typed tool 호출 원장과 의도 sidecar를 남겼다. DXF는 5개 모두 skipped 0이다. 프로그램 사각형의 좌표 면적과 같은 층 중복/외곽 범위를 확인했다. 그 값은 연면적이나 실사용면적이 아니다. 벽체·문·코어 연결의 의미를 가진 BIM 도면도 아니다.

색상/표현은 설계자가 기존 CAD 스타일 명령으로 적용했고 SVG 표현 선폭과 텍스트 색상을 별도 설정했다. 형상 생성이나 미적 추론으로 집계하지 않는다. 학습 대지 뷰와 층별 뷰는 편집 화면에서 겹치지 않게 나눠 배치했다.

## 과제 중 발견하고 수정한 기능

- 복합 건축 브리프를 단순 도형으로 축약하는 잘못된 성공을 차단했다. 제한된 범위 검사이며 일반 언어 이해 모델이 아니다. 의도 확인에도 지원 범위를 표시한다. ‘진입면’이 ‘입면’으로 오인되는 회귀를 수정했다.
- 공통 도구에 `draft.text`, `draft.linearDimension`을 추가해 총 29개가 됐다. 입력은 schema·64 KiB·20개 호출 제한을 적용하며 scripts/raw commands/HTML 실행은 허용하지 않는다. 치수는 실제 두 점에서 측정한 정적 주석이고 기하 변경 시 재검토해야 한다.
- Copilot → CAD tools → Structured CAD proposal에서 설계자가 정한 좌표/치수를 입력하고 검토할 수 있다. 제안 출처가 설계자 입력임을 Review에 표시한다. 모델이나 코딩 에이전트가 자동 설계한 것으로 표기하지 않는다.
