# CAD-TOOLS-02 — 회전·스윕·로프트와 필렛·모따기·셸 연결

2026-10-19. [Copilot 사용법](../features/COPILOT.md), [공통 도구 계약](../architecture/CAD-TOOL-INTERFACE.md)이 현재 지원 범위를 소유한다. [CAD-TOOLS-01](CAD-TOOLS-01-2026-10-19.md)의 같은 계획 경로에 9개 도구를 추가하여 총 23개로 확대했다.

## 변경과 이유

`cad.edges`는 안정된 모서리 identity와 객체 배치를 반영한 world 대표 점을 반환한다. `curve.circle/polyline`은 원점 평면에서 떨어진 원형 단면과 open 경로를 생성하여 loft/sweep를 빈 문서에서도 구성한다. `solid.revolve/sweep/loft/fillet/chamfer/shell`은 기존 명령·OCCT 커널·원본 관계·Preview/Apply/Undo를 재사용한다. 필렛/모따기 canonical 명령에 선택적 결과 ID와 충돌 검사를 추가하여 그 결과를 같은 제안의 Boolean 입력으로 연결한다. 기존 호출은 ID 생략 동작을 유지한다.

선택 밖 원본·중복/사라진 위상 key·잘못된 단면·비평면 경로·열린 회전 윤곽·닫힌 스윕 경로를 거절한다. 마감은 기존 선택 솔리드의 실제 위상을 조회한 다음 계획한다. 새 솔리드는 먼저 Apply한다. 잘못된 마감은 원본/Undo를 바꾸지 않는다. 미해결 hole/shell/face-sketch 원본에서 유지된 예전 형상을 새 모서리 조회나 연산 입력으로 사용하지 않는다. 취소·버전·출력 레이어 검사는 기존 session 계약을 그대로 적용한다.

로컬 shortcut은 선택 윤곽의 명시적 축/각도 회전, profile→path 순서 스윕, 선택 순서 smooth/ruled 로프트, world 수직 직선 모서리 필렛/대칭 모따기, 유일한 윗면 제거 셸이다. 미지원/불완전 요청이 기존 단순 도형 규칙으로 넘어가 다른 형상을 생성하지 않도록 진단한다. Copilot 예시와 발견 가능한 도구 목록을 갱신했다.

## 검증

신규 Node 11개 과제에서 정확한 schema, 회전 180/360도, 원형 스윕, ruled frustum/smooth cylinder 로프트, world edge 변환과 detached 반환, 필렛/모따기→Boolean 연결, 셸과 미해결 원본 거절, 불가능한 마감의 원자적 실패, ID 충돌, 로컬 표현, gateway 모서리 조회→마감 제안을 검사했다. 기존 커널 연산 회귀도 전체 Node 실행에 포함했다.

최종 전체 Node 1529개(54 suites, 실패 0), 새 브라우저 17개와 기존 cadTools 19개·copilotEdit 25개·copilotSolid 18개·copilotGateway 13개를 통과했다. production build/typecheck, architecture 726모듈·문서 링크 검사도 통과했다. Vite의 기존 500kB 초과 main chunk 경고는 유지된다.

새 실제 React/Worker 브라우저 17개 검사는 gateway의 9단계 구성에서 회전 튜브·스윕 원기둥·로프트 원뿔대·박스를 한 Undo로 생성한다. 박스에 로컬 필렛→Undo/Redo→모따기→Undo→셸을 적용하고 최종 4개 솔리드를 STEP로 출력한다. 실제 페이지 reload로 원본 graph·정확한 면 참조·체적을 다시 검증했다. gateway 응답은 fixture이고 계산은 실제 Worker다.

독립 체적 기준은 튜브 `1500*pi`, 스윕 `480*pi`, 로프트 `1750*pi`, 셸 `24000-36*26*18=7152`mm³이다. 브라우저 STEP를 별도 OCCT STEPControl_Reader로 재수입해 유효성과 전체 체적 `7152+3730*pi`, 경계 `[-40,-10,0]–[70,44,30]`mm를 비교했다. 체적 허용오차는 0.005mm³다. 실행 수치는 [검증 manifest](../verification/CAD-TOOLS-02-2026-10-19.json)에 둔다.

## 남은 범위

임의 자연어 설계 전체와 실제 provider/서버/인증 연결은 이번 범위가 아니다. 회전축은 원점 통과 작업면 로컬 x/y, 스윕 경로는 open planar drawing, 단면은 구멍 없는 단일 닫힌 윤곽이다. 스윕은 기존 world point spine을 사용하므로 arc 경로는 표본을 잇는 근사이며 해석적 원호 spine은 후속이다. 대칭 모따기만 지원한다. 마감 참조는 정확한 identity를 사용하며 자동 추측/복구하지 않는다. 저장 schema와 의존성은 추가하지 않았다.
