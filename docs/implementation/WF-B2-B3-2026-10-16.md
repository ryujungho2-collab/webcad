# WF-B2 벽 생성·반복 돌출 → WF-B3 연관 개구부

> **현재 기능 설명:** [평면도와 건축 콘텐츠](../features/FLOOR-PLANNING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

2026-10-16. 아래 지원 범위의 실제 구현을 완료했다. 일반 BIM·모든 벽 접합·곡면 호스트 구현 완료를 뜻하지 않는다.

## 사용 흐름

1. 직선 XY 중심선(한 batch 최대 32개) 또는 준비된 닫힌 외곽/face를 선택한다. File → Floor plan tasks…, Copilot → Clean / Make face…, Ctrl K의 기존 공통 평면도 작업 진입에서 **Walls & openings**를 사용한다.
2. 중심선/footprint 모드를 고르고 단위가 있는 높이·두께·기준 레벨을 입력한다. Review에서 정확한 solid ghost·전후 체적·영향받는 도면의 생성/수정/삭제 수를 확인한다. Apply 한 번이 Undo 한 번이다. 음수 높이는 아래로 돌출한다. 기준 레벨은 독립 호스트 배치 전 Z이며 이후 호스트 이동/회전이 전체 형상에 적용된다.
3. 다음 원본을 선택하고 **Use last applied wall height**로 직전 확정 높이를 반복한다. 취소·실패한 Review는 직전 높이를 바꾸지 않는다. 패널이 모델 트리를 덮는 경우 Close floor tasks 후 원본을 선택하고 패널을 다시 연다.
4. 생성된 벽을 선택해 문/창, 좌우 호스트 측면, 원본 시작점에서 개구부 **중앙까지 거리**, 폭·높이·창턱을 입력한다. 문 창턱은 0이다. 창 상단은 창턱+높이로 표시하며 남는 상부 벽이 인방이다. Review → Apply로 현재 반대 면까지 관통한다.
5. 호스트 치수를 바꾸면 기존 opening ID를 유지하며 관통 깊이를 다시 계산한다. 목록에서 개구부를 고르면 수정/삭제할 수 있고 삭제는 벽 재료를 복원한다. 저장 및 portable 파일 재열기에 의미/원본/개구부가 보존된다.

## 구현 계약

- `ArchitectureWall`과 `WallOpening`은 기존 live feature metadata에 저장한다. 원본 IDs, 모드, signed 높이, 두께, 기준 레벨, opening ID/종류/좌우 면/거리/치수를 가진다. 벽은 원본 drawing/drafting에 연관되며 같은 host object/feature ID를 유지한다.
- 원본 중심선에서 정확한 띠 profile을 만들거나 기존 analytic face/profile/holes를 재사용하고 기존 OpenCascade extrusion/Boolean cut을 실행한다. 개구부는 현재 두께보다 양측으로 여유 있는 cutter를 만든다. 정확한 solid 유효성·빈 결과·실제 체적을 검사한다.
- 원본 이동/회전과 치수 재생성은 개구부까지 재계산한다. 독립 호스트 이동/회전도 전체 벽·개구부를 함께 변환한다. 일반 scale/copy/update-extrude로 의미를 우회하는 편집은 거부하고 원본 복사/벽 치수 편집으로 안내한다. 일반 Extrude 수치 패널은 벽에 노출하지 않는다.
- 벽 밖·끝 기둥 제거·상단 초과·음수 창턱·개구부 겹침/접촉·중복 ID·잠긴 대상은 문서 변경 없이 거부한다. 한 호스트 최대 100개 개구부다. 준비된 footprint의 두께는 원본이 결정한다.
- Review는 detached document에서 계산하고 실제 viewport solid ghost를 표시한다. 취소/Escape/패널 닫기는 계획과 ghost를 폐기한다. 문서 버전이 바뀌면 오래된 Apply를 거부한다. 확정은 한 Undo이며 Undo/Redo에 원본·벽·개구부·연관 도면이 함께 복원된다.
- **Include affected drawing rebind in Review**는 선택한 벽을 참조하는 등록 part의 평단면/정투영만 명시적으로 rebind한다. 같은 batch/Review/Undo에 포함되며 출력 잠금은 전체를 거부한다. 끄면 기존 보수적 topology stale 정책을 유지한다. 소실된 주석 대응을 임의 재연결하지 않으며 기존 참조 정책에 따라 수리/재연결이 필요하다.
- 벽 변경 후 같은 batch에서 입면 rebind할 때 현재 source snapshot을 과거 외곽선의 증거로 쓰던 경로를 피한다. 정확 HLR을 재계산하며 기존 source cache/영향 view 갱신 경로를 사용한다. 일반 도면 placement/scale 최적화를 변경하지 않는다.
- 파일은 벽이 있을 때 v41이며 v40 이하로 의미를 숨기는 downgrade를 거부한다. source 존재·live 계약·opening ID 유일성·unit host scale을 검증한다. 이전 문서는 기존 버전으로 유지한다.

## 지원 경계와 후속

- 중심선은 평면 XY의 유한 직선이며 batch 벽은 독립 butt end다. 자동 miter/융합/T 접합이나 접합 우선순위는 구현하지 않았다. 코너가 필요한 경우 준비된 닫힌 벽 footprint를 사용한다. 복잡한 외곽/홀의 벽 extrusion은 가능하지만 이 호스트의 개구부는 아직 지원하지 않는다.
- 문/창은 직선 중심선 벽 또는 단일 직사각형 띠 footprint의 직사각형 관통 개구부다. 원본 시작/방향을 기준으로 거리와 좌우 면을 저장하며 원본을 임의로 뒤집는 rebind는 별도 검토한다. 커서 호스트 면 pick·snap·두 점 폭·아치형 개구부·복합/곡선 벽·문짝/창틀 컴포넌트·방화/법규 판단은 후속이다.
- 반복 높이는 이 세션에서 같은 문서에 확정된 값이다. viewport 더블 클릭 반복·프로젝트 간 반복 높이 공유·장시간/대규모 wall network 성능은 검증하지 않았다. 임의 자연어 해석은 별도이며 Copilot은 공통 로컬 작업 패널과 타입 명령을 사용한다.
- 다음 기능은 **CMP-S1 인스턴스 콘텐츠 슬롯·여유 공간/재사용 창호 → WF-D1 바닥·천장·재질**이다. 먼저 작은 방 과제로 벽-개구부-창호 배치-단면/시트 출력을 연결하고, 자동 코너 접합/면 pick은 명확한 후속 CAD 범위로 남긴다.
