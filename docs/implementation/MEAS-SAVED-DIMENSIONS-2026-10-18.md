# MEAS 후속: 측정 결과 고정·치수화

2026-10-18

Direct의 면·모서리 A/B, 거리 모드, 이름, 출력 평면과 배치를 저장하고 도구 종료·파일 재열기 후에도 연관 치수로 표시한다. 원본 편집으로 참조가 사라지면 이전 값을 남겨 표시하지 않고 재지정을 요구한다. 같은 평면의 아트보드 SVG·PNG·PDF 출력에도 치수를 포함한다.

## 문서와 명령

`CadDocument.savedMeasurements`는 최대 32개 정의와 검증된 결과 캐시를 보관한다. 정의는 ID/이름, 두 원본 objectId+topology key, 거리 모드, 월드 출력 평면, X/Y 오프셋, 텍스트 높이와 표시 여부다. 결과는 값·원본 witness·정밀도·수치 추정 범위와 원본 전체 정의의 sourceKey에 연결된다. 모델 revision만으로 캐시 유효성을 판단하지 않는다.

문서 구조 검증·command validator를 추가했다. 새 데이터가 있는 파일만 version 46으로 저장하고 낮은 버전으로 위장한 새 데이터를 거부한다. 캐시 수치·상태·배치·예산과 중복 참조를 검증한다. 파일 로드, 프로젝트 초기화, 명령 publish/rollback, Undo/Redo의 선택적 필드 복사·제거 경로를 연결했다.

`upsert-saved-measurement`, `delete-saved-measurement`, `refresh-saved-measurements`는 기존 문서 명령 큐와 history를 사용한다. 원본은 변경하지 않는다. 명령 payload의 계산 결과를 신뢰하지 않고 정의만 복사한다. 동일 원본의 이름·배치·표시 변경은 기존 유효 결과를 재사용한다. 측정 전용 명령은 불필요한 모델 재생성을 건너뛴다.

실제 모델 명령의 feature regeneration과 검증이 끝난 뒤 변경된 참조만 native 재측정한다. 실패는 측정의 broken 상태/이유로 기록하고 결과를 제거한다. 정상 모델 편집을 참조 오류 때문에 되돌리지 않는다. Undo는 모델과 그때의 연관 결과를 함께 복원한다. 렌더링/출력은 sourceKey를 확인하며 문서 명령을 실행하거나 native query를 만들지 않는다.

## 화면과 출력

Direct 측정 패널에서 저장, 같은 항목 갱신, 별도 항목 저장, 이름·평면·X/Y 배치를 편집한다. 오른쪽 위 저장 목록은 도구 밖에서도 현재 값·참조 상태와 표시·삭제·다시 계산을 제공한다. 편집/재지정은 Direct에서 같은 ID를 불러와 A/B를 바인딩한다.

치수선·연장선·화살표·텍스트는 읽기 전용 평면 기하이며 SVG overlay로 그린다. 문서 generation마다 기하와 상태를 메모해 카메라 추적 시 원본 정의를 반복 직렬화하지 않는다. 표시할 치수가 없으면 애니메이션 갱신도 중단한다.

`collectExportAnnotations`가 저장 치수를 원본 A의 출력 순서에 추가하므로 일반 아트보드·SVG·PNG·PDF가 기존 장면/클리핑/물리 크기를 공유한다. 범위 출력에서는 A/B가 모두 범위에 있어야 한다. 표시 중인 무효 치수의 출력은 오류를 낸다. 이를 숨기면 출력에서 제외한다. 원본 모델이 출력 도면 자체로 변환되는 기능은 추가하지 않는다.

## 제한과 단위

저장 대상은 BRep 지정 측정이다. 문서당 32개이며 치수 위치는 모델 mm의 평면 X/Y 수치 배치다. 드래그 배치, 유한 도면 hover 자동 치수화, 프레임·모델 시트의 소유 범위 자동 확장, 영구 topology naming은 포함하지 않는다. 3D 값은 출력 평면의 선 길이와 다를 수 있어 모드를 문구에 표시한다. 투영/축의 수치 정밀도·근사 상태는 기존 계산 계약을 유지한다. 결과 캐시는 원본 정의가 같은 정상 재열기에서 복원하고, 명시적 재계산으로 native 참조를 다시 검증할 수 있다.
