# S자 조명 · 열린 곡선의 실제 3D 인계

2026-10-24. [원본과 STEP](../../output/projects/curve-lamp/README.md).

새 과제는 약 755 mm 높이의 조명이다. 일곱 통과점을 가진 S자 지지대, 원형 받침, 네 단면을 부드럽게 연결한 속 빈 갓, 오팔 확산판, 하단 링의 다섯 부품으로 구성한다. 사람은 XZ 평면의 열린 맞춤 곡선과 R8 단면을 만든다. 공통 스윕 폼과 내부 자연어로 동일한 실제 BRep를 만들고, 접선 강도를 조절한다. 실제 SDK stdio MCP가 곡선의 허리를 수정하고 나머지 부품과 마감을 작성한다. 모델 엔드포인트 호출 없이 이 과정을 검증한다.

기존 스윕은 열린 선분·폴리라인·원호의 점 목록만 받았다. 이제 spline의 세계 좌표 제어점·차수·매듭·가중치·유효 구간을 그대로 전달한다. `resolveSweepPath`를 생성과 live 재생성에서 함께 사용한다. 비균일 크기·이동·회전을 포함한 세계 좌표 원본을 유지하며 표시용 샘플을 기하 경로로 사용하지 않는다. native 커널은 기존 정확한 spline edge 생성기를 재사용한다. 원호 경로의 기존 샘플 방식은 이번 작업에서 변경하지 않는다.

곡선 스윕은 corrected Frenet 모드를 사용한다. `SetMode(false)`가 이 모드라는 사실은 [OCCT 공식 API](https://occt3d.com/dev/doc/refman/html/class_b_rep_offset_a_p_i___make_pipe_shell.html)로 확인했다. 변곡점을 포함한 이번 S자 경로는 독립 길이 적분과 체적 비교로 검증한다. 이것이 모든 자기 교차 경로나 단면에 대해 성공한다는 뜻은 아니다. 기하가 유효하지 않으면 기존 native Review가 전체 작업을 거절한다.

새 형상 명령을 추가하는 대신 기존 `curve.reshape`를 사람용 접선 강도 폼과 `곡선 접선 강도 1.0` 자연어에 연결했다. 현재 원본 강도를 읽고 0.1–1.5의 명시적 새 값을 검토한다. 통과점·평면·열림/닫힘·배치를 유지한다. 기존 `curve.adjust`는 한 점의 위치를 바꾼다. 두 수정 모두 연결된 스윕과 같은 Undo 트랜잭션이다. canonical 39종 / MCP 42종을 유지하며 사람 공통 폼은 13종이다. 임의 외부 NURBS의 통과점을 추측하거나 복구하지 않는다.

저장 형식 52는 정확한 spline 경로를 가진 스윕을 표시한다. source와 Boolean 피연산자의 중첩 경로까지 검사한다. 이전 형식으로 위장하거나 가중치가 손상된 파일은 거절한다. 기존 형식 50/51의 닫힌 spline 프로파일과 구멍은 그대로 지원한다.

지지대 체적의 독립 기준은 cardinal-Hermite 속도를 span마다 4096 구간의 composite Simpson 방식으로 적분한 길이 × π × 8²이다. 제품의 `splineLength`, 표시 샘플 또는 커널 체적을 길이 기준으로 재사용하지 않는다. 받침·확산판·링은 원기둥과 토러스 공식으로 비교한다. 갓의 체적은 유효한 실제 BRep에서 읽으며 별도의 해석적 정답을 주장하지 않는다. STEP은 새 reader로 다시 읽어 다섯 솔리드의 유효성과 체적을 검사한다.

현재 통과점 보간은 기존 cardinal cubic의 C1 연결이다. C2 곡률 연속 최적화, 개별 접선 핸들, 곡률 빗 표시, 서로 다른 곡선 사이의 접선 구속은 이번 범위가 아니다. 조명은 CAD 연결 과제이며 전기·발열·전도 안정성이나 생산 도면의 검증 결과가 아니다.
