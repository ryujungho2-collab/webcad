## 치수 표시

- 선형·반지름·지름·각도 치수를 선택하면 Properties → Annotation에서 길이 단위(mm/cm/m/in/ft), 각도 단위(도/rad), 소수 자릿수(0–6), 글자 높이·화살표 크기·문자 간격·종이 축척을 편집한다. 연속 치수는 Drafting → Continuous dimensions에서 공통 단위·자릿수·화살표·간격·축척을 지정하고 기존 Text height가 글자 높이를 맡는다.
- 공통 `CadDimensionStyle`은 각 주석의 `params.style`에 선택적으로 저장한다. 기존 파일은 기본 표시값을 사용한다. 명령 경계와 CAD 파일 검증에서 잘못된 단위·음수/0 크기·과도한 자릿수를 거부한다. 스타일 수정은 원본 도형, 측정 `value`, 구동 스케치 치수, 연관 참조를 바꾸지 않는다. Undo/Redo와 JSON 저장·재열기는 같은 스타일을 복원한다.
- `resolveDimension`이 화면 선·문자와 active-plane SVG/PDF 주석에 같은 해석을 제공한다. 길이는 내부 mm, 각도는 내부 rad로 유지하고 표시할 때만 변환한다. 종이 축척은 글자·화살표·간격에 곱하고 치수선의 측정 위치/기준점을 바꾸지 않는다. 텍스트 수동 재정의는 자동 형식보다 우선한다.

## 작도 추적

선·다중선·사각형·원·호 작성 중 실제 객체 스냅 지점에 커서를 놓고 **Shift+A**를 누르면 추적점을 획득한다. 같은 점에서 다시 누르면 해제된다. **Shift+R**은 전체 해제, **Shift+L**은 자유→수평→수직 방향 잠금 순환, **Shift+N**은 가까운 후보를 순환한다. **Alt**를 누르는 동안 객체 스냅과 추적을 억제한다. 캔버스 readout과 커서 기호는 후보 축·원본과 해제 방법을 표시한다.

추적 후보는 취득한 점의 수평/수직 투영과 서로 다른 두 점의 추적선 교점이다. 교점을 먼저, 이어 픽셀 거리와 원본 순서로 결정한다. 기존 직접 객체 스냅을 우선하고, 격자/최근점만 추적 후보에 양보한다. 사용자의 정확한 숫자 입력은 추적 후보를 사용하지 않는다. 취득 반경은 스냅 설정의 화면 픽셀 값이므로 zoom에 독립적이다. 후보가 없거나 다른 후보가 없으면 readout에 이유와 다음 조작을 알려 준다.

추적점·잠금·후보 번호는 문서/History/구속에 저장하지 않는다. 작성 종료·취소·문서 변경과 원본 숨김/삭제 시 해제한다. 추적 교점은 기존 스케치 `Coincident` 구속으로 잘못 승격하지 않는다.
