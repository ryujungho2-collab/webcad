# 비정형 전시 키오스크 · 곡선 수정 인계

2026-10-24. 원본·STEP·도면 (local-only, not in repository: `output/projects/organic-kiosk/README.md`).

약 6 m급 유기적 전시 키오스크를 2D 맞춤 곡선부터 작성했다. 120 mm 바닥, 900 mm 안내 데스크, Z2700–2850의 테이퍼 캐노피, Ø120 기둥 세 개와 전시 패널을 독립 BRep 일곱 개로 구성한다. 설계 품질이나 법규 적합성의 인증이 아니라, 사람·내부 자연어·실제 MCP 사이에서 수정 작업을 이어가는 검증 과제다.

사람용 공통 폼에 `curve.fitted`, `curve.adjust`, `drawing.refresh`를 추가해 총 12종을 연결했다. 실제 복원 가능한 점 목록과 원본 좌표, 배치 변환을 표시한다. 사람은 1부터 시작하는 점 번호를 보고 선택하며 MCP의 0부터 시작하는 인덱스도 함께 확인한다. 대상을 바꾸면 점과 이동량을 초기화한다. 대상 목록의 grid 스타일이 hidden을 덮어쓰던 문제를 고쳐, 접으면 실제로 목록을 숨기고 수정 폼 공간을 확보한다. 내부의 제한된 문법 `곡선 4번 점 X -300mm 이동`은 같은 `curve.adjust`로 컴파일한다. 도구 호출·편집 대상·검토·게시·Undo 경로를 별도로 만들지 않았다. canonical 도구 39종, MCP stdio 노출 42종은 유지한다.

실제 작성 중 닫힌 스플라인을 3D 프로파일로 전달하지 못하는 결함을 발견했다. 프로파일 추출기는 원래 NURBS와 안정적인 원본 참조를 유지하고, 기존 rational Bezier 경계 검증기로 닫힘·분기·교차를 확인한다. 공통 커널 wire 생성기를 돌출·로프트·스윕·회전에서 사용한다. 원래 매듭 구간별로 정확한 edge를 만들며 폴리라인으로 치환하지 않는다. 구간을 분리하지 않은 긴 스플라인의 cap 적분에서 나타난 체적 불일치도 독립 계산으로 잡았다. OCCT handle이 소유한 곡선을 중복 해제하지 않도록 수명을 정리했다. 동일 매듭 구조의 로프트는 명시적인 구간 대응을 유지한다.

교차 연산이 반환한 스플라인이 256 poles 한도를 넘으면 원래 native 곡선을 여러 유한 domain으로 나눈다. 각 조각은 여전히 스플라인이며 차수·pole 예산을 유지한다. 이 단면은 OCCT 교차 허용오차를 따르며 렌더링 메시의 실루엣이 아니다. 저장 형식 50은 중첩 Boolean 피연산자까지 스플라인 프로파일을 식별하고 잘못된 basis나 이전 버전으로의 위장을 거절한다.

곡선 수정은 연결된 3D 형상을 같은 트랜잭션에서 재생성한다. 반면 변경된 스플라인 단면의 대응 관계를 증명할 수 없으면 기존 도면을 `unresolved`로 표시하고 숨긴다. 공통 도면 재연결 폼으로 명시적으로 다시 검토한다. 가까운 곡선에 임의로 연결하거나 이전 형상을 현재 단면처럼 남기지 않는다. 혼합 스플라인 경계와 내부 구멍은 이번 범위에서 지원하지 않으며 별도 솔리드 연산으로 작성한다. 열린 스플라인의 스윕 경로도 이번 추가 범위가 아니다.

`kioskHandoff` 실제 React UI/Worker/공식 SDK stdio 검증 48개를 통과했다. 사람 폼과 자연어의 게시 결과 일치, MCP 읽기와 편집 권한 분리, 원본의 한 점만 수정, 독립 체적 계산, 단면의 명시 재연결, 단일 Undo, 저장 후 재열기, 실제 STEP·SVG·DXF 출력을 포함한다. 외부/로컬 모델 endpoint 요청은 0회다. [검증 기록](../verification/KIOSK-HANDOFF-2026-10-24.json)에 실행 결과와 파일 해시를 기록한다.
