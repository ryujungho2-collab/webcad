# 확장 스케치 구속과 정밀 스냅

> **현재 기능 설명:** [정밀 작도와 편집](../features/DRAWING-EDITING.md). 이 문서는 날짜별 구현·설계 기록이며, 아래 사용법·제한·수치는 당시 범위다. 후속 지원은 대표 가이드를 따른다.

> 단계 기록: 아래 구현·검수 수치는 해당 시점의 근거다. 최신 지원 범위는 [CAD-BASICS](../product/CAD-BASICS.md), 최근 전체 검수는 [PROJECT-STATE](../../PROJECT-STATE.md), 다음 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)를 따른다.

2026-10-04. G2 중 구속·스냅 묶음을 구현했다. 곡선 수정 작업과 상용 CAD의 전체 기능을 완료한 것은 아니다.

## 추가한 기능

| 관계 | 대상과 저장 의미 |
| --- | --- |
| Parallel / Perpendicular | 선, 폴리라인의 직선 변, 회전된 사각형의 변. 영구 geometry/segment ID로 참조한다. 반대 방향의 평행도 허용한다. |
| Equal length | 두 직선 변의 실제 길이를 유지한다. |
| Concentric / Equal radius | 원과 호의 중심 또는 반지름을 함께 유지한다. |
| Tangent | 직선 변의 지지 직선과 원. 방향 있는 선의 어느 쪽에 닿는지 저장한다. |
| External / Internal tangent | 두 원의 외접/내접을 구분해 저장한다. 동일 반지름의 내접은 퇴화하므로 거부한다. |
| Point on line / circle | 영구 점 ID를 직선 변의 지지 직선 또는 전체 원 위에 유지한다. |
| Symmetric | 두 점을 영구 직선 변을 축으로 대칭 배치한다. 축 자체가 자유로우면 축도 함께 움직일 수 있다. |

10개 관계 종류를 기존 일치·수평·수직·고정·거리·각도·반지름·지름 솔버에 통합했다.
연결 관계 탐색, 자유도 계산, 충돌 진단, 연관 치수/솔리드 갱신, 삭제와 복제도 같은 참조를 사용한다.
복제는 내부 관계와 하위 참조를 새 ID로 재연결하고 외부 관계를 복제하지 않는다.
충돌 결과가 문서, 캐시 형상, revision 또는 Undo를 부분적으로 바꾸지 않는다.

## 캔버스에서 사용하는 흐름

1. Sketch를 편집하고 두 선/원 또는 폴리라인·사각형 변을 선택한다. Inspector에서 필요한 변을 지정하고 관계를 선택한다.
2. 황색 이전 형상, 녹색 해석 결과와 `add on Apply` 관계 기호를 캔버스에서 확인한다. Inspector에는 적용 이후 DOF가 표시된다.
3. `Apply constraint`로 검토한 결과를 한 Undo 단계로 적용한다. `Cancel constraint` 또는 Esc로 취소한다. 선택·문서·명령이 바뀌면 이전 검토를 폐기한다.
4. 점 관계는 Direct 모드에서 Ctrl로 점과 대상 객체를 선택한다. 대칭은 두 점과 `Symmetry axis`를 지정한다.
5. 드래그는 저장 관계를 유지한다. 고정된 원 위 점과 고정 원에 접하는 원의 중심은 실제 원형 이동 안내를 제공한다. 다른 비선형 관계는 국소 방향 안내와 실제 해석 결과를 검토한다.

기존 연결 점 편집은 이동한 점만 임시 고정해 이웃 자유점을 따라 움직이게 한다. AB=50, BC=30과 전용 Perpendicular를 함께 유지하는 명령을 검수했다.

## 스냅

상태바 `Snaps ▾`에서 Endpoint / Midpoint / Center / Intersection / Quadrant / Perpendicular / Tangent / Extension / Nearest / Grid를 각각 켠다.
격자 간격은 `2.5cm`처럼 단위를 입력할 수 있고, 취득 반경은 2–40 화면 픽셀이다. F3는 전체 ON/OFF, Alt는 그리기·직접 편집·점 기준 변환에서 일시적으로 스냅을 억제한다.

- Quadrant는 정확한 0/90/180/270° 점이며 호와 bulge 호에서는 실제 방향 있는 호 범위에 포함되는 점만 제공한다.
- Extension은 유한한 직선 변의 양쪽 연장 부분에 투영하고 원래 객체·변 참조와 연장 시작점을 반환한다. 유한 bounding box 밖에서도 취득한다. 기본 OFF이며 설정에서 켠다.
- 실제 그리기는 종류별 기호·이름·원본 객체를 표시하고 Extension의 연장 방향을 캔버스에 표시한다. 고정된 화면 픽셀 반경을 사용한다.
- 설정은 브라우저에 저장되며 문서와 Undo를 변경하지 않는다. 그리기, 직접 편집, 점 기준 Move/Copy/Rotate, 작도와 거리 측정에 전달한다. Break의 끝점 취득도 Endpoint 설정을 따른다.

## 저장·검수·경계

새 관계를 포함한 WebCAD 파일은 v5이다. v1–v4는 계속 읽으며, v5 관계를 낮은 버전으로 위장한 파일은 거부한다. 일반 파일은 필요한 기존 버전으로 저장한다. SVG/DXF/PDF에 스케치 구속 정의를 저장하는 것은 지원하지 않는다.

새 Node 22개는 수렴·각도/거리의 독립 수치 기준, 1e8 측량 좌표, 서명 있는 접선, 폴리라인/사각형 하위 참조, DOF와 원형 드래그, 복제/삭제/저장, 실패 원자성 및 XY/XZ/YZ 스냅을 검사한다.
새 실제 브라우저 과제 27개는 관계 생성·Esc 취소·충돌·한 Apply/Undo/Redo·재열기·원형 드래그와 스냅 설정·실제 Quadrant/Extension 그리기·Alt 억제를 검사한다.
이 구속·스냅 묶음 검수 시점에는 전체 Node 483개 / 49 suites, 브라우저 18과제 / 370개 검사와 production 빌드를 통과했다. 기존 번들 크기 경고는 남아 있다. 검수 로그는 PROJECT-STATE의 최신 기록을 따른다.

현재 선 관계는 유한 변의 전체 지지 직선을 대상으로 한다. 호의 접점이 실제 호 범위에 있는지까지 해석하는 접선, 호 위 점 구속, 일반 스플라인, 독립 Point/무한 Line/Ray의 스케치 엔티티 통합은 후속이다.
Extension은 직접 투영 스냅이며 끝점 취득 후 추적선 유지, 복수 추적 교점과 Polar tracking은 후속이다. 이후 첫 곡선 다중선 Offset/자유 끝부분 Trim/Extend와 두 객체 직선 Fillet/Chamfer, 결과 인계 작업대를 구현했다. [후속 범위와 검수](CURVE-WORKFLOW-2026-10-04.md)를 따른다.
