# G6-D5-E2 곡선 DXF 확대

2026-10-18 · 첫 지원 범위 완료. [현재 사용법](../features/DRAWINGS-OUTPUT.md) · [검증 manifest](../verification/G6-D5-E2-2026-10-18.json) · 다운로드 산출물 (local-only, not in repository: `output/projects/curve-dxf/README.md`)

periodic SPLINE의 명시적 wrapped control basis와 열린 fit-only cubic 입력을 추가했다. 문서 schema 39의 degree 1–8·최대 256 poles·양의 가중치·유한 nonperiodic domain은 유지한다. import 이후의 편집 원본은 명시적 유한 control/knot basis다. 임의 polyline 대체는 없다.

## Periodic 원본과 seam

첫 범위는 반복 전 poles가 degree+1개 이상인 basis다. 원본에 마지막 degree개 poles/weights가 앞의 degree개와 동일하게 반복되고, 확장 knot 구간이 같은 period를 나타내는 경우만 지원한다. 누락된 cyclic poles를 추측하거나 잘못된 seam을 수리하지 않는다. rational homogeneous knot insertion으로 원래 domain 양끝을 고정하고 한 주기의 finite source를 만든다. source knot parameter와 start seam 위치, WCS 형상과 가중치 효과는 유지한다. cyclic pole editing과 periodic flag는 이후 export에서 보존하지 않으며 이 손실을 Review에서 별도로 동의받는다.

기존 비고정 오른쪽 domain 끝의 knot 삽입은 마지막 평가 span을 그대로 사용해 끝점이 이동할 수 있었다. 오른쪽 경계를 뒤집은 basis의 왼쪽 경계로 삽입하고 다시 뒤집어 고쳤다. rational 비고정 basis의 모든 span과 끝점, 재차 trim, 내부 domain을 독립 Cox basis 평가와 대조한다.

## Fit-only 재구성

첫 범위는 degree 3, 열린 비유리 곡선, fit points 2–86개, knots/weights/control points와 끝점 접선이 없는 입력이다. chord-length parameter와 natural endpoint 조건으로 결정적인 C2 cubic interpolation을 만들고 piecewise cubic Bézier control basis로 저장한다. 86점은 정확히 256 poles이며 기존 예산을 늘리지 않는다. 연속 중복/나쁜 conditioning, 닫힌 끝점, periodic/closed fit flags, tangent boundary 조건은 구체적인 이유와 함께 제외한다.

각 fit point 잔차가 선언된 group 44 tolerance 이내인지 확인하고 실제 잔차와 허용오차를 원본 파일 단위로 Review에 표시한다. **이 잔차는 원래 CAD 곡선과 점 사이에서 일치한다는 보장이 아니다.** DXF fit points만으로 원본 CAD의 재구성 방식이 결정되지 않으므로 natural endpoint 정책, fit editing 의미 손실, source-curve deviation bound 부재를 함께 고지한다. control/knot basis와 보조 fit/tangent 데이터가 같이 있으면 control basis가 우선이며 보조 편집 정보 손실도 고지한다.

변환 고지는 제외 목록과 분리한다. 두 동의가 필요한 경우 각각 확인해야 Apply가 가능하다. source/준비 설정/문서가 바뀌면 동의를 초기화하고 기존 detached Review·stale 거절·한 Undo 계약을 유지한다. source-wide 고지는 레이어 필터 이전 입력을 설명하며 입력 단위 override 전의 원본 단위를 명시한다.

## 교환과 출력

SPLINE의 control/fit points와 tangents는 WCS이므로 normal을 OCS transform으로 적용하지 않는다. 원본 단위→mm와 준비 단계 unit override는 명시적 control points에 적용한다. 숫자·중복/누락 좌표·count·knot·가중치·flag·normal을 검증한다. 블록 내부 곡선의 변환 고지도 Review에 포함하고 TABLES에 없는 멤버 레이어도 수집해 누락을 막는다.

writer는 finite domain을 knot insertion으로 자르고 editable SPLINE을 출력한다. knots·weights·poles는 JavaScript 숫자가 왕복되는 표기를 사용한다. 기존 소수 12자리 고정 반올림이 짧은 parameter domain이나 작은 가중치를 손상시키던 경우를 제거했다. paper crop의 parameter 허용오차와 구간 병합 기준도 domain 길이에 비례시켜 1e-14 크기의 domain을 검증한다. 표시/SVG/PDF의 기존 0.02mm 종이 chord tolerance는 source 교환 오차와 구분한다.

그룹 코드·WCS·flags/tangents 정의는 [Autodesk SPLINE DXF reference](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-DXF/files/GUID-E1F884F8-AA90-4864-A215-3182D47A9C74.htm)를 따른다. natural interpolation 정책은 이 구현에서 선택한 재구성이며 AutoCAD의 원래 between-point 형상 재현을 주장하지 않는다.
