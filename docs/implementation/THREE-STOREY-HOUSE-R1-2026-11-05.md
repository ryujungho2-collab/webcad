# 3층 주택 R1 — 내부·외부 복잡도와 실제 간섭 검증

사용자 피드백: R0의 반복 모듈만으로 산업디자인을 충분히 반영했다고 보기 어렵다. 이번에는 산업디자인 완성을 선언하지 않고 **실제 내부 구성과 외피 상세를 늘려 조립·편집·간섭을 검증**했다. R0 파일은 보존하고 `output/projects/three-storey-house/r1`에 별도 결과를 작성한다.

## 추가한 구성

- 채워진 수납장 대용 상자 12개를 표시 대상에서 제외하고 옆판·바닥·선반·문짝·손잡이 및 상판으로 대체.
- 주방 아일랜드, 침대/소파의 기단·쿠션·등판, 욕실 세면대 테두리·WC 외형·샤워 트레이와 유리, 열린 욕실 문짝·손잡이.
- 2개 층 계단의 경사진 손잡이·유리 채움재를 YZ 원본 윤곽에서 돌출. 창호 상·하부 프레임, 비대칭 현관 캐노피, 테라스 전면/측면 유리와 손잡이, 지붕 파라펫.
- 새 2D 원본과 연결된 부품 182개 추가. 기존 대용 수납장 12개를 제외한 표시/출력 부품 총 361개. 원본은 CAD에서 재편집 가능하다.

## 검사와 수정

598개 검사 통과. 새 부품 유효성·직육면체 독립 체적, 선정 간섭쌍의 실제 BRep 거리/공통체적, 3개 층 욕실 문 여닫이 보수적 범위, 두 계단의 4지점씩 상부 슬래브 머리높이, 원본 이동→돌출 재생성→Undo/Redo, 5개 native 절단 도면 갱신, 저장/재열기를 포함한다.

**실제로 수정한 충돌:** R0의 2층 작업대 다리와 추가 침대 기단이 750,000mm³ 관통했다. 작업대와 네 다리의 원본 2D를 X+4300/Y−2600mm 옮겨 인접 공간으로 재배치했다. 같은 쌍의 재검사 공통체적은 0이다. 작업대와 벽체 간섭도 별도로 검사했다.

**의도적으로 통과시키지 않은 항목:** F1 서측/북측 벽체 접합부의 관통이 양성 대조군에서 검출된다. 이를 전체 무간섭으로 숨기거나 물량에서 임의 차감하지 않았다. CSV는 부품별 총체적이다.

독립 STEP reader에서 **361개 솔리드의 유효성·체적 보존**을 재확인했다. 실제 Chrome에서 외관과 1층 내부 표시 절단을 캡처해 검토했다. 모든 사용자 UI 조작·MCP 인계 또는 LLM 설계 성능을 이번 과제로 검사한 것은 아니다. 이 작업은 native 명령을 사용한 과제 모델 검증이며 제품 기능 변경은 없다.

## 보는 방법

[R1 검토 화면](../../output/projects/three-storey-house/r1/review.html)의 1층/2층/3층 버튼은 해당 층 바닥 +1200mm에서 화면 표시만 절단해 내부를 보여준다. 원본 BRep은 바뀌지 않는다. 전체/지붕/층 분리 보기 및 부품 클릭 이름 확인을 제공한다. SVG 평면은 native 단면에 저층 가구 원본의 평면 윤곽을 겹친 검토도이며 DXF는 native 절단선이다.

## 남은 난이도

검사한 쌍과 표본만 통과했다. 문 여닫이 검사는 서비스실 기구에 한정하고 머리높이는 상부 슬래브에 대한 8지점 표본이다. 전체 경로, 모든 부품쌍, 외벽 단열·방수·배수, 계단 디딤판 지지·난간 체결, 구조/설비, 법규 및 실시설계 상세는 미해결이다. 욕실 기구는 설치 공간 검토 외형이고 제품 내부 구조/설비 연결 모델이 아니다. 창호 유리·프레임 접합, 외장 고정 브래킷 및 벽 접합을 다음 조정 대상으로 남긴다.

재현: `refineThreeStoreyHouse.ts` → `buildThreeStoreyReview.ts --r1` → `inspectThreeStoreyStep.ts --r1`를 `pnpm --filter @agent-webcad/web exec tsx scripts/…`로 실행한다.
