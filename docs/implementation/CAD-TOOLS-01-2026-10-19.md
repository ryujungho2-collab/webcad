# CAD-TOOLS-01 — 공통 조회·계획 계약과 3D 도구 확대

2026-10-19. 현재 사용자 지원 범위는 [Copilot](../features/COPILOT.md), 개발 계약은 [공통 CAD 도구](../architecture/CAD-TOOL-INTERFACE.md)가 소유한다. [첫 3D 생성·후속 수정](COPILOT-SOLID-01-2026-10-19.md)을 바탕으로 도구 발견과 조회 왕복, 일반 스케치/돌출/면 구멍/Boolean을 연결했다.

## 변경한 것과 이유

도구 이름·설명·JSON inputSchema·단위를 한 catalog로 정의했다. gateway와 로컬 shortcut이 같은 검증기와 도구→기존 명령 변환을 사용하므로 도구별 기하 엔진을 새로 만들지 않는다. 원본 스케치·구속·피처 입력과 정확한 면 작업면을 보존한다. 새로운 저장 schema나 외부 의존성은 추가하지 않았다.

gateway는 최종 계획 전에 객체 검색/상세/측정/면/지원 치수를 조회할 수 있다. 조회는 캡처한 문서의 제한된 DTO를 반환하고 다시 gateway에 전달한다. 읽기/쓰기 혼합과 재사용된 call ID·알 수 없는 필드·한도 초과를 거절한다. 전체 요청 deadline과 취소는 네트워크뿐 아니라 로컬 조회 대기에도 적용한다. 모델링 응답은 공통 Preview/Apply로 보내고 한 Undo로 게시한다.

기존 입력은 선택한 원본에 한정하며, 같은 제안에서 생성한 결과는 다음 연산에서 참조할 수 있다. Boolean 입력 순서와 구멍의 면 로컬 좌표를 요약에 명시한다. 읽은 객체가 자동 편집 대상이 되지 않는다. 미해결 면/소스 참조는 query 진단으로 보이고 새 기하의 측정/모델링 입력에서 거절한다. 기존 gateway command allowlist와 단일 치수 변경은 유지했다.

로컬에서 `80x50 사각형 스케치`, `선택한 윤곽 20mm 돌출`, `80x50 사각형 스케치 20mm 돌출`, `윗면 중심에 지름 6mm 관통 구멍`, `윗면 중심에 지름 6mm 깊이 5mm 구멍`, 두 솔리드 선택 후 `합집합/차집합/교집합`을 지원한다. 잘못된 새 스케치/구멍 요청이 기존 단순 도형 규칙으로 흘러가 다른 형상을 만들지 않도록 실패를 명시한다.

## 코드 위치

- `copilot/cadToolContract.ts`: catalog, 입력 schema와 한도, call 검증.
- `copilot/cadModelingTools.ts`: 선택/새 결과의 원본 범위, 모델링 명령 변환, 참조 진단.
- `copilot/cadToolSession.ts`: detached snapshot 조회, 버전 검사, 제한된 DTO.
- `copilot/cadToolPrompts.ts`: 같은 도구를 호출하는 로컬 shortcut.
- `copilot/copilotConnection.ts`: 제한된 조회 왕복과 최종 제안, 요청 전체 취소/deadline.
- App·CopilotPanel: 공통 tool session, 실제 계산된 결과 미리보기, 도구 목록/단계와 최종 결과 인계.

## 검증

신규 Node 9개 과제에서 schema·권한·명령 그래프, 외곽+내측 원의 돌출, Boolean 3종, 정확한 면의 관통/막힌 Hole, 출력 ID 충돌/중간 실패 원자성, stale generation/취소/잠금/미해결 참조, gateway 조회→계획과 호출/크기/시간 한도, 로컬 shortcut을 검증했다. 수정된 면 identity를 잃은 Hole의 예전 형상을 현재 측정/새 입력으로 사용하지 않는 것도 확인했다.

실제 React/Worker 브라우저 19개 검사에서 다음을 확인했다.

1. 구속된 80×50mm 사각형 스케치를 만들고 선택 원본을 20mm 돌출.
2. 가장 높은 +Z 평면을 조회해 중심 Ø6mm 관통 구멍 생성. 면 작업면과 Hole을 한 Undo로 적용/복원.
3. gateway fixture가 inspect/measure/faces를 읽은 후 새 박스와 union을 같은 계획으로 제안.
4. 한 Apply로 연결된 union을 만들고 입력을 숨김. 선택 밖/숨김 원본 제안과 취소 뒤 늦은 응답을 거절.
5. STEP를 출력하고 실제 페이지 reload로 캐시 문서를 다시 읽어 같은 원본 그래프·체적을 확인.

기대 체적은 돌출 `80*50*20=80000`mm³, 관통 구멍 `80000-180*pi`, 최종 union `84000-180*pi`mm³다. 추가 박스는 30×20×20mm, world (60,20,0)에 놓여 기존 형상에 10×20×20mm 부피를 더한다. 허용오차는 0.001–0.002mm³다. 최종 수치는 [검증 manifest](../verification/CAD-TOOLS-01-2026-10-19.json)에 기록한다.

## 범위

gateway 연결/왕복은 fixture로 검증했으며 실제 모델 provider·서버·인증은 연결하지 않았다. 이 catalog는 브라우저 계획 프로토콜이며 MCP 서버 설치나 headless 패키지 분리를 완료한 것이 아니다. 원점 평면의 사각형/원과 일반 돌출, Boolean, 기존 선택 body의 면 Hole이 첫 범위다. 새 body를 먼저 Apply한 뒤 면 조회를 수행하며, 임의 면 identity 추측이나 자동 repair는 하지 않는다. 명시적 solver/위상 문제는 기존 수동 편집·복구로 인계한다.
