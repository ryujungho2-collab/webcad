# 문서 구조 정리

2026-10-17. [계획서 정합성 정리](PLAN-CONSISTENCY-2026-10-17.md)에 이어 진입 문서와 상세 기록을 분리했다. 제품 기능·우선순위·과거 검증 결과는 변경하지 않았다.

## 변경

- PROJECT-STATE는 현재 지원 요약·최신 제품 검증·남은 경계만 남겼다.
- NEXT-STEPS는 현재 큐·WF-Q1 완료 조건·별도 확장/담당 경계를 남겼다. 완료 이력과 전체 B/X/G/I 표는 history로 분리했다.
- docs/README는 목적별 진입점과 분류별 색인으로 바꿨다. 각 폴더 색인은 Markdown/검증 JSON의 전체 목록이다.
- [기존 상태](../history/PROJECT-STATE-2026-10-17.md), [기존 큐](../history/NEXT-STEPS-2026-10-17.md), [기존 안내](../history/DOCUMENT-INDEX-2026-10-17.md)는 전체 본문을 보존하고 상대 링크만 새 위치에 맞췄다. 루트의 이전 상세 제목 앵커에는 보존본 안내를 남겼다.
- 기존 구현·검증·제품·구조 파일의 경로는 유지했다. README의 오래된 최근 기능 나열은 현재 상태와 구현 색인으로 연결했다.
