# 기능 설명 통합

2026-10-17. 파일 색인만으로 해결되지 않았던 기능 설명 분산을 정리했다. 현재 설명의 기준은 [기능별 가이드](../features/README.md)다. 제품 코드와 실행 우선순위는 변경하지 않았다.

## 설명 소유권

프로젝트·작도·솔리드·평면도/건축 콘텐츠·도면/출력·이미지/장면·Copilot의 7개 대표 문서가 현재 사용법·지원/미지원·근거를 관리한다. 공유 기능은 다른 대표 문서로 연결한다. 예를 들어 Copilot은 벽 생성 절차를 복사하지 않고 평면도 가이드로, 평면도 가이드는 시트 발행을 출력 가이드로 연결한다.

| 기존 중복 | 변경 |
| --- | --- |
| 상태 문서의 기능/한도 상세 표 | 상태와 대표 가이드 링크만 유지 |
| CAD-BASICS의 누적 기능표 | 대표 가이드 안내로 변경. 기존 본문·제목 앵커는 보존본으로 연결 |
| 평면도 계획의 기반/공백·완료 카드 설명 | 현재 가이드 링크로 대체하고 후속 목표·선행·완료 조건을 유지 |
| 워크스페이스 계획의 완료 H1/H2/P2 재설명 | 프로젝트 가이드로 대체하고 최초 설계/담당 계약은 보존 |
| 통합 제작 로드맵의 현재 기능 나열 | 해당 대표 가이드로 대체 |
| 구현 기록 94개·Markdown 검증 기록 15개 | 맨 위에 대표 가이드와 당시 기록임을 표시. 본문·수치는 보존 |
| 날짜별 목록 중심 진입 | 위키 홈/README에서 현재 기능 가이드를 우선 안내 |

예전 CAD 기능표의 타원/스플라인·기준점 복사 미지원 문구는 과거 기록으로 보존하고, 대표 작도 가이드에 후속 pilot의 실제 지원과 제한을 통합했다. 단일 슬롯을 범용 Flex, AABB 경고를 정확 거리로 확대하지 않았다.
