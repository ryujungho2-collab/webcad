# CAD-LAYER-01 — Layer isolation

최종 검증: 2026-11-07 (Asia/Seoul). 작업 범위는 CAD-LAYER-01에 한정했다. 다음 카드, 새 커널·명령·MCP·문서 포맷은 추가하지 않았다.

## 구현 결과와 사용법

1. 객체를 하나 또는 여러 개 선택한다.
2. **Layers → Isolate selected layers**, 또는 **Ctrl+K → Isolate selected layers**를 실행한다. 팔레트에서 `레이어`, `LAYISO`, `LAYUNISO`로도 검색 가능하다. AutoCAD 명령행 실행 지원은 아니다.
3. 선택 객체가 속한 레이어의 가시 객체만 뷰포트에 남는다. 배너는 `Layer isolated view`로 현재 모드를 표시한다.
4. **Exit layer isolation** 또는 배너의 **Exit isolation**으로 필터를 해제한다.

빈 선택에서는 진입 버튼이 비활성화된다. 같은 활성 모드를 다시 실행하면 해제하며, 객체 격리와 레이어 격리는 서로 교체한다. 기존 Show all은 필터를 해제한 뒤 기존 `show-all-objects` 명령을 실행한다.

## 상태 정책

- 격리는 App의 임시 상태다. `CadDocument`의 레이어/객체 가시성 및 잠금을 바꾸지 않고 revision·History를 만들지 않는다. 파일에도 저장하지 않는다.
- 원래 숨긴 객체/레이어는 계속 숨겨지고 잠긴 레이어는 계속 선택·편집할 수 없다. Explorer 전체 목록은 유지하지만 격리 밖 객체의 선택은 거부한다.
- 대상 레이어에 추가되거나 이동한 객체는 자동 포함되고, 다른 레이어 객체는 제외된다. 대상 레이어 삭제 시 남은 ID만 유지하며 모두 삭제되면 해제한다. 삭제 후 Undo로 복원된 레이어를 격리 대상으로 자동 재추가하지 않는다.
- 격리 중 명시적으로 수행한 가시성 변경은 정상 CommandBus/Undo/Redo를 사용한다. 격리 해제는 그 편집을 되돌리지 않는다.
- 같은 ID 파일 재열기·새 문서·재로드는 격리를 해제한다. 기존 호스트의 유효한 프로젝트 비활성화 신호도 해제한다. 해당 신호는 탭 전환 외에 홈 이동·브라우저 숨김에서도 올 수 있다.
- 기존 문서 기반 SVG/PDF/DXF 출력 정책은 유지한다. 이번 임시 화면 격리는 출력 범위를 줄이는 기능이 아니다.
- 별도 Scene Graph, Visibility Engine, 문서 스키마 마이그레이션은 없다.

## 온톨로지

`layer-isolate`: `supported`, `kind: interaction`, `executor: ui-state`, `targetKinds: [layer, selection]`. 새 명령/MCP가 없으므로 `commandTypes`와 `mcpTools`는 빈 배열이다. UI 경로, 빈 선택 조건, 숨김·잠금 보존, 비저장·비History·출력 불변 정책과 코드/테스트 근거를 기록했다.

`capabilityInventory()`로 [JSON](WEBCAD-CAPABILITY-INVENTORY.json)을 생성했다. 현재 기능 87개 중 supported 45 / partial 23 / unconfirmed 19. 2026-11-05의 단축키 120개 판정 16/50/31/23은 그대로 유지한다. 승격은 097/098의 기존 기능 하나에만 해당한다.

새 단위 검사 7개는 격리 중 새 객체/레이어·레이어 이동, 대상 삭제/전체 삭제, 문서·revision·History·출력 불변, 숨김/잠금, 같은 ID 재열기와 새 문서 전환을 실제 명령과 함께 확인했다. 브라우저 저장/재열기는 실제 파일 input을 사용했고 재로드는 기존 로컬 캐시 저장 API를 사용했다. 디스크 다운로드 완료를 검증한 것은 아니다.

프로젝트 관련 브라우저 검사는 기존 host activity 메시지의 유효/오래된 세션 처리를 확인했다. 실제 여러 프로젝트 탭을 클릭하는 전체 워크스페이스 E2E는 이번 실행 범위 밖이다. 순수 필터의 멤버십/잠금 검증과 브라우저 UI 검증을 구분한다.

초기 브라우저 실패 2건은 테스트 하네스 문제였다. 첫째는 허용되지 않은 업로드 fixture 파일명이며 기존 허용 이름 `prepared.webcad.json`을 사용하도록 수정했다. 둘째는 파일 재열기가 이미 Model 패널을 여는데 테스트가 같은 버튼을 다시 눌러 패널을 닫은 문제였다. 불필요한 토글을 제거했다. assertion 삭제·완화·skip으로 통과시키지 않았다. 최종 실행에서 미해결 실패는 없다.

## 미실행·미지원 및 종료

전체 단위 suite, 전체 제품 브라우저 감사, 대형 문서 성능 벤치마크, 별도의 3D BRep/Mesh 격리 E2E는 실행하지 않았다. 기존 뷰포트 필터를 공용으로 사용하지만 이번 실제 화면 증거는 작은 2D 도형 fixture다. 스냅 필터 코드는 포함했으나 개별 스냅 모드별 브라우저 검증은 하지 않았다.

레이어 동결, 전체 켜기, 특성 복사, 새 기본 단축키, 명령행, MCP 격리, 해석 온톨로지 확장은 구현하지 않았다. CAD-LAYER-01의 제한된 UI 기능·온톨로지·관련 검증을 완료하고 종료한다. 다음 카드는 시작하지 않았다.
