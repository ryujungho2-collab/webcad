# CAD-STYLE-01 — 2D 벡터 특성 복사

2026-11-07 검증 완료.

## 사용자 동작

2D 작업 공간에서 원본 도형 하나를 선택하고 Ctrl+K로 팔레트를 열어 **Match vector appearance**를 실행한다. 속성과 대상을 고르고 **Preview appearance match**를 누르면 대상별 이전 값과 적용 예정 값을 확인할 수 있다. **Apply appearance match**로 확정하고 **Cancel appearance match**로 취소한다.

| 속성 | 지원 범위 |
| --- | --- |
| 선 색상, 불투명도, 선 굵기 | XY 평면의 일반 선, 폴리라인, 사각형, 원, 호 |
| 채우기 | 닫힌 폴리라인, 사각형, 원 사이의 단색 또는 채우기 없음. 원본 그라디언트는 Fill을 선택하면 거부 |

대상은 보이는 최상위 도형 중 하나 이상이다. DXF 스타일이 있는 도형, 보조선, 모델 투영, 다른 평면은 지원 범위 밖이다.

## 적용 정책

- 원본 객체에 명시값이 있으면 그 값을 쓴다. 선 색상과 굵기에 명시값이 없으면 레이어의 표시값을 쓴다. Preview가 그 시점의 값을 확정한다.
- 원본이 파란색을 상속받고 대상이 빨간색과 0.5 mm 굵기를 상속받는 경우, 선 색상만 복사하면 대상은 자기 레이어에서 명시적 파란색과 상속된 0.5 mm 굵기를 사용한다. 이후 대상 레이어의 굵기 변경도 반영된다.
- 선택된 Fill은 단색 또는 채우기 없음으로 적용한다. 기존 대상의 그라디언트도 Fill의 일부로 함께 교체한다.
- 잠긴 대상, 사라지거나 숨겨진 대상, 미지원 도형이 섞이면 전체 배치를 거부한다. Preview 이후 문서가 변경되면 다시 검토해야 한다. 적용 전 취소는 준비된 계획을 버린다.
- 배치 한 건을 History 한 항목으로 게시한다. 한 번의 Undo와 Redo로 모든 대상의 스타일을 복원하고 다시 적용할 수 있다.
- 현재 버전은 기존 전체 스타일과 새 부분 스타일을 모두 읽는다. 부분 스타일의 저장·재로드를 집중 테스트로 확인했다. **이전 앱 빌드는 부분 스타일이 들어 있는 새 파일을 거부할 수 있다.** 파일 버전과 다운그레이드 변환은 이번 범위에 포함하지 않았다.
