## 저장 상태와 진행 상태

편집기 하단 **Save and download status** 버튼에서 현재 로컬 저장 상태와 파일 다운로드 상태를 따로 확인한다. 실패하면 **Retry local save**, 정상 상태에서는 **Save locally**로 같은 저장 경로를 호출한다. **Download WebCAD file**은 현재 프로젝트의 휴대 가능한 파일을 내려받는다. 로컬 저장 완료는 이 브라우저의 복구본 저장이며 다운로드 시작은 디스크 기록 완료를 뜻하지 않는다. 파일 다운로드 완료는 브라우저에서 확인한다.

기하 작업 상태는 실제 Worker의 대기·로딩·생성·표시 준비·엣지 읽기·측정 단계를 표시한다. 백분율을 추정하지 않는다. **Cancel tasks**는 이 프로젝트의 대기/실행 중 기하 작업을 취소한다. 이미 완료한 편집은 Undo에 남으며, 취소가 이전 편집을 되돌리는 동작은 아니다. 저장소 transaction과 파일 다운로드를 취소하는 버튼도 아니다. 작업 취소 후 새 명령을 실행할 수 있다.

Review의 다음 행동은 상태 영역으로 알리고 적용 중에는 busy 상태를 표시한다. 작업별 Review/Apply·잠금·stale 판정과 문서 transaction이 실제 적용을 결정한다.

## 키보드 사용

| 상황 | 동작 |
| --- | --- |
| 기능과 단축키 찾기 | 편집기에서 Ctrl+K → 기능명 입력 → 위/아래 → Enter. Shortcuts에서 입력·탐색 안내를 검색한다. |
| 프로젝트 이름 변경 | 프로젝트 탭에 포커스를 두고 F2. Esc로 초안을 취소하고 탭으로 돌아간다. |
| 도구 그룹·저장 상태 열기 | Tab으로 버튼에 이동한 뒤 Enter 또는 아래 화살표. 첫 사용 가능한 입력/버튼으로 이동한다. |
| 펼친 도구 그룹 | 위/아래·Home/End로 버튼 이동, Tab/Shift+Tab으로 입력 필드 방문. 입력 필드의 화살표는 필드가 소유한다. |
| 메뉴·팝오버 종료 | Esc로 닫는다. 메뉴에서 키보드로 이동한 경우 호출 버튼으로 돌아간다. 포인터로 연 팝오버도 Esc가 CAD 선택을 해제하지 않는다. |
| 숫자 편집 | 지원되는 필드에 mm/cm/m/in/ft 입력 → Enter/필드 이탈로 적용, Esc로 현재 초안 취소. 세부 규칙은 [속성 패널](PROPERTIES.md)을 따른다. |
| Undo/Redo | Ctrl+Z, Ctrl+Y 또는 Ctrl+Shift+Z. 텍스트/숫자/선택 입력과 modal은 자체 입력 범위를 유지한다. |
| 로컬 저장 / 파일 다운로드 | Ctrl+S / Ctrl+Shift+S. 텍스트 입력이나 modal이 활성 상태면 입력을 먼저 마친다. |

한글 IME 조합 중 및 호환 keyCode 229에서는 전역 CAD·History·명령 검색 실행을 가로채지 않는다. Home·프로젝트 탭·복구 관리의 키보드 경로는 [프로젝트 가이드](PROJECTS.md)를 따른다. 명령 검색·프로젝트 관리·이름 변경 modal은 native focus containment를 사용하며 닫힐 때 다른 컨트롤이 이미 포커스를 받았다면 이를 빼앗지 않는다.

## 화면과 지원 경계

키보드 포커스에 명시적인 테두리를 표시하고, 상태는 색상과 함께 문구로 구분한다. 저장 세부 팝오버는 하단에서 위로 열리며 화면 안으로 제한한다. 960px 및 640×667 CSS px의 150% 상당 화면을 검증했다. 좁은 편집기 하단은 두 줄로 배치하고 정밀 설정은 가로 스크롤할 수 있다.

현재 검증은 Edge의 실제 pointer/key/IME 입력, DOM 상태와 화면 확인이다. 스크린리더의 실제 음성 출력, 모든 운영체제/브라우저, 제품 전체의 접근성 표준 인증은 포함하지 않는다. 모든 CAD 도구의 캔버스 pointer 제스처를 키보드로 대체하는 기능도 아니다. 상태·입력 UI를 탐색하는 것만으로 문서 revision·형상·Undo를 추가하지 않는다.
