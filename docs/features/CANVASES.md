# 상위 캔버스와 소유·참조 계층

[프로젝트 안내](../../NEXT-STEPS.md) · [프로젝트와 저장](PROJECTS.md) · [도면과 출력](DRAWINGS-OUTPUT.md)

## 시작하기

왼쪽 **Project navigation → Canvases**에서 **Organize existing document → Apply canvas changes**를 사용하면 기존 문서를 계층으로 정리한다. 모델 원본은 모델 캔버스, 작업 구역·시트·일반 프레임은 종이 캔버스로 나눈다. 투영/단면·장면은 기존 원본을 참조한다. 원본 ID, 모델 좌표, Section/Frame 멤버·crop·축척은 바꾸지 않는다. 기존 파일을 열었다는 이유만으로 자동 변환하지 않는다.

**New canvas**에서 이름·단위 공간·작업면·경계를 정하고 Target kind/Target/Relation을 선택해 **Add canvas member**로 추가한다. 선택한 모델은 **Add selected objects**로 담을 수도 있다. **Review canvas → Apply canvas changes**로 적용하며 Cancel/Esc는 미확정 변경을 버린다. 변경은 한 번의 Undo/Redo로 복원한다.

## 소유와 참조

- **Own**은 계층의 소유 관계다. 같은 대상은 한 캔버스에서만 소유한다. 작업 구역이 소유한 프레임과 시트의 종이 아트보드도 별도로 중복 소유할 수 없다.
- **Reference**는 원본을 공유하는 링크다. 여러 캔버스에서 같은 모델·프레임·뷰를 참조할 수 있다. 모델/종이 공간이나 작업면을 넘는 연결에는 참조를 사용한다.
- **Parent**는 현재 캔버스의 소유 부모를 바꾼다. Document root는 최상위로 해제한다. 소유 부모는 하나이며 소유와 참조를 통한 캔버스 순환은 모두 거부한다.
- 대상 종류는 캔버스, 모델 객체, 아트보드/프레임, 작업 구역, 모델 투영/단면/시트, 장면이다. 프레임의 모델 멤버는 계속 표현 참조이며 캔버스 소유를 이유로 모델 원본을 가져오거나 복제하지 않는다.

## 단위와 화면

**Model · mm**는 모델 공간, **Paper · mm**는 종이 공간이다. 숫자 단위가 모두 mm여도 자동으로 같은 공간으로 변환하지 않는다. 다른 단위 공간/작업면의 소유는 거부하며 참조는 허용한다. 기존 프레임 축척이 모델과 종이 사이의 표현을 계속 담당한다.

캔버스 경계는 해당 작업면의 **절대 좌표**다. 부모 변경이나 경계 편집은 자식의 좌표·치수·축척을 바꾸지 않는다. 2D 뷰에서 모델 경계는 청록, 종이 경계는 황갈색 점선으로 표시한다. 트리의 캔버스 이름을 누르면 경계를 화면에 맞추며 참조 항목을 누르면 기존 모델/뷰/프레임으로 이동한다. 검색은 하위 항목과 상위 소유 계층을 함께 보여준다. 접기는 탐색 UI만 바꾸며 모델·출력을 숨기지 않는다.

## Flex 배치 · CAN-A2

캔버스를 **Edit → Enable Flex**로 설정한다. **Row(+X) / Column(+Y)**, Wrap, Gap, Padding, Alignment, Distribution을 고르고 **Review Flex layout → Apply canvas changes**로 배치한다. 좌표는 해당 작업면의 양의 X/Y 방향이다. 설정과 전체 배치는 한 번의 Undo로 되돌린다. **Review canvas**는 설정만 저장하며 실제 재배치에는 Review Flex layout을 사용한다. 콘텐츠·경계를 수정한 뒤에도 명시적으로 다시 검토한다.

- **Fixed:** 지정 크기 또는 기존 원본/캔버스 크기다.
- **Hug:** 흐름 항목과 간격·여백을 감싸는 크기다. 절대 배치 항목은 계산에서 제외한다.
- **Fill:** 남은 내부 공간을 weight 비율로 분배한다. min/max에 도달한 항목의 남은 공간은 다른 Fill 항목으로 재분배한다. 교차축 Fill은 해당 줄의 공간을 사용한다.
- 항목별 규칙을 펼쳐 Flow/Absolute, 축별 Fixed/Hug/Fill·min/max·weight를 설정하고 Earlier/Later로 순서를 바꾼다. Absolute는 기존 위치를 유지하거나 소유 항목에 한해 명시적 offset을 준다.

소유 하위 캔버스·일반 종이 프레임·작업 구역은 기본 Flow다. 모델 원본·공유 참조·시트·장면/투영은 기본 Absolute다. 공유 참조는 원본에 고정하며 배치하려면 소유한 표현 프레임을 만든다. 시트·장면·연관 뷰의 직접 이동은 각 소유 도구를 사용한다. 연결 프레임은 전체 연결 트리를 담은 작업 구역으로 함께 이동해야 한다.

Fixed/Hug/Fill은 **배치 상자** 크기다. 프레임과 모델을 상자에 맞춰 늘리거나 자르지 않는다. 프레임의 종이 크기·crop·축척과 원본 CAD 치수는 유지하며, 흐름 상자가 원본보다 작으면 거부한다. 하위 캔버스 경계는 계산 크기로 조절하고 구성된 하위 Flex는 재배치한다. 원본 객체를 Flow로 옮기려면 **Explicitly allow original model translation**을 선택해야 한다. 기존 CAD 이동 명령과 잠금/종속 검증을 거치며 모델 치수나 scale은 변경하지 않는다.

검토 화면은 제안 위치·상자 크기와 항목별 번호를 보여 준다. 흐름 넘침, Hug/Fill 의존 순환, Hug 주축의 Wrap, 부모 크기가 없는 Fill, 단위/작업면 불일치, 잠금과 연결 프레임의 부분 이동은 거부한다. 절대 항목 넘침은 경고로 표시하며 조용히 clipping/resize하지 않는다. 자식의 Hug/Fill 의존은 부모 멤버의 명시적 Fixed 경계로 해소할 수 있다.

Flex 설정과 항목 규칙이 있는 파일은 **v44**다. 기존 v43 계층과 v1–v42 문서는 그대로 읽는다. Flex 구성은 로컬 복구·portable 파일·프로젝트 묶음에 포함된다. 내용 비례 확대는 아래 CAN-A3의 별도 조작이다. [CAN-A2 구현·검증](../implementation/CAN-A2-FLEX-LAYOUT-2026-10-18.md).

## 콘텐츠 비례 확대 · CAN-A3

캔버스를 **Edit → Scale contents**에서 열고 **Uniform factor**를 입력한 뒤 **Review Scale contents → Apply canvas changes**를 사용한다. `2`는 두 배, `0.5`는 절반이다. 검토에서 변경 전후 크기·축척과 최대 네 개 프레임의 실제 제안 출력을 확인한다. Cancel/Esc는 변경을 버리며, 전체 적용은 한 번의 Undo/Redo다.

세 조작은 구분된다. **Review canvas**의 Size는 컨테이너 경계만 바꾼다. **Review Flex layout**은 배치 상자를 재계산한다. **Scale contents**는 루트 캔버스 원점을 고정하고 소유 콘텐츠의 상대 위치와 크기를 같은 비율로 바꾼다. 하위 캔버스, 작업 구역 경계, Flex gap/padding·고정값·min/max·offset도 비례 조정하며 모드와 Fill weight는 유지한다. 자동 Flex reflow는 실행하지 않는다.

종이 캔버스의 소유 일반 도면 프레임은 종이 크기와 위치를 조정하고 축척 분모를 factor로 나눈다. 원본 CAD 좌표·치수·구속·반지름·텍스트 정의와 프레임 sourceOrigin은 바꾸지 않으므로 같은 원본의 다른 프레임은 영향을 받지 않는다. 프레임의 지원 곡선·테두리·채움·글자는 표현 공간에서 확대된다. 기본값은 글자와 선 굵기·점선 간격도 확대한다. **Keep text and line weights in paper units**는 종이상의 글자·선 굵기·점선 간격을 고정한다. 누적 스타일 계수를 저장하므로 반복 확대·축소와 재열기에서도 선택 결과를 유지한다. 뷰포트 프레임·SVG·PDF는 같은 출력 항목을 사용한다.

모델 단위 캔버스의 소유 이미지 배치는 **Include image placements**로 포함/제외한다. 포함하면 위치와 표시 크기만 변경한다. 원본 bitmap·hash·asset ID·crop·mask·투명도·색 보정은 유지하며 이미지를 재생성하지 않는다. 색 보정 값은 길이 단위가 아니므로 변경하지 않는다. 별도 길이 속성인 shadow/blur 효과는 현재 문서 모델에 없으며 추가 지원으로 간주하지 않는다.

공유 참조와 제외 이미지는 그대로 두며 검토에 제외 이유를 표시한다. 직접 소유 CAD 객체는 물리 치수를 바꾸지 않고 **소유 도면 프레임을 만들도록 안내**한다. 서로 다른 단위·작업면, 잠금/숨김 프레임, 연결·연속 프레임과 발행 시트가 소유한 배치는 거부하며 해당 소유 도구에서 해제/편집해야 한다. X/Y 비균등 확대는 지원하지 않으므로 원·호를 임의 타원으로 바꾸거나 구속을 깨지 않는다. 배율은 0.001–1000이고 결과 경계·축척·스타일의 기존 예산을 넘으면 전체 적용을 거부한다.

프레임 스타일 계수를 포함한 문서는 **v45**로 저장한다. 이전 버전으로 가장한 파일은 거부하고 로컬 복구·portable·프로젝트 묶음에서 그대로 복원한다. [CAN-A3 구현·검증](../implementation/CAN-A3-CONTENT-SCALE-2026-10-18.md).

## 잠금과 삭제

**Lock canvas hierarchy**는 해당 캔버스와 소유 하위 캔버스의 계층 편집을 막는다. **Review unlock canvas → Apply canvas changes**로 해제한다. 원본 CAD의 레이어/프레임 잠금은 별도이며 계층 편집이 원본 잠금을 해제하지 않는다.

**Review delete canvas**는 컨테이너와 그 컨테이너를 가리키는 캔버스 링크만 제거한다. 모델 객체와 소유 하위 캔버스는 남는다. 수정해야 하는 부모/참조 캔버스나 하위 캔버스가 잠겨 있으면 먼저 해제한다. 캔버스가 참조하는 원본을 삭제하려면 해당 멤버 관계를 먼저 해제한다. 실패·취소·stale 검토는 원본을 유지한다.

## 저장과 지원 범위

계층만 있는 문서는 **WebCAD v43**, Flex 규칙이 있는 문서는 **v44**, 프레임 표현 스타일 계수가 있는 문서는 **v45**로 저장한다. 기존 v1–v44 파일도 읽는다. 계층은 로컬 복구·portable 파일·프로젝트 묶음에 포함된다. 계층이 없는 파일로 교체하면 이전 계층이 남지 않는다. 새로고침 후 Undo는 기존 프로젝트 계약대로 새 세션이다.

상한은 256개 캔버스, 캔버스당 1,000개 멤버, 전체 5,000개 관계, 32단계다. CAN-A1은 소유·참조·단위 경계·탐색 기반이다. CAN-A2 Flex와 CAN-A3의 균등 표현 확대를 지원한다. 모델/종이 단위 자동 변환과 원본 CAD의 물리 치수 확대는 지원하지 않는다. 경계는 화면 조직용이며 SVG/PDF에 새로운 도곽으로 출력하지 않는다.
