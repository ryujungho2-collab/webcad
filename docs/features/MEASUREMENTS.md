# 거리와 측정 지점

[기능 안내](README.md) · [정밀 작도와 편집](DRAWING-EDITING.md)

## 호버 거리 · MEAS-H1

Object 선택 상태에서 기준 도형을 선택한 뒤 다른 도형이나 솔리드 위에 마우스를 올린다. 뷰포트의 **Hover distance** 패널에서 기준과 거리 방식을 선택한다. 여러 도형을 선택한 경우 Reference로 기준 하나를 고른다. 그리기·직접 편집·이동·거리 도구 등 다른 작업 중에는 호버 측정을 숨긴다.

두 실제 기하 위에 **A/B 측정 지점**과 점선을 표시한다. Measurement points를 펼치면 객체 ID·요소 ID·매개변수, world X/Y/Z, 거리의 상·하한과 오차를 확인한다. 패널에 들어가도 결과를 유지하므로 내용을 펼치고 옵션을 바꿀 수 있다. 뷰포트/패널 밖으로 나가거나 포커스를 잃으면 계산과 표시를 취소한다. **Esc**는 호버 측정을 끄며 체크박스로 다시 켠다. 선택·도형·Undo·저장 내용은 바꾸지 않는다.

## 거리 방식과 단위

| 방식 | 의미 |
| --- | --- |
| Shortest · 3D | 두 유한 도형 사이 실제 3차원 최단거리 |
| Projected · XY/XZ/YZ | 해당 world 평면에 투영했을 때의 최단거리 |
| Axis · X/Y/Z | 해당 world 축에 투영했을 때의 최단거리 |

모든 값은 **world mm**다. 각 방식에서 거리를 다시 최소화하므로 측정 지점도 달라질 수 있다. 지점은 항상 원래 3D 도형 위에 있으며 점선은 그 지점들을 연결한다. 투영/축 모드의 숫자는 그 연결선의 3D 길이가 아니다. 서로 다른 고도에서도 투영이 겹치면 0일 수 있다. 화면 크기·줌·픽셀 간격이나 외접 상자 간격으로 대체하지 않는다.

프레임/시트 그림의 종이 축척을 역변환하는 도구가 아니다. 원본 유한 도형을 선택한다. 생성된 투영/단면 도형을 측정하면 현재 저장된 도형의 world 좌표를 측정하며 원본 솔리드의 3D 치수로 환산하지 않는다. 기존 두 점 거리 도구와 구동 치수 편집의 동작은 바꾸지 않는다.

## 정확도와 지원 도형

유한 점·선·폴리라인·사각형, 원·부호 있는 호·bulge 호, 타원/타원호, 양의 가중치 유리 스플라인을 지원한다. 원본 파라미터와 전체 affine 변환을 사용하므로 회전·고도·반사·비균등 확대를 반영한다. 원의 비균등 변환도 원래 곡선의 변환으로 계산한다.

- **Analytic · 선형:** 점/유한 선분 사이를 직접 계산한다. 수치 연산의 오차 여유를 상·하한에 포함한다.
- **Bounded · 허용 오차 내:** 실제 곡선 지점으로 상한을 구하고 곡선의 chord/hull 경계로 하한을 계산한다. 기본 요청 오차는 0.001 mm다.
- **Approximate · 근사:** 계산 예산 내에 오차 폭이 충분히 줄지 않았다. `≈`와 근사 표시, 남은 오차 범위를 함께 제공한다. 정확 결과로 표시하지 않는다.

경계 계산은 부동소수점 기하와 수치 오차 여유를 사용하며 임의 정밀도 interval arithmetic은 아니다. 매우 큰 좌표에서는 표시되는 오차 폭이 요청 오차보다 클 수 있다. 허용 범위가 필요한 작업은 숫자와 함께 Error/Range를 확인한다.

메시·이미지·치수/주석 외곽·블록 인스턴스·무한 직선/반직선은 거리 계산을 제공하지 않는다. `Unavailable`과 이유를 표시하며 AABB나 렌더 메시를 실제 CAD 거리로 보고하지 않는다. 유한 도면의 거리는 경계 사이 거리이며 채워진 2D 영역의 포함 판정이 아니다. 닫힌 솔리드는 아래 별도 BRep 계산을 사용한다.

## 레이어 대상과 계산 수명

Target을 **Hovered layer · nearest**로 바꾸면 마우스 아래 객체의 레이어에서 실제 최근접 객체를 찾고 이름·ID를 표시한다. 기준 객체 자신은 제외한다. 문서상 보이는 객체/레이어와 현재 뷰포트에서 보이는 객체만 포함하며 격리/숨김을 반영한다. 잠긴 레이어는 기본 제외하고 **Include locked layers**로 명시적으로 포함한다. 원본을 수정하는 옵션이 아니다.

지원하지 않는 대상은 이유와 함께 제외 목록에 표시하고 **nearest supported object**로 한정한다. 지원 대상이 없으면 결과를 표시하지 않는다. 레이어 전체의 정확한 거리로 오인하지 않도록 제외 항목을 확인한다. 유한 도면은 한 레이어의 적격 객체가 32개를 넘으면 거부하며 더 작은 레이어/객체 범위를 사용하도록 안내한다.

80ms 호버 대기 후 계산한다. 유한 도면 계산은 작업을 나누어 취소할 수 있다. 객체당 곡선 조각 512개, 초기 조각 쌍 16,384개, 한 쌍 계산 20,000회, 레이어 쿼리 80,000회 평가 예산을 사용한다. 예산 초과는 근사/제외/거부로 명시한다. 결과 cache는 뷰포트당 최대 64개이며 문서 ID·revision·세션 generation·객체 컬렉션과 정책/거리 방식·기본/명시 허용 오차로 구분한다. 편집·Undo·프로젝트 교체·대상 변경 시 이전 결과를 재사용/발행하지 않는다. 결과는 저장 파일이나 출력에 추가하지 않는다.

## 솔리드/BRep 거리 · MEAS-H1 후속

닫힌 솔리드를 기준으로 선택하고 다른 솔리드에 호버한다. **Shortest · 3D**에서 **OCCT · BRep**로 표시한다. 원본 BRep의 실제 face/edge/vertex 위 A/B를 구하며 렌더 삼각형·AABB 거리를 사용하지 않는다. 이동·회전·양의 비균등 확대, 기존 Boolean/돌출 등 지원 BRep 생성 경로의 world 변환을 반영한다.

기본 숫자와 점선은 **Boundary gap: 두 표면 경계의 최단거리**다. 별도로 **Material separation: 재료 영역 간 분리 거리**와 떨어짐·접촉 범위·관통·A/B 포함·허용 오차 내 일치·판정 불가를 표시한다. 포함된 물체의 표면 사이에 4 mm가 있어도 재료 분리는 0일 수 있다. 이 양수 경계 간격을 가구·부품을 놓을 수 있는 자유 공간으로 해석하지 않는다. 빈 Boolean cavity 안의 물체는 재료 영역이 겹치지 않으면 떨어짐으로 판정한다.

관계는 공통 BRep 체적으로 판정하며 **Solid classification**에서 공통 체적과 체적 허용 오차를 확인한다. 포함/일치는 체적 허용 오차를 사용하는 수치 판정이다. 접촉 범위는 실제 접촉과 선형 허용 오차 이내 간격을 포함한다. 극소 공통 체적이나 판정 실패는 **Indeterminate**로 남기며 실패 이유를 보여 준다. 공통 체적을 구하지 못하면 재료 분리는 unavailable이고, 유효한 표면 경계 거리는 유지한다. signed distance나 관통 깊이를 계산하지 않는다.

기본 커널 선형 허용 오차는 **1e-6 mm**다. 결과는 OCCT 수치 계산이며 유한 곡선 solver의 chord/hull 기반 오차 구간과 구분하며 certified interval로 주장하지 않는다. metadata의 `accuracy: brep`와 `boundKind: kernel-tolerance`가 이 차이를 나타낸다. support signature는 object/revision과 함께 읽는 기하 식별이며 편집용 영구 topology 참조가 아니다. 실제로 얻지 못한 edge/face parameter를 만들어 표시하지 않는다.

닫힌 양의 체적 솔리드 또는 솔리드만 담긴 compound를 지원한다. 열린 face/shell, free face가 섞인 compound, 메시, drawing/solid 혼합 쌍은 지원하지 않는다. 직접 선택한 subface/subedge 사이 거리와 솔리드 projected/axis 모드는 후속이며, 현재는 명시적 계산 불가 이유를 표시한다. **분해 표시와 모델 clipping을 해제**해야 화면과 원본 BRep 위치가 일치한다.

레이어 검색은 **표면 경계 거리**로 최근접 몸체를 찾는다. 솔리드 기준 레이어의 적격 대상은 최대 8개, 몸체당 32 solids/4096 faces/16단계 compound 제한이다. 유한 도면과 마찬가지로 숨김/격리와 잠금 포함 정책을 적용하고 미지원 후보를 별도로 보여 준다. 계산은 Worker에서 실행하며 active task는 Esc/대상·문서 변경으로 취소할 수 있다. 커널이 동기 계산 중이면 해당 Worker를 종료하고 다음 작업은 새 Worker에서 재시도한다. 완료된 같은 revision 쌍은 기존 호버 cache를 사용한다. 문서·선택·Undo는 변경하지 않으며 새 파일 버전도 필요하지 않다.

[BRep 구현·검증](../implementation/MEAS-H1-BREP-DISTANCE-2026-10-18.md).

## 면·모서리 지정 측정 · MEAS 후속

리본 **Direct**(F2)에서 솔리드의 면 또는 모서리를 선택하고, 화면 오른쪽 아래 **선택을 기준 A로 고정**을 누릅니다. 두 번째 대상을 선택한 뒤 **선택을 대상 B로 고정**을 누르면 3D 최단거리와 실제 A/B 측정점을 표시합니다. 면↔면, 모서리↔모서리, 면↔모서리를 지정할 수 있으며 같은 솔리드 안의 서로 다른 요소도 지원합니다. 선택 대상은 청록색·보라색으로 강조합니다. 초기화 또는 Escape로 측정을 지웁니다.

유한한 원본 BRep 면·모서리에서 OCCT로 계산합니다. 무한 평면·직선의 연장 거리, 솔리드 전체의 여유, 침투 깊이와는 다릅니다. 수치 허용 오차는 0.000001 mm이며 보증 오차 구간을 뜻하지 않습니다. 면의 삼각형과 모서리 표본은 선택·강조와 기존 참조 해석에만 사용하고 거리 계산에는 사용하지 않습니다.

편집·Undo/Redo 때 원본 형상의 참조를 다시 해석합니다. 사라지거나 모호한 참조는 재선택 안내로 처리하며 이전 측정점은 즉시 숨깁니다. 프로젝트 전환·Direct 종료 시 고정을 해제합니다. 숨김·잠금 대상, 분해 표시 및 모델 클리핑 상태는 측정을 거부합니다. 참조의 다른 면으로 자동 재연결은 제공하지 않습니다. 측정은 문서·Undo 이력을 변경하지 않습니다.

구현과 검증: [면·모서리 지정 측정](../implementation/MEAS-SELECTED-ELEMENTS-2026-10-18.md).

### 혼합 대상과 투영·축별 모드

A와 B에 면과 모서리를 섞어서 고정할 수 있습니다. **거리 모드**에서 다음 중 하나를 선택합니다.

| 모드 | 의미 |
| --- | --- |
| 3D 최단거리 | 원본 두 요소 사이 공간상 최단거리 |
| XY / XZ / YZ 평면 투영 | 지정한 월드 평면으로 투영한 두 유한 요소 사이 최소 간격 |
| X / Y / Z축 최소 간격 | 지정한 월드 축 방향으로만 비교한 최소 간격, 항상 0 이상 |

각 모드는 그 모드에서 가장 가까운 점 쌍을 새로 찾습니다. 3D 최단거리의 성분을 단순히 나누는 기능이 아닙니다. 투영 범위가 겹치면 실제 3D 높이 차가 있어도 0이 될 수 있습니다. 현재 카메라나 활성 작업 평면을 바꿔도 XY/XZ/YZ와 축은 월드 좌표 기준입니다.

A/B는 원본 형상 위의 실제 측정점입니다. 청록색 선은 선택한 거리 모드의 간격이고 P는 투영 보조점입니다. 회색 연결선은 실제 A/B의 위치 관계를 보여줍니다. P는 원본 위의 점이 아닐 수 있습니다.

투영·축별 계산은 원본 BRep를 비특이 가중 변환해 최대 3회 수치 탐색한 뒤 원본 위로 측정점을 복원합니다. 목표 수치 오차는 0.001 mm입니다. 결과의 `≈`와 상세의 수치 최소거리 추정은 보증 오차 구간을 뜻하지 않습니다. 누락 축 방향의 범위가 매우 크거나 수치 복원이 불안정하면 **근사값**으로 명시합니다. 근사값에는 추정 구간과 목표 오차 미달 상태를 확인할 수 있습니다. 계산이 실패하면 오류를 표시하며 3D 결과로 대신하지 않습니다.

이 모드들은 Direct의 **지정 측정**에 적용됩니다. 솔리드 전체 hover 측정은 기존 3D 경계 거리 모드를 유지합니다.

구현·검증: [혼합 측정 및 투영·축별 거리](../implementation/MEAS-MIXED-PROJECTED-DISTANCE-2026-10-18.md).

## 측정 결과 고정·치수화

Direct(F2)에서 A/B와 거리 모드를 지정한 뒤 **측정 고정·치수화** 영역에 이름, 출력 평면, 치수선 X/Y 오프셋(mm)을 입력하고 **측정 저장**을 누릅니다. 측정 도구를 종료해도 치수선·화살표·값이 남습니다. 오프셋은 모델 mm이며 저장한 월드 XY/XZ/YZ 평면에 치수를 배치합니다. 3D 측정값과 그 평면에 투영한 선 길이는 다를 수 있어 치수 문구에 3D/XY/XZ/YZ/X/Y/Z 모드를 표시합니다. 투영 수치 결과는 `≈`, 정밀도 미달은 `approx.`를 유지합니다.

오른쪽 위 **저장된 측정**에서 현재 값과 참조 상태를 확인합니다. Direct 모드에서 **편집·재지정**을 누르면 같은 저장 항목을 불러옵니다. 이름·배치·모드를 수정하거나 A/B를 다시 선택한 뒤 **측정 갱신**합니다. **새 측정으로 저장**은 별도 항목을 만듭니다. 체크박스는 화면 표시와 출력을 함께 제어하며 삭제·갱신·표시 변경은 모두 Undo/Redo가 됩니다.

형상·배치 변경 시 원본 BRep 참조를 확인하고 값을 갱신합니다. 참조 삭제·키 변경·숨김/잠금·분해 표시·클리핑 등으로 계산할 수 없으면 **재지정 필요**와 이유를 표시하고 이전 치수를 숨깁니다. 유효한 원래 형상을 Undo하면 값도 복원됩니다. 다른 면으로 자동 연결하지 않습니다. **저장 측정 다시 계산**으로 명시적으로 재검증할 수도 있습니다.

프로젝트 파일에는 정의와 원본 정의에 연결된 계산 결과를 저장합니다. 도면 연결 없는 저장 측정 파일은 **version 46**, 도면 연결을 사용하면 **version 47**이며 이전 리더는 파일을 거부해야 합니다. 이전 프로젝트는 기존 버전을 유지합니다. 프로젝트당 최대 32개를 지원합니다. 읽기·화면 렌더링·출력만으로 문서나 이력이 바뀌지는 않습니다.

같은 출력 평면의 저장 치수는 일반 아트보드 SVG·PNG·PDF 장면에 포함됩니다. 원본을 제한한 출력은 A/B 원본이 모두 범위에 포함되어야 합니다. 표시 중인 치수에 무효 참조가 있으면 출력은 오류를 내며, 재지정·다시 계산하거나 치수를 숨긴 뒤 출력합니다. 프레임/모델 시트의 출력 소유 범위를 자동 확장하지 않습니다. 모델 시트에 출력하려면 아래 **출력 도면** 연결을 지정합니다. 현재 저장은 BRep 지정 측정에 적용하며 유한 도면 hover 거리의 자동 치수 변환은 포함하지 않습니다.

### 치수선 직접 배치·편집

저장된 **치수선 또는 문구**를 클릭해 선택하고 끌면 치수 전체가 이동합니다. 이동 중에는 연장선·화살표·문구의 미리보기와 평면 X/Y 오프셋(mm)을 표시합니다. 마우스를 놓을 때 한 번 확정하며 Undo 한 번으로 원래 위치를 복원합니다. 문구와 치수선은 함께 이동하고 측정 원본·값·A/B 참조는 변경하지 않습니다.

선택한 치수에 키보드 포커스가 있으면 방향키는 저장 평면에서 1 mm, Shift+방향키는 10 mm, Alt+방향키는 0.1 mm 이동합니다. Delete/Backspace 또는 **선택 치수 삭제**는 치수 항목만 삭제합니다. Ctrl/Cmd+Z와 Ctrl/Cmd+Shift+Z로 배치 Undo/Redo를 사용할 수 있습니다. Escape는 진행 중인 배치를 저장하지 않고 취소하며, 클릭만 하고 놓으면 이력을 만들지 않습니다. 빈 캔버스를 클릭하면 치수 선택을 해제합니다.

이동은 현재 작업 평면이 아니라 치수에 저장된 출력 평면을 사용합니다. 원근/직교 화면과 확대율에 맞게 포인터를 그 평면에 투영합니다. 평면이 화면에 거의 옆으로 보이면 드래그를 거부하고 회전 안내를 표시합니다. 기존 X/Y 오프셋 숫자 편집도 사용할 수 있습니다.

드래그 중 모델 편집·Undo·프로젝트 전환·화면 크기 변경·카메라 변화·창 포커스 상실·포인터 취소가 발생하면 미리보기를 취소합니다. 휠은 미리보기를 취소하고 기존 캔버스 탐색으로 연결합니다. 다른 작성 도구 사용 중에는 치수의 포인터 편집을 비활성화합니다.

미리보기는 프로젝트와 SVG/PDF 출력을 변경하지 않습니다. 확정한 배치는 저장 오프셋으로 저장되고 프로젝트 재열기 및 출력에 반영됩니다. 문구만 따로 옮기는 배치, 스냅·자동 겹침 회피는 이번 개선에 포함하지 않습니다.

### 치수 배치 스냅·겹침 정리

치수를 선택한 뒤 드래그하면 같은 출력 평면의 유효한 **평행 치수선**에 정렬합니다. 8px 이내의 보정에서 스냅하며 초록색 기준선과 상태 안내를 표시합니다. 문구·간격이 아니라 실제 치수선의 법선 위치를 맞춥니다. **정렬 스냅** 체크로 끄거나, 드래그 중 **Alt**로 잠시 해제할 수 있습니다.

드래그 중 **Shift**는 처음 이동량이 큰 저장 평면 X/Y 축을 선택하고, 키를 놓을 때까지 그 축을 유지합니다. 스냅도 이 고정을 벗어나지 않습니다. 기존 Shift+방향키 10 mm 이동은 유지합니다. 원근·직교·확대율이 바뀌어도 확정 값은 모델 mm이며, 8px는 마우스 스냅 감도에만 사용합니다.

문구끼리 또는 다른 치수의 선이 문구 영역을 지나는 경우 문구 테두리와 **겹침 N개** 안내를 표시합니다. 겹침은 화면의 추정 글자 영역으로 판단하며 PDF의 글꼴·배율에 대한 검사나 실제 모델 충돌 판정은 아닙니다.

선택 치수의 **간격 mm**를 지정하고 **간격 정리 미리보기**를 누르면 같은 출력 평면의 유효한 평행 치수를 일정한 법선 간격으로 배치합니다. 선택한 치수를 고정점으로 유지하고, 기존 순서와 접선 방향 배치를 보존합니다. 숨김·무효 참조·다른 평면·평행하지 않은 치수는 포함하지 않습니다. **치수 정리 적용**은 모든 위치를 한 번에 저장하며 Undo 한 번으로 모두 복원합니다. 취소·Escape 또는 문서/화면 변경은 미리보기만 폐기합니다.

간격 정리는 모든 겹침을 자동 해소하는 기능은 아닙니다. 긴 문구나 연장선 교차는 남을 수 있으므로 빨간 안내를 확인하고 개별 배치로 조절하세요. 미리보기는 프로젝트·출력을 변경하지 않으며, 적용한 결과만 기존 저장·SVG/PDF 경로에 반영됩니다.

### 주거 시트와 저장 치수 연결

Direct의 저장/편집에서 **출력 도면**을 선택하면 모델 측정을 기존 단면 도면에 붙일 수 있습니다. 기준 평면이 같고 A/B 부품을 모두 포함한 유효 도면이 필요합니다. **모델 좌표**는 기존 동작을 유지합니다. 도면 연결은 version 47 파일로 저장됩니다.

연결한 도면의 원점·축척을 따라 종이 XY로 표시·출력합니다. 측정 숫자는 모델의 실제 거리이며 문자 높이는 종이 mm입니다. 오프셋·방향키·정리 간격은 모델 mm이므로 1:100에서 100mm 이동은 종이 1mm 이동입니다. 직접 드래그는 이 축척을 자동 적용합니다. 스냅·그룹 정리는 같은 출력 도면의 치수끼리 적용합니다.

연결된 도면이 없어지거나 원본 부품을 포함하지 않으면 재지정이 필요합니다. 기존 측정의 **편집·재지정**에서 유효 도면 또는 **모델 좌표**를 선택해 복구하세요. 임의 카메라 투영/HLR 도면 연결과 저장 치수 DXF 출력은 지원하지 않습니다.
