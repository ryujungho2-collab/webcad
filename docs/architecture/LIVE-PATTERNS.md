# Live 2D Mirror / Linear·Grid / Radial Pattern

> 단계 기록: 아래 구현·검수 수치는 해당 시점의 근거다. 최신 지원 범위는 [CAD-BASICS](../product/CAD-BASICS.md), 최근 전체 검수는 [PROJECT-STATE](../../PROJECT-STATE.md), 다음 실행 순서는 [NEXT-STEPS](../../NEXT-STEPS.md)를 따른다.

2026-10-03. 사용자가 기능 확장을 우선하도록 재지정하여, 기계 부품의 반복
구멍과 건축 도면의 반복 형상을 만드는 첫 CAD 기능 묶음을 구현했다.

## 사용할 수 있는 기능

- 일반 도형 또는 스케치 곡선을 선택하고 Modify → Mirror / Linear Array /
  Radial Array로 생성한다. 여러 원본도 같은 작업면이면 함께 배치한다.
- 미러 축의 두 점, 격자의 열·행·간격, 원형 배열의 중심·개수·각도 간격을
  정확히 입력한다. mm/cm/m/in/ft와 deg/rad를 지원한다.
- 실제 명령으로 계산한 미리보기를 표시하며 Fit preview로 원본과 모든
  생성 형상을 화면에 맞춘다. Apply 전에는 문서와 Undo 이력을 변경하지 않는다.
- 원본은 그대로 남는다. 원본의 좌표·반지름·스케치 구동 치수·배치를 바꾸면
  생성 곡선과 연결된 배열·돌출·연관 치수까지 같은 트랜잭션으로 갱신한다.
- 생성 인스턴스를 선택하면 Inspector의 Edit pattern으로 정의를 다시 편집한다.
  격자의 개수를 바꾸어도 살아남는 **행·열 위치**의 객체·위상 참조를 보존한다.
- Detach pattern은 현재 모든 인스턴스를 독립 도형으로 분리한다.
  Delete pattern은 생성 형상만 삭제한다. 개별 인스턴스의 직접 형상 수정은
  원본/정의 편집 또는 분리로 안내하며, Duplicate는 독립 복사본을 만든다.
- 생성 결과는 일반 해석 곡선으로 측정·돌출·SVG/DXF 출력에 사용할 수 있다.
  저장 파일 v3은 원본 관계와 정의를 보존한다. v1/v2도 계속 읽는다.

## 정확성과 트랜잭션

원의 반지름, 호의 각도·진행 방향, 폴리라인의 bulge를 유지한다. 화면에
그린 점들을 원본으로 저장하지 않는다. 원본의 모델 배치를 실제 좌표로
반영하며 XY/XZ/YZ 작업면과 작업면에 평행한 회전·균일 곡선 스케일을 지원한다.
구속된 스케치 원본은 해석한 투영에서 읽고, 생성 결과에 스케치 소유권을
복사하지 않는다. 위상 ID는 원본 ID를 인스턴스 범위로 확장한다.

생성·정의 편집·분리·삭제는 각각 한 Undo다. 미리보기 Apply는 동일한 평가
결과와 ID를 쓰며, 문서 버전이 바뀐 제안은 거부한다. 누락된 원본, 불완전한
그룹, 순환 참조, 잠긴 출력과 하위 피처가 사용하는 인스턴스 삭제는 전체를
실패시키므로 부분 변경이 남지 않는다. 생성된 반지름 등에 별도 변수
바인딩을 걸어 정의와 충돌시키는 경로도 차단한다.

## 현재 범위와 다음 기능

이번 기능은 **2D 해석 곡선 배열**이다. 원본을 포함한 배치 수는 2–128,
원본은 최대 32개, 생성 객체는 최대 256개다. 원형 배열은 전체 회전에서
마지막 인스턴스가 원본과 중복되지 않는 각도 간격을 받는다. 타원으로
변하는 비균일 곡선 스케일, 작업면 밖의 기울기와 법선 방향 이동은 명시적으로 거부한다.
기존 돌출이 참조한 구멍을 줄이려면 먼저 하위 피처의 프로파일 관계를 바꿔야 한다.

미러 원본 삭제 옵션, 배열 인스턴스 제외/개별 덮어쓰기, 경로 배열,
정의의 변수 바인딩과 드래그 축/중심 핸들은 후속 범위다.
3D BRep 솔리드의 직접 미러/배열은 아직 구현하지 않았다.
최신 사용자 요청에 따라 다음 작업은 [기본 CAD 기준과 공백](../product/CAD-BASICS.md)을
먼저 처리한다. 블록 정의/인스턴스의 추가 확장과 3D 솔리드 배열은 그 뒤이며,
Hole/Shell은 기본 3D 기준에 포함한다. 큰 배열의 피드백·입력 편의는 후속 과제다.
