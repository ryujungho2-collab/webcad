# Courtyard Commons — conic HLR

56부품·12도면·7페이지(v36). 원래 제외했던 경사 천창을 포함한 전체 입면과 천창 상면/측면 HLR, 타원 단면의 실제 배경을 추가했다.

- `courtyard-commons.webcad.json`: 전체 원본·도면
- `courtyard-commons.pdf`: 실제 앱 다운로드 7페이지 PDF
- `conic-sheet.svg/.dxf`, `skylight-background.svg/.dxf`: 새 정확 출력
- `project-report.json`, `native-project-report.json`: 실제 모델·출력·재열기
- `conic-projection.*`, `native-report.json`: 작은 실제 UI/Worker pilot

타원/유한 타원호를 source axes/domain으로 보존한다. sharp/silhouette만 출력하고 tangent/seam/isoline은 제외한다. 가시·숨은 구간과 실제 가림 gap은 합치지 않는다. 비선형 spline/parabola/hyperbola와 타원 해치는 남은 범위다. 제품 성능과 건축 설계의 법규·구조·피난 완성을 주장하지 않는다.
