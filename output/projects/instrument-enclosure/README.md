# 벽걸이 전자장치 외함 · 별도 덮개

120 × 90 × 40 mm 외함, 3 mm 벽/바닥과 3 mm 별도 덮개. 케이블 포트 Ø12, 덮개 기둥 네 개와 막힌 구멍, 벽걸이 귀 두 개와 Ø5 구멍, 덮개 Ø3.5 구멍 네 개와 3 × 24 mm 환기 슬롯 일곱 개를 만들었다.

사람의 공통 도구 입력 → 내부 자연어 → 실제 MCP SDK → 사람의 후속 Boolean으로 작업했다. 사람의 대상 선택은 같은 편집기·자연어·MCP에 반영된다. 모델 API 요청은 0회이며 과제 치수와 호출 순서는 에이전트가 작성했다.

- [편집 원본](enclosure.webcad.json): 두 부품·숨긴 원본·마감·연관 단면
- [STEP](enclosure.step): 실제 두 부품 BRep
- [호출과 영수증](handoff.json): MCP 요청/적용, 부품 ID와 과제 치수
- [외함 상부 절단](housingUpper.svg): Z35에서 기둥과 막힌 구멍
- [외함 가로 절단](housingSection.svg): Y45
- [덮개 절단](coverPlan.svg): Z1.5, 환기 슬롯과 구멍
- 각 단면의 동일 이름 `.dxf`
- `native-editor.png`: 실제 사용자 CAD 프로젝트 화면
- `browser-report.json`, `verification.json`: 검증 결과와 해시

덮개는 구멍 중심이 기둥과 일치하는 Z40 조립 위치를 확인한 뒤, 검사하기 쉽도록 +160 X / −40 Z로 분리했다. Undo/Redo로 같은 부품을 이동한다.

체적: 외함 `81048 + 2074.62π mm³`, 덮개 `30888 − 36.75π mm³`. 실제 보어 원본의 XY 중심도 비교한다. 나사산, 전자부품/배선 배치, 열·방수·구조 성능과 제작 공차는 검증하지 않았다. 단면은 실제 절단 형상이며 완성된 제작도는 아니다.
